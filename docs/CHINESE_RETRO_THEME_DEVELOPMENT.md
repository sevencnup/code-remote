# 中国复古风主题开发文档

## 目标

新增可在主题设置中选择的中国复古风主题，使用用户提供的青黛山水边框和图标素材，并保持现有主题设置及浏览器本地保存方式。

## 用户可见分类与版本

- 分类：新增功能。用户可选择此前不存在的界面主题。
- 版本：`0.67.0-dev.1`，从当前 `0.66.1-dev.6` 按 0.x 新功能递增中版本。
- 更新记录：只写主题新增描述，不写实现细节。

## 实施步骤

1. 检查现有主题偏好、主题选择器、像素风素材引用和主题样式，确认复用现有主题切换流程。
2. 从用户提供的边框图和图标图中提取透明 PNG 资源；按上两排各 6 个、底排 7 个的排布裁出 19 个独立图标，保存到中国复古主题资源目录。
3. 在主题枚举、设置选项和预览卡片中加入“中国复古”主题。
4. 增加配套的青黛、冷白与灰青配色；参照像素风，把边框素材用于各个独立模块（标题栏、侧栏控件、聊天输入与消息卡片、文件区、设置卡片、对话框和终端导航），不把边框铺成整屏外框；将图标应用到对应操作与主题设置面板，确保原有主题样式不受影响。
5. 更新 `package.json` 与 `CHANGELOG.md` 到 `0.67.0-dev.1`，记录本次新增主题。
6. 检查变更范围与 Git 状态，仅提交本次开发文件；保留工作区中原有未跟踪的 APK 和部署记录。

## 完成标准

- 用户可以在主题设置中选中“中国复古”，即时应用并在刷新后保留选择。
- 主题以青黛、暖米色和金色为主，使用提供的边框和独立图标素材。
- 现有主题标识、配色和设置流程继续工作。
- 更新记录与应用版本号一致，提交只包含本次任务相关文件。

## 验证说明

原主题开发按源码、资源和版本记录检查；本次边框归位修正另行运行本地前端构建，不新增或运行测试。

## 边框归位修正（0.67.0-dev.1）

- 分类：修复 / 样式纠正。中国复古主题已存在，本次只将边框从整屏外框改为模块边框，不增加新的用户能力。
- 版本记录：属于小调整，不新增 CHANGELOG 条目，版本保持 `0.67.0-dev.1`。
- 实施步骤：移除根节点伪元素外框及页面缩进；按像素风已有边框模块，将中国风边框应用到对应模块；保留主题选择器里的主题预览边框。
- 后续细节调整：加厚模块边框，让角饰和山水纹样在面板、标题栏与卡片上清楚可见；选中项按尺寸使用较细的边框。
- 范围修正：聊天主页面不加整块外框或激活描边；保留标题栏、输入区、消息卡片等子模块的边框。
- 遗漏控件补齐：为侧栏搜索框和文件面板顶部的服务端路径输入框加上清晰的中国风边框，并为路径输入框留出合适的高度。
- 外层边框调整：侧栏和设置页最外层收窄为 1px 灰青线，与白色主题的细分隔线接近；内部模块边框保持原厚度。
- 状态提示留白：正在思考区域不套装饰边框，避免压缩聊天内容空间。
- 用户消息卡片：压缩上下边框厚度，减少卡片纵向占用。
- 聊天输入框：改用用户补充的横向山水边框素材。
- 聊天输入框：山水边框调整为上沿 20px、其余三边 16px，减少素材透明边缘占用。
- 聊天输入框：收窄边框与文本、工具栏之间的内侧空隙，避免厚边框内再显出一圈空白。
- 聊天输入区：采用冷白底色，与聊天背景拉开区分。
- 输入框背景修正：容器背景改为透明，去掉垫在山水边框后的黄色层；文本输入区沿用控件自身的冷白底色。
- 用户消息卡片：上下内边距从 10px 收到 7px，边框从 7px 收到 5px；非内容纵向留白约减少三成，保持文字字号与左右间距。
- 右侧文件菜单：为普通操作补上与侧栏协调的深青色文字和浅色悬停样式，保留禁用态与删除操作的区分。
- CPA 用量筛选：为时间范围标签补上清晰区分的灰绿普通态和深青选中态。
- 终端故障提示：加深说明文字颜色，并区分重试主按钮与关闭按钮，提升浅色背景上的可读性。
- 验证：按用户当前请求构建本地前端产物；不新增或运行测试。

## 去黄配色调整

- 分类：修复 / PATCH。保留中国复古主题的青黛山水风格，按用户反馈移除界面中的黄色和米金色调。
- 版本：保持 `0.67.0-dev.1`；这是配色修正，不增加功能，不新增 CHANGELOG 条目。
- 实施：将主题界面颜色统一调整为冷白与灰青；为山水边框和主题图标生成冷色素材版本；移除对暖色主题样式的继承，并覆盖工作区默认深色底。
- 墨绿色微调：按用户色样将主色统一为 `#15464e`，用于主题强调色。
- 输入框底色修正：输入框容器改用与聊天背景相同的冷白 `#f1f9fb`，保留独立文本输入区的亮色底。
- 背景统一：工作区、分栏和聊天面板统一使用聊天内容区的冷白底色 `#f1f9fb`。
- 排队消息可读性：为浅色队列面板设置深色标题、状态、消息摘要和操作文字；禁用操作保持足够对比度。
- 菜单配色统一：输入框下拉菜单、左侧聊天右键菜单和右侧文件右键菜单统一为冷白底、深青文字和灰青悬停；删除操作保留红色区分。
- 输入区可读性：为浅色输入区补充深色输入文字、占位提示和模型/思考/权限控件颜色；禁用控件不再整体降透明度。
- CPA 用量页前景色：在统计面板根级统一浅色主题文字前景，避免卡片、趋势图和表格继承深色主题浅字；金额、主指标和错误状态保留可读的语义色。
- 输入框边界清理：文本输入区移除独立底色、描边和内层焦点框，沿用聊天背景；保留用户选定的山水外框作为唯一输入框边界。
