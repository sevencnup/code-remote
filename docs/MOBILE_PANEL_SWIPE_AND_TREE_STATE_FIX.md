# 移动端侧栏滑动与文件树状态修复

## 目标

- 降低左右侧栏跟手滑动时的卡顿和重绘。
- 从已打开的移动端文件树进入预览后，关闭预览时恢复文件树，并保留展开目录、选中项和滚动位置。
- 切换聊天或浏览根目录后，再返回时恢复各自的文件树浏览现场。

## 原因

- 触摸移动事件当前会在同一帧内反复写入侧栏位移和遮罩背景，拖动自定义透明主题时还会持续计算模糊效果。
- 文件树状态只保存在当前 React 状态中，作用域变化时会直接清空，并且滚动位置没有单独记录。

## 实施步骤

1. 用 `requestAnimationFrame` 合并同一帧内的侧栏位移与遮罩透明度更新。
2. 让位移和遮罩使用独立合成层；拖动期间暂停阴影和背景模糊。
3. 按聊天、工作目录和浏览根目录保存文件树目录数据、展开项、选中项和滚动位置。
4. 记录预览前文件树是否打开；关闭预览或返回先前文件树作用域时恢复浏览现场。
5. 更新测试版本与版本记录，完成构建和差异检查后提交到本地仓库。

## 验收条件

- 左右侧栏连续来回拖动时，面板和遮罩每帧最多更新一次，手势结束后停靠状态正确。
- 从已打开的文件树进入预览，关闭预览后文件树自动恢复，展开目录、选中文件和滚动位置保持不变。
- 切换聊天后各聊天的文件树状态互不覆盖；首次进入的目录仍能正常加载。
- 桌面端文件树、文件预览和移动端点击遮罩关闭行为保持正常。
