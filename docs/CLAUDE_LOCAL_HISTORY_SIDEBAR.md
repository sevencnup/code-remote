# Claude 本机历史与模式侧栏

## 现场

- 侧栏直接展示合并后的 Codex 与 Claude 列表，切换模式后仍显示大量 Codex 对话。
- 本机 Claude Code 的 `projects` 目录有 2 个原生会话文件；现有服务只读取自己维护的 `claude-code.sqlite3`，其中仅有 1 条网页创建的空对话。因此本机已有 Claude 记录没有进入侧栏。

## 目标与处理

1. 侧栏按当前窗口模式筛选，Codex 模式只列 Codex，Claude Code 模式只列 Claude；切换入口仍可在内部的完整列表中寻找目标对话。空列表文案按模式区分。
2. 读取本机 Claude Code 配置目录的项目会话 JSONL，跳过子代理会话与无用户消息的文件。提取普通用户文字和 Claude 回复文字，按轮次映射到现有聊天格式，不传送工具原始参数、思考内容、认证信息或附件数据。
3. 把发现的本机会话登记在服务自己的数据库，以便复用现有的读取、重命名、继续聊天和工作目录逻辑。源文件只读；按文件修改时间增量同步尚未由网页继续的会话。网页开始继续后以自己的记录为准，避免同步覆盖正在进行的回复。
4. 删除从本机导入的条目只在远程侧栏隐藏，不删除本机 Claude Code 原始历史；防止后续扫描再次出现。网页自己创建的 Claude 对话保持原有删除行为。
5. 更新语义版本和简要记录，构建网页、检查改动并提交本地仓库。保留用户现有 Android 文档修改，不主动重启当前后端。

## 版本判断

读取本机 Claude Code 历史使用户可以打开和继续之前无法在远程页面使用的对话，属于新增功能（MINOR），目标版本 `0.14.0-dev.1`。本次不打 Android 安装包，`versionCode` 不变。

## 检查与生效

- Python 文件已完成语法编译，网页 `pnpm build` 成功；没有运行自动化测试。
- 当前 Python 服务仍是旧进程。侧栏筛选随新网页资源生效，本机历史导入需后端重新加载；在此之前不会改动本机 Claude 原始文件或运行中聊天。
