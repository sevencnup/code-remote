# Android 原生界面功能补齐记录

## 目标

对照网页端系统设置和移动端原生界面，补齐消息时间、模式主题、输入区布局、图片预览和文件树导航，并让原生设置覆盖网页端已有的外观、显示和系统通知功能。

## 用户可见变更分类

- 分类：新增功能 / MINOR。
- 理由：原生设置增加暖色和自定义主题能力，并补齐网页已有的全局字号、背景图、颜色及透明度设置；其余消息展示和导航问题属于修复。
- 目标版本：`0.21.0-dev.1`。
- Android `versionCode`：`169`。

## 开发步骤

1. 对照 `ThemeSettingsPanel` 与原生 `showSettings`，列出并实现一致的主题、显示、通知选项。
2. 统一全局字号缩放；保留所有标签、输入框、侧栏、文件树、操作记录、聊天消息和设置页面的基础字号比例。
3. 显示 AI 回复时间和思考状态时间，修正短用户消息气泡宽度及模式切换后的空白提示文案。
4. 让 Codex/Claude 模式品牌图标出现在模式提示中，且 Claude 模式使用橙色强调色。
5. 收紧模型、思考、权限菜单与发送按钮尺寸，替换排队操作按钮图标。
6. 修复 Codex 查看图片的工作目录相对路径解析和图片预览错误重试。
7. 改善输入法开合期间的窗口布局，确保内容平滑跟随且不遮挡输入区。
8. 为文件树增加路径输入/跳转与返回上级操作，保留当前目录缓存和错误反馈。
9. 逐项检查设置、聊天、侧栏、队列、模式切换、终端、文件树及图片/文件预览的可达性和空/错状态。
10. 执行静态检查、项目现有构建与测试、原生构建和可用真机验收；归档 APK 并本地提交。
