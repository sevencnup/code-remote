# 文件树刷新与脚本样例可见性修复

## 问题

手动验证脚本位于 `/mnt/data/code/终端运行测试`，而文件树通常跟随当前聊天目录 `/mnt/data/code/code-remote`。刷新只读取当前根目录，因此不会显示上一级的兄弟目录。文件树的刷新按钮也只重新读取根目录，已展开的目录仍保留旧内容；输入框可能显示切换前的工作目录，进一步误导用户。

## 目标

- 在当前项目根目录提供同一组终端运行样例，同时保留原位置的样例。
- 刷新按钮重读当前根目录和已展开且已加载的子目录。
- 文件树跟随聊天目录切换时，路径输入框同步显示实际浏览目录。

## 步骤

1. 将样例复制到项目内的 `终端运行测试` 文件夹，方便从当前项目的文件树直接找到。
2. 调整刷新按钮，使其重新读取根目录和当前已展开的子目录。
3. 修正跟随聊天目录时的路径输入框同步。
4. 按修复类别更新测试版号，构建并检查产物，创建本地提交。

## 验收标准

- 当前聊天工作目录为项目根目录时，文件树刷新后出现 `终端运行测试`。
- 在测试文件夹中新增文件后，展开该文件夹再按刷新，可以看到新增内容。
- 切换不同工作目录的聊天时，文件树路径输入框显示当前实际浏览目录。
