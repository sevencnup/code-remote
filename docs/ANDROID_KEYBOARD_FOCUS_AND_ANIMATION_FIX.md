# Android 键盘与输入焦点修复

## 问题

- 键盘弹出、收起时聊天页面卡顿。
- AI 回复刷新消息后，聊天输入框失去焦点和光标，用户需要重新点按输入框。

## 实施步骤

1. 移除消息自动贴底时会转移焦点的滚动调用，滚动位置更新只改变消息列表的偏移。
2. 键盘动画期间只按当前动画帧的高度移动聊天区和输入框，避免提前应用最终高度后再反向跳回；仅在系统栏位置变化时更新顶栏、侧栏与设置浮层。
3. 检查流式回复和键盘升降时输入框的焦点、草稿与光标位置，并避免终端输出滚动抢占终端输入焦点。
4. 递增 Android 测试包版本，构建独立 APK，更新已连接设备并核对安装版本。

## 验收标准

- AI 流式回复期间，输入框的焦点和光标位置保持稳定，输入中的文字不被清空。
- 键盘弹出和收起时，底部消息与输入框同步移动；用户手动上翻后不强制滚到底部。
- Android Debug 构建成功，安装到已连接设备；旧 APK 保留。

分类：PATCH / 修复既有输入与布局行为。`0.21.7-dev.20`、`versionCode 195` 是焦点与边距优化的中间测试包；最终目标版本：`0.21.7-dev.21`，Android `versionCode 196`。
