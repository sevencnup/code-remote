# 输入框偏好记忆开发文档

## 目标

刷新网页后恢复用户上次选择的模型和思考强度，同时在模型列表变化时自动校验并回退到可用选项。

## 实施步骤

1. 使用浏览器 `localStorage` 保存模型 ID 和思考强度。
2. 页面初始化时读取保存值，等待模型列表加载后校验模型和思考强度。
3. 保存值失效时使用当前 Codex 返回的默认模型和思考强度。
4. 更新版本记录，执行构建和差异检查，提交本地 Git 仓库。

## 验收标准

- 刷新网页后模型选择保持不变。
- 刷新网页后思考强度保持不变。
- 已保存模型或思考强度不再可用时，不会显示空菜单或发送非法值。
- `pnpm --filter codex-remote build` 成功，`git diff --check` 无输出。
