# Android 模式主题色与切换提示修复

## 目标

使侧栏新建对话按钮和当前聊天选中状态随 Codex / Claude Code 模式切换颜色，并移除模式切换时显示应用默认黑色图标的系统 Toast。

## 根因与方案

侧栏新建对话按钮把 Codex 蓝色背景写成固定色值，模式切换时没有更新。聊天列表选中描边也在暗色主题使用固定蓝灰色。改为按当前模式生成强调色，并在头部刷新时更新已构建的侧栏控件。模式切换已有带 Codex、Claude 图标的页面提示条；额外的系统 Toast 显示应用黑色图标且信息重复，切换模式时改由提示条单独反馈。

## 实施步骤

1. 按当前模式更新新建对话按钮背景、加号、文字和当前聊天描边颜色。
2. 切换模式时刷新侧栏强调色。
3. 保留包含正确模式图标的页面提示条，移除重复的系统 Toast。
4. 更新 PATCH 版本和简短记录，构建新的 Android debug APK，检查差异并提交本地 Git；保留旧 APK，不推送远端。

## 验收标准

- Claude Code 模式侧栏强调色为橙色系，Codex 模式为蓝色系。
- 切换提示条中的 Codex 与 Claude 图标分别保留对应品牌颜色。
- 模式切换不再弹出黑色应用图标的系统 Toast。
