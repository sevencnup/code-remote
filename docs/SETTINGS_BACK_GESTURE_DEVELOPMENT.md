# 设置页侧滑返回开发记录

## 问题

移动端设置页通过 React 状态显示，没有对应的浏览器历史记录。原生返回桥接未识别设置状态时，WebView 的兜底回退会把当前页面当作顶层页面退出。

## 实施

1. 打开设置页时压入一个仅用于设置层的同页历史状态。
2. 浏览器 `popstate` 以及 Android 原生返回都优先关闭设置层；关闭设置时同步清理该历史状态。
3. 验证普通页面回退行为不变，运行前端构建和差异检查；本地提交，不推送远端。

## 验收

- 设置打开后使用手机系统侧滑返回，只关闭设置并回到对话页，不退出应用/网页。
- 设置页内的返回按钮也关闭设置，不留下多余的历史层。
- 设置关闭后，下一次返回仍按原有 WebView/浏览器历史行为执行。
