# Android 横屏显示缺口与全宽布局开发说明

## 问题

横屏时聊天页右侧出现约 120px 的空带。PJZ110 的横屏窗口帧比整块显示区域少 120px，差值与右侧显示缺口安全 inset 一致；页面又把左右系统 inset 直接设为整体 padding，导致状态栏、顶栏、聊天区和输入框的背景都停在安全区边缘。

## 实施步骤（0.30.1-dev.14 / PATCH）

1. Android 11 及以上允许窗口布局进入显示缺口区域；Android 9–10 使用短边缺口模式，以便横屏应用绘制全宽背景。
2. 聊天页根容器只保留底部系统栏/键盘 inset，不再用水平 inset 缩短页面背景；将左右安全 inset 移到顶栏按钮、消息内容、输入框内部和悬浮操作上，避免交互内容进入缺口区域。
3. 更新 PATCH 版本和 Android `versionCode`，构建并安装 APK；确认横屏背景延伸到屏幕右缘，同时控件避开摄像头缺口。

## 验收

- 横屏顶栏、聊天底色和输入框边框都延伸至屏幕右缘。
- 右侧缺口内不出现文字、图标或可点按控件。
- 竖屏系统栏和输入法留白保持正确。
