# Android 聊天文档附件显示

## 目标与分类

Android 聊天记录目前把用户消息中的 `[附件文档：文件名] ... [/附件文档]` 标记和整份文档正文当作普通消息显示。与网页保持一致：解析文档附件包装，聊天中显示文件名和字符数卡片，正文继续作为原消息附件内容保留。

本次属于修复 / PATCH：附件发送能力已存在，修正 Android 对已有附件消息的展示方式。目标版本 `0.49.1-dev.8`，Android `versionCode 308`。

## 实施步骤

1. 在 Android 用户消息中解析一个或多个文本文档附件标记，保留附件之外的普通消息文字。
2. 在聊天气泡中按网页样式显示文档名和字符数，不把文档全文展开在消息正文里。
3. 新发送消息的临时气泡也显示待发送文档卡片；复制用户消息时保留附件正文。
4. 更新版本、变更记录与开发记录，构建独立 APK，安装到已连接手机并核对现有引用消息。
5. 执行 `git diff --check` 并创建本地提交，不推送 GitHub。

## 验收标准

- 历史消息中标准 Markdown 文档附件不再显示原始附件标记或整篇正文，只显示文件名和字符数卡片。
- 附件前后用户输入的普通文字继续显示。
- 正常用户消息、助手 Markdown 消息、图片和发送内容不受影响。
- APK 成功构建并安装，手机现有对话中的文档引用显示为卡片。
