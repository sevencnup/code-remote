# Android 手势导航背景与键盘间距修复记录

## 目标

让 Android 网页内容延伸到手势导航区域，去掉底部黑条；键盘弹出时让输入区贴近键盘，不留下大块空白。

## 处理方案

- Activity 使用 edge-to-edge 布局，保留状态栏顶部安全区，让网页背景继续绘制到导航手势区域。
- Android 将导航栏底部安全距离传给网页。键盘收起时输入区避开手势条；键盘弹出时改用 IME inset 调整 WebView 可用高度，并取消导航栏预留距离。
- 保留网页现有 `visualViewport` 高度同步，避免窗口尺寸变化后输入区位置滞后。

## 实施步骤

1. 配置透明导航栏和 edge-to-edge WindowInsets；状态栏和原生连接页继续遵循系统栏安全区。
2. WebView 内容绘制到导航栏后方，键盘显示时按 IME inset 收缩内容区域。
3. 将导航栏安全距离同步为网页 CSS 变量，仅在键盘收起时用于输入区底边距。
4. 更新 Android 版本和 CHANGELOG，构建网页和新版本 APK，检查差异并提交本地仓库。

## 验收标准

- 聊天页面背景覆盖底部手势导航区域，不露出独立黑色横条。
- 键盘收起时输入区与手势条保持安全距离。
- 键盘显示时输入区位于键盘上沿附近，没有大块空白；收起键盘后页面恢复全高。
- 原生连接页仍避开状态栏和导航栏，旧 APK 保留，新 APK 使用独立版本文件名。
