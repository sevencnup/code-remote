# Android 附件、排队与页面交互开发记录

## 需求

1. 从打开键盘的输入框选择图片并返回时保持键盘状态稳定。
2. 图片和文字发送成功后，排队消息不再残留对应图片。
3. 设置页采用紧凑的折叠菜单，保留现有设置功能。
4. 页面返回增加平滑过渡。
5. 输入框附件图片支持放大查看。
6. 侧栏聊天三点菜单扩大触摸范围。

## 实施步骤

1. 检查附件选择、消息提交、排队刷新和键盘焦点的现有状态流。
2. 修正附件返回与发送状态，调整设置、导航及相关触摸控件。
3. 递增 Android 测试版本并记录用户可见更新，构建独立 APK、安装到已连接设备。
4. 检查改动和安装结果，提交本地仓库；不向 GitHub 推送。

## 版本分类

附件预览属于新增能力，目标版本使用 `0.25.0-dev.1`；其余属于修复或体验优化。
