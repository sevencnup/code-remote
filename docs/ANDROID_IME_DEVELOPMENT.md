# Android 输入法唤起修复记录

## 目标

修复 Android APK 内的 WebView 输入框获得焦点后无法显示系统输入法的问题，同时保留网页侧边栏中的地址切换入口。

## 判断

最近移除原生顶部工具栏时，WebView 从垂直 `LinearLayout` 的剩余空间改为直接挂在 `FrameLayout` 上。这个尺寸链路在当前设备的 Android WebView 中会让输入法窗口虽然收到显示请求，却没有正确参与可调整布局。恢复垂直容器，并显式设置可调整的软键盘模式，避免网页输入区与 IME 的窗口测量脱节。

## 实施步骤

1. 保留无原生工具栏的界面，将 WebView 放回垂直容器并使用权重占满剩余空间。
2. 为 Activity 设置 `adjustResize`，让系统输入法出现时 WebView 能收到新的可用高度。
3. 网页聊天输入框获得焦点时，通过 Android bridge 使用 `SHOW_FORCED` 再次请求输入法，兼容设备存在外接或虚拟键盘时系统忽略隐式唤起的情况。
4. 更新 Android 版本号和版本记录，构建新 APK，不覆盖历史产物。
5. 在真机上验证配对码输入框和聊天输入框都能唤起输入法，并完成本地提交。

## 验收标准

- 点击配对码输入框后系统输入法可见并可输入。
- 进入聊天页后点击消息输入框，系统输入法可见，输入区不会被遮挡。
- Android 地址切换仍通过网页侧边栏的桥接入口完成。
- 旧版本 APK 文件保留，新 APK 使用独立版本号。
