# 网页消息图片复制修复

## 目标

复制带图片的聊天消息后，粘贴到支持图片的目标时包含图片；粘贴回本应用输入框时保留消息文字和所有图片。

## 根因

局域网 HTTP 页面通常没有异步 Clipboard API。现有回退只写入 `text/plain` 和包含 `data:` 图片地址的 `text/html`，但输入框只读取剪贴板文件，因此图片丢失，按钮仍错误显示“已复制”。

## 实施步骤

1. 在同步复制事件中尝试将消息中的图片作为文件写入剪贴板，同时保留文字与 HTML；只有真实图片数据写入成功时才显示完整复制成功。
2. 输入框粘贴时兼容消息复制产生的 HTML 内嵌图片，优先保留全部图片，并同时插入原消息文字；仅接受内嵌且属于受支持格式的图片。
3. 保持安全上下文的 PNG 复制路径，并处理图片转换失败时的结果，避免把只有图片标签的内容误报为完整成功。
4. 按 PATCH 更新版本记录，构建网页，检查差异并提交本地仓库。

## 验收标准

- 在局域网 HTTP 页面复制单张或多张图片消息，粘贴到本应用输入框后能看到图片附件和原消息文字。
- 能写入图片文件的浏览器会向系统剪贴板提供图片数据；不能写入时，按钮不会提示图片已复制成功。
- 普通纯文字消息的复制与粘贴行为保持可用。
