# Android 文件树脚本终端运行补齐

## 问题

网页版文件树已显示“终端运行”，Android 原生文件树使用独立右键菜单，仍只显示“加入输入框”等旧操作，因此用户在原生界面看不到按钮。

## 目标

Android 原生文件树对单个受支持的脚本文件显示“终端运行”。点击后打开独立终端会话，以脚本所在目录为工作目录，连接就绪后自动提交运行命令。与网页版支持的扩展名保持一致：`.py`、`.js`、`.mjs`、`.cjs`、`.sh`、`.ps1`、`.bat`、`.cmd`。

## 实施步骤

1. 在 Android 原生文件菜单中识别脚本并加入“终端运行”。
2. 为终端增加一次性运行请求；运行时避免复用当前聊天的 tmux 会话，并使用脚本所在目录。
3. 按服务端返回的 shell 安全引用脚本路径，连接就绪后执行一次；不支持当前 shell 的脚本显示明确错误。
4. 更新 Android 与应用版本，构建不覆盖历史包的新版 APK，检查差异并本地提交。

## 验收标准

- 原生文件树单选脚本文件的菜单可见“终端运行”。
- 终端显示脚本输出，工作目录为脚本所在目录。
- 旧终端的程序不会收到脚本命令；连接失败和终端重连不会重复执行。
- 目录菜单的“加入终端”仍只填入切换目录命令。
