# 移动端工作区文件预览开发文档

## 目标

移动端可以从已编辑文件卡片或文件树打开只读文件预览，并在已编辑文件的差异视图中标注新增行和删除行。

## 设计边界

- 预览沿用现有受保护的工作区文本读取接口、行号、语法高亮、刷新、复制和 unified diff 渲染，不新增写文件能力。
- 手机预览以全屏对话层显示，尊重设备安全区；提供关闭按钮、点背景关闭、Escape 和 Android 系统返回关闭。
- 从文件树打开预览后关闭，返回原有文件树浮层并保留目录展开与滚动状态；从改动卡片打开则关闭后返回聊天。
- 文件树点文件改为预览；原有“加入输入框”按钮继续插入路径，且已加入的路径仍不显示重复添加按钮。
- 从改动卡片打开时传递该文件的 diff，复用已有浅绿新增行、浅红删除行标注；从文件树打开仍展示文件当前全文。
- 桌面端预览栏布局和宽度调整不变，移动端不显示拖动分隔条。

## 实施步骤

1. 更新原文件预览与文件差异开发文档，记录移动端新增入口及既有移动端插入行为的调整。
2. 让审核卡片和工作区文件树在移动端均可进入共享的预览加载状态，并保留普通文件树全文与审核 diff 两种模式。
3. 增加安全区全屏预览层和遮罩样式；在手机端提供显式关闭、背景关闭、Escape 与系统返回处理。
4. 保持文件树加号的路径插入功能；切换聊天工作目录时仍清理过期预览请求。
5. 执行 TypeScript 检查、Vite 生产构建、相关后端测试和 `git diff --check`；更新版本记录并创建本地提交，不推送 GitHub、不启动或重启服务。

## 验收标准

- 手机点已编辑文件卡片的文件名，打开对应只读预览；有 diff 时能看到新增行浅绿、删除行浅红。
- 手机文件树点普通文件打开全文预览，关闭后回到之前展开的文件树。
- 预览支持语法颜色、行号、横纵滚动、刷新和复制；删除文件仍能展示卡片传入的 diff。
- 预览可以由关闭按钮、遮罩、Escape 和 Android 系统返回关闭；打开文件树时不误关文件树状态。
- 文件树加号仍插入路径，已加入的路径仍避免重复插入；桌面端原有预览栏和调宽行为不变。
- TypeScript/Vite 构建、相关后端测试和 `git diff --check` 通过。
