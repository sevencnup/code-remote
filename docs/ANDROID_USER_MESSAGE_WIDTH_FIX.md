# Android 用户消息宽度修复

## 目标

修复窄屏下 Android 原生聊天中的用户消息气泡被压成单字宽、文字逐字竖排的问题。

## 根因与方案

消息气泡按内容宽度布局，但内部消息文本视图使用 `MATCH_PARENT`。父子宽度互相依赖时，Android 测量可能把气泡压到最小宽度。将文本视图改为 `WRAP_CONTENT`，并继续通过 `maxWidth` 限制消息宽度，让长内容正常换行。

## 实施步骤

1. 将聊天气泡中的消息文本改为按内容测量。
2. 更新 PATCH 版本与简短版本记录。
3. 构建 Android debug APK，检查差异并提交本地 Git；保留已有 APK，不推送远端。

## 验收标准

- 窄屏中文、英文及混合文本不再逐字竖排。
- 长消息受气泡最大宽度限制并正常换行。
- 新 APK 使用新版本文件名，不覆盖历史包。
