# CPA 用量统计“昨天”筛选

## 目标

在 CPA Token 用量统计页面增加“昨天”时间范围，按浏览器本地时区查询昨天完整自然日的数据。

## 实施步骤

1. [x] 为 CPA 用量范围类型增加“昨天”。
2. [x] 将“昨天”添加到时间范围筛选，并请求昨天本地时间 00:00:00.000 至 23:59:59.999 的数据。
3. [x] 更新语义化版本、Android `versionName` 和更新记录。
4. [x] 检查改动范围；本次不运行测试或构建。

## 验收条件

- 时间范围筛选显示“昨天”，切换后摘要、趋势、模型、账号和调用方密钥筛选都使用昨天的查询范围。
- 日期边界使用设备本地时区，并排除今天零点及之后的数据。
- 更新记录说明新增能力，不记录实现细节。
