# Android 终端光标可见性

## 目标与分类

Android 终端输入时显示 PTY 光标，让用户看见下一个字符会出现在哪里；光标随回车、退格、方向键及终端控制序列移动，在终端要求隐藏光标时消失。已有输入方式不变，属于修复 / PATCH。目标版本 `0.62.0-dev.15`，Android `versionCode 339`。

## 原因

`TerminalScreenBuffer` 已跟踪光标行列，但 `render()` 只输出屏幕字符；终端的隐藏输入控件又明确关闭了系统光标，所以页面完全没有插入位置提示。

## 开发步骤

1. 为终端输出文字控件添加独立的闪烁光标绘制，不向可复制的输出文本插入光标字符。
2. 将终端缓冲区的当前光标位置传给显示控件；遵守 tmux 状态行隐藏规则和 ANSI 光标显示/隐藏序列。
3. 关闭终端时停止闪烁回调；输入或移动光标后立即显示新位置，避免光标停在旧位置。
4. 更新版本记录，构建独立 APK；设备可连接时装机核对光标与键盘输入，不覆盖旧包。
5. 清理临时文件，检查差异并创建本地提交；不推送 GitHub。

## 验收标准

- 打开终端并聚焦键盘时能看到闪烁的插入光标。
- 按左右方向键、输入字符、退格后，光标跟随 PTY 输出移动。
- 复制终端文本时不出现光标字符；终端关闭后不再运行闪烁回调。
