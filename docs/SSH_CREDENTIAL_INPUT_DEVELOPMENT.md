# 远程 SSH 凭据输入补全

用户需要在网页里直接填写 SSH 密码，或粘贴、上传私钥。此前只能填写 Code Remote 主机上的私钥路径；直填凭据能连接此前无法使用的服务器，属于**新增功能 / MINOR**。继续 `0.81.0` 内测目标，版本递增为 `0.81.0-dev.2`。

## 范围和约束

1. 每台服务器选择认证方式：本机密钥/ssh-agent、SSH 密码、粘贴或上传私钥。加密私钥可另填口令。
2. 私钥文件从浏览器读取文本后提交；不把文件路径误当作目标机器路径。已有服务器编辑时，留空密码/私钥表示保留旧凭据。切换认证方式时要求提供新方式所需凭据。
3. 凭据存于服务端独立的权限受限文件，不放进普通服务器配置或操作日志；列表、保存和错误响应均不回显密码、私钥和口令。删除服务器时删除对应凭据。
4. 密码和直填私钥使用支持这两种认证的 Python SSH 客户端；原有本机密钥路径和 ssh-agent 连接保留。所有方式仍校验 known_hosts，不自动接受未知主机指纹。
5. 现有 MCP 权限检查、命令限时、输出日志和聊天显示继续适用。服务器操作权限的系统隔离边界不因存储凭据而改变。

## 实施顺序

1. 扩充服务端配置和凭据存储，并加认证方式的校验与脱敏响应。
2. 为密码和直填私钥接入 SSH 执行与连接检查，更新 Python 依赖。
3. 设置页增加认证方式、密码框、私钥文本框/文件选择及凭据状态。
4. 更新版本记录、构建并本地提交。本次不推送 GitHub。

当前网页若通过 HTTP 打开，直填凭据会经局域网明文传输；界面须明确提示，实际使用建议 HTTPS。
