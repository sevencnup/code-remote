# 聊天浮层共用与高度调整开发说明

## 目标

让工作区文件预览和本机终端共用同一聊天浮层面板，并能拖动浮层底边调整高度。

## 交互设计

- 文件预览与终端共用同一个 `ChatOverlayPanel`，共享标题栏、关闭操作、遮罩、尺寸约束和底边拖动手柄。
- 浮层仍限定在聊天区域，不挤压聊天和文件树布局，也不遮挡聊天输入框。
- 默认铺满可用聊天区域；向上拖动底边可缩小面板，向下拖动可增大；高度在当前页面会话内由两种面板共用。
- 鼠标、触屏拖动和键盘方向键都可以调整高度；双击手柄恢复铺满。窗口或方向改变后高度不超过可用区域。
- 文件预览的编辑、保存、复制、差异展示、移动端返回关闭和未保存修改保护继续有效；终端关闭仍结束 PTY shell。

## 实施步骤

1. 新建通用聊天浮层面板，统一标题栏、内容区、关闭行为及不同视口范围的定位方式。
2. 将文件预览和终端的专属界面内容移入通用面板，保留各自工具栏、终端状态和内容行为。
3. 为通用面板增加底边拖动手柄、键盘调整、最小与最大高度约束，以及当前页面会话内共享的高度记忆。
4. 更新开发文档、版本号、Android `versionCode` 和 CHANGELOG。
5. 执行 TypeScript 检查、生产构建和 `git diff --check`，不新增或运行测试；完成后创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 文件预览与终端使用同一个浮层外框和底边高度调整手柄。
- 调整浮层高度不改变聊天窗格、文件树和输入框的布局尺寸。
- 高度调整适用于鼠标、触屏与键盘，且不会超出当前可用聊天区域。
- 文件预览原有功能、终端交互、终端选区右键插入输入框及进程清理仍可用。
