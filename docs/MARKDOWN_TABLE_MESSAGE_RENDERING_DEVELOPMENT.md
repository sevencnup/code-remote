# 网页聊天 Markdown 表格显示开发

## 目标

粘贴的表格继续以 Markdown 文本进入输入框；发送后，网页聊天消息应将符合标准表头和分隔行格式的 Markdown 表格显示为带单元格边框的网格。普通文本、代码块和不符合表格格式的管道符文本保持原有显示方式。

## 实施步骤

1. 检查聊天文本分块渲染逻辑，找到不影响代码块处理的 Markdown 表格识别与解析位置。
2. 将合法表格渲染为语义化表头和数据行，并对表格单元格文本进行安全显示。
3. 添加与聊天主题适配的单元格边框、间距及窄视口横向滚动样式。
4. 运行相关测试和生产构建，检查工作区差异，确保不包含已有 Android 或 APK 改动。
5. 按项目版本规则判断并记录本次变更；仅提交本次相关文件，不推送远端。

## 验收标准

- 已转换的 Markdown 表格在发送后的消息中显示为带边框的网格。
- 表格前后的普通文本仍可正常显示。
- 代码围栏中的管道符不会被识别为表格。
- 窄屏内容可横向滚动，不撑破聊天布局。
- 用户粘贴到输入框中的表格仍保留可编辑的 Markdown 文本。
