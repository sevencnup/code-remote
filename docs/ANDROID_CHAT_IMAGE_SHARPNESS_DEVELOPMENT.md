# Android 聊天图片清晰度

## 分类与版本

- 分类：修复 / PATCH。聊天图片展示能力已经存在；本次修复 Android 预览降采样过度的问题，不改变发送和历史数据格式。
- 目标版本：`0.56.4-dev.5`，Android `versionCode 321`。

## 问题与方案

- Android 聊天缩略图当前限制为 720 px，但采样器总是向上取 2 的幂，图片只比限制大一点也可能被缩到一半尺寸。
- 点击聊天图片时复用缩略图 bitmap，放大查看仍然模糊。
- 调整采样尺寸选择，避免明显低于目标分辨率；点击图片时从内嵌原始数据或工作区原图异步解码，展示清晰预览，避免在主线程解码。
- 缩略图继续使用有界缓存；高清预览只在打开时按屏幕尺寸解码，不额外缓存多份大图。

## 实施步骤

1. 修正 Android 图片采样器的尺寸选择，保留接近目标分辨率的图像。
2. 聊天内图片点开时从原始数据或工作区图片端点重新取原图，并在后台解码。
3. 更新 Android PATCH 版本和简短版本记录。
4. 编译 Android Debug APK；如测试设备在线，检查聊天缩略图和高清预览，不运行独立测试套件。
5. 检查变更并创建本地提交，不推送 GitHub。

## 验收标准

- Android 聊天缩略图不再因采样进位而突然损失一半分辨率。
- 点开网页发送的图片时使用原图数据解码，显示清晰预览；工作区路径图片也使用原图。
- 图片解码和网络读取不阻塞主线程；原有低分辨率缓存仍有上限。

## 实施结果

- 图片采样器改为在接近目标大小时保留较高采样率，避免分辨率稍微超过上限时被直接降到一半。
- 聊天内嵌图片使用缓存缩略图；点开后以内嵌原图或工作区原图重新加载，在后台解码，预览目标尺寸不超过屏幕长边 2400 px。加载期间先显示缩略图和进度指示。
