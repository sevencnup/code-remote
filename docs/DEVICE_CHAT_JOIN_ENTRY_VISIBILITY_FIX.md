# 群聊加入入口可见性修复

## 分类与目标

修复 / PATCH，目标版本 `0.69.3-dev.1`。设备已有房间时，原实现隐藏整个加入表单，导致用户只看到生成加入码。修复现有加入操作的入口，不改变单设备当前只参与一个房间的约束。

## 步骤

1. 在群聊侧栏顶部常驻“创建房间”和“加入房间”按钮；无房间时优先展示加入表单。
2. 加入表单在已有房间时仍可打开和填写，提示先退出当前房间。退出使用现有确认流程，失败时保留当前状态和输入，不自动退出或解散。
3. 移除进入群聊模式时自动收起移动侧栏的逻辑，保留用户主动点击房间条目收起侧栏。
4. 更新版本及记录，检查已有房间和无房间时的入口，执行 TypeScript 与生产构建，提交并推送 Gitea。

## 验收

- 主持设备、加入设备和未加入设备都能直接看到“加入房间”入口。
- 已有房间时点击加入，地址和设备加入码输入框可见，提交前要求明确退出当前房间。
- 取消退出不会清除房间或填写的地址、加入码。
- 网页继续使用原聊天组件。

## 验证结果

- 渲染未加入、房间创建者、已加入成员三种侧栏状态，均显示加入入口；未加入时直接显示地址和加入码输入表单。
- TypeScript 检查通过；生产构建与差异检查通过，一次性渲染脚本已清理。
