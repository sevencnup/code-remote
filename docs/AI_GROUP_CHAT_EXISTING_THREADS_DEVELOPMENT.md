# AI 群聊与现有聊天关联开发文档

## 目标

扩展现有 AI 群聊，让用户创建多个群，并将已有 Codex / Claude Code 聊天加入群聊。群聊必须继续通过成员自己的会话发送消息，保留各自原有的历史、模型和权限设置。

## 范围与决策

- 群聊入口和群列表放在侧边栏聊天列表上方，以群聊图标标识，并提供创建入口。
- 每个群最多关联一个 Codex 聊天和一个 Claude Code 聊天；一个普通聊天最多属于一个群。
- 群组元数据及合并展示记录保存在浏览器本地；模型上下文仍由两个原始后端会话各自保存，不复制、重命名或删除成员聊天。
- 创建空群后，用户从普通聊天右键菜单选择「加入群聊」并指定目标群；群未同时拥有两个模式的成员时不可发送群聊消息。
- 群内可独立编辑 Codex / Claude Code 的显示昵称；此操作只修改群内显示名，不修改实际模式、模型或权限。
- 群成员聊天的右键菜单显示「退出群聊」。任一成员退出即解散整个群，并清除其群聊汇总记录；成员原始聊天保持不变。
- 删除任一群成员聊天时，在该聊天删除成功后解散所属群。删除失败或用户取消时不更改群关系。
- 将现有 `codex-remote.ai-group-chat.v1` 单群数据迁移到多群存储，保留原群的 thread ID 与合并消息。
- 限制群数量和本地消息存储量，避免 localStorage 被群聊累积内容占满。

## 实施步骤

1. 新增多群数据类型、校验、旧版单群迁移及本地持久化逻辑。
2. 调整群聊面板：使用传入的既有成员 thread ID，不自动新建聊天；按成员各自偏好发送；支持未齐成员提示和群内显示名编辑。
3. 将侧边栏群组列表与创建入口移到普通聊天列表上方；支持打开不同群聊。
4. 为普通聊天右键菜单添加加入群聊选择器和退出群聊；限制重复加入、模式槽位冲突，并在成功删除成员聊天后解散关联群。
5. 更新版本到 `0.52.0-dev.1`，新增一条版本记录；只修改 Android `versionName`，不构建 APK、不修改 `versionCode`。
6. 运行 `pnpm --filter codex-remote build` 和 `git diff --check`；不新增或运行测试。检查只暂存本次改动，不包含工作区原有未提交文件，并创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 侧边栏顶部可创建、查看并打开多个群聊。
- 可从聊天右键菜单将已有 Codex / Claude Code 聊天加入指定群；同一模式重复占位或聊天已在其他群时有明确反馈。
- 双成员群聊发送一条消息后，分别进入两个已有原始会话；两个模式看到自己的原聊天记忆，且模型和权限仍按原会话分别应用。
- 群内改名只改变该群对 AI 和消息显示使用的昵称。
- 任一成员聊天右键退出群聊会解散群及其合并记录，成员原始聊天继续保留。
- 删除群成员聊天成功会清理群关系；取消或删除失败不会解散群。
- 刷新网页后多群信息及合并显示记录仍在；旧版单群数据能被迁移。
- 构建成功，`git diff --check` 无输出；本次提交不包含用户已有的未提交改动。
