# 侧栏聊天快捷键切换开发说明

## 目标

在网页版侧栏中增加键盘快捷键，按当前侧栏显示顺序切换聊天。目标版本为 `0.36.0-dev.1`，属于新增功能（MINOR）。

## 设计

- 使用 `Alt + ↑` 切换到上一条聊天，使用 `Alt + ↓` 切换到下一条聊天；顺序与侧栏分组及置顶顺序一致，到达列表边界后循环。
- 搜索时只在匹配结果中切换；当前聊天不在结果中时，向下从第一项开始，向上从最后一项开始。
- 复用现有聊天选择逻辑，切到已在其他窗格打开的聊天时保持现有窗格行为。
- 输入框、文本编辑区、批量选择状态和弹窗中不响应快捷键，避免干扰输入和其他操作。
- 在侧栏聊天记录标题旁显示快捷键提示。
- 仅修改 Web 交互；同步 `package.json` 和 Android `versionName`，不改 Android 原生代码、不递增 `versionCode`、不生成 APK。

## 实施步骤

1. 在网页聊天页监听 `Alt + ↑/↓`，基于当前分组后的侧栏聊天列表循环选择上一条或下一条聊天。
2. 为输入编辑区域、批量选择、弹窗和不可切换状态增加忽略条件，并在侧栏显示快捷键提示。
3. 将 Web 和 Android `versionName` 更新为 `0.36.0-dev.1`，在 `CHANGELOG.md` 记录用户可见更新描述。
4. 执行生产构建和差异检查，创建只包含本次改动的本地提交；不运行测试、不推送远端。

## 验收标准

- `Alt + ↑/↓` 按侧栏可见顺序切换聊天，并在首尾循环。
- 搜索过滤后的结果可切换；当前聊天不在结果中时，从对应方向的结果边界进入。
- 已在其他窗格打开的聊天通过现有选择逻辑切换到对应窗格。
- 在输入框、编辑区域、批量选择或弹窗中按快捷键不会切换聊天。
- 侧栏标题显示 `Alt ↑↓` 提示；生产构建和差异检查通过。

## 完成记录

- 桌面网页支持 `Alt + ↑/↓` 按当前侧栏分组顺序循环切换聊天，提示会显示在聊天记录标题旁；输入区域、弹窗、批量选择和已交还状态会忽略快捷键。
- Web 与 Android `versionName` 更新为 `0.36.0-dev.1`；Android `versionCode` 保持 `279`，未修改原生代码或生成 APK。
- `pnpm build` 和 `git diff --check` 通过；未新增或运行测试。
