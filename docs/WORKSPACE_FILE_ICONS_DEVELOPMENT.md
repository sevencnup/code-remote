# 工作区文件类型图标开发说明

## 目标

将文件树、文件预览标题和文件变更入口使用的自制“文件页轮廓 + 扩展名文字”替换为 VS Code 文件图标主题中的对应 SVG，让常见代码、配置、文档和资源文件按类型显示各自的图标。

## 范围

- 复用同一个图标组件，覆盖文件树、预览标题和文件变更入口。
- 优先匹配特殊文件名，再匹配扩展名；未知类型使用主题通用文件图标。
- 保持现有尺寸参数、暗色/亮色主题可见性和无障碍标题。
- 图标资源取自 MIT 许可的 `@iconify-json/vscode-icons@1.2.89`（VS Code Icons 主题），并在项目中保留其许可声明。
- 不改动文件名解析、语法高亮和文件操作行为。

## 实施步骤

1. 确认并选取许可兼容的 VS Code Icons SVG 资源，放入项目静态资源目录。
2. 将常用扩展名和特殊文件名映射到有辨识度的图标；未映射文件回退到通用图标。
3. 更新图标组件和样式，移除单字母文件页仿制图标。
4. 检查差异和资源引用，构建前端确认静态资源可打包。
5. 按修复分类递增版本，并在完成回复中说明分类和判断理由。

## 验收标准

- `.sh`、`.jsonl`、`.ts`、`.py`、`.md`、`.gradle`、`package.json` 等文件能显示对应主题图标，不再只靠同一文件外框和扩展名字母区分。
- 图标在文件树、预览标题和文件变更入口保持一致。
- 未知扩展名仍有清晰的通用图标。
- 原有未提交的 `docs/ANDROID_APK_DEVELOPMENT.md` 修改保持不变。
