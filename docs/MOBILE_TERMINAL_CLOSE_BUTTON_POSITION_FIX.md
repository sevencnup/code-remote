# 移动端终端关闭按钮位置修复

## 目标与分类

修复移动端终端打开后关闭按钮位置跳到浮层右侧的问题。保留聊天顶部带边框的终端按钮，并让它在原位置切换为关闭按钮；移除终端浮层标题栏的关闭按钮。本次属于 PATCH，目标版本为 `0.8.0-dev.10`。

## 实施步骤

1. 终端开关按钮保持显示，打开时继续使用带边框的按钮并切换为关闭图标。
2. 隐藏终端浮层标题栏的关闭按钮，并移除仅用于切换关闭按钮位置的屏幕尺寸状态。
3. 更新 Web、服务端和 Android `versionName`，记录版本描述；不修改 Android `versionCode`。
4. 构建 Web 静态资源供当前 preview 服务使用；不新增或运行测试，不重启服务。
5. 检查差异并本地提交本次文件，不推送 GitHub，保留用户已有文档修改。

## 完成标准

- 手机端终端关闭键有边框，且与打开终端的按钮处于相同坐标。
- 终端浮层右侧不再出现额外关闭键。
- 页面构建通过，工作树中用户原有修改未进入提交。
