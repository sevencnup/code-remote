# 操作记录与复制按钮顺序调整开发文档

## 目标

调整已完成助手消息下方的辅助内容顺序，让复制按钮不再夹在操作记录和本机编辑卡片之间。

## 现状

助手消息当前按“操作记录、复制按钮、本机编辑卡片”显示。操作记录与本机编辑卡片被复制按钮分隔，移动端阅读顺序不够连贯。

## 实施步骤

1. 保持本机编辑卡片作为消息外部的后续内容。
2. 在助手消息内部交换操作记录和复制按钮的 JSX 顺序，使页面显示为“复制按钮、操作记录、本机编辑卡片”。
3. 更新版本记录并执行网页生产构建。
4. 创建本地 Git 提交，不推送到 GitHub。

## 验收标准

- 复制按钮位于操作记录上方。
- 操作记录位于本机编辑卡片上方。
- 复制功能、操作记录展开收起和本机编辑卡片功能不受影响。
