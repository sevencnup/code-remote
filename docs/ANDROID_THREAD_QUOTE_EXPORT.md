# Android 聊天标题菜单引用与导出

## 目标与分类

Android 侧边栏长按聊天标题目前只有打开、置顶、重命名和删除。新增与网页版一致的“导出”和“引用”：导出完整对话 Markdown，引用将对话记录作为文档加入当前输入框。用户因此能在 APP 内完成以前无法完成的任务，归类为新增功能 / MINOR。最终版本 `0.75.0-dev.2`，Android `versionCode 356`；第一次构建的 dev.1 安装包保留供追溯。

## 实施步骤

1. 对照网页版对话记录格式、文件名和附件语义，确认 Android 侧边栏菜单与草稿附件结构。
2. 从服务器读取所选聊天的完整历史，生成不嵌入图片二进制内容的 Markdown 对话记录。
3. 在长按菜单加入“导出”和“引用”；导出使用 Android 文档保存界面，引用加入当前输入框的文档附件并保留原草稿。
4. 处理读取、保存失败与跨连接切换，更新版本与更新记录，构建 Android APK 并保留历史包。
5. 复核改动并本地提交，不推送远端。

## 验收

- Codex 和 Claude Code 聊天都可导出、引用，菜单图标跟随现有主题。
- 导出文件包含完整对话文本与时间信息；图片和原始 PDF 只记名称。
- 引用不改变当前聊天和已有输入，文档出现在输入框附件区域，可在发送前移除。
