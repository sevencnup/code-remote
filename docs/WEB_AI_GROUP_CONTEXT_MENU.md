# 侧边栏 AI 群聊右键菜单

## 目标与分类

为侧边栏顶部的 AI 群聊条目增加管理菜单，支持打开、重命名和解散群聊。属于 MINOR / 新增功能：用户可以直接从侧边栏管理群聊。目标版本为 `0.57.0-dev.1`。

## 交互要求

- 桌面右键群聊条目打开菜单；触屏设备长按也可打开。
- 菜单提供打开群聊、重命名群聊和解散群聊。
- 重命名只修改群聊显示名称，不改变 Codex / Claude 成员名称、模型或权限。
- 解散前二次确认；删除群聊及群聊区域保存的消息，保留加入群聊的原始 Codex / Claude 聊天记录。
- 群聊正在生成回复时，不允许解散。
- 菜单沿用现有右键菜单样式和主题配色；Escape 与点击菜单外部可关闭菜单。

## 实施步骤

1. 为侧边栏群聊条目接入右键菜单和触屏长按。
2. 增加群聊重命名与解散确认流程，并接入现有群聊状态持久化。
3. 更新版本和 CHANGELOG；运行生产构建及差异检查，不新增或运行测试。
4. 检查差异并创建仅包含本次修改的本地提交，不推送 GitHub。

## 验收标准

- 右键或长按群聊条目可打开菜单，打开操作正常切换到相应群聊。
- 重命名后群聊列表和聊天标题同步更新并能持久化。
- 确认解散后群聊及其群内消息被移除，原始成员聊天记录仍保留；生成中群聊不可解散。
- `pnpm build` 成功；`git diff --check` 无输出；不新增或运行测试。
