# 移动端文件夹添加到终端

目标版本：`0.60.0-dev.1`（新增功能 / MINOR）。

## 目标

移动端用户可在右侧文件树中长按单个文件夹，通过现有上下文菜单打开当前聊天的终端，并预填切换到该目录的命令；不自动执行命令。

## 实施步骤

1. 在移动端文件夹菜单中显示现有的“添加到终端”操作，保留根目录及多选限制。
2. 为新增菜单项更新弹出菜单的定位高度；启动终端时收起移动端文件侧栏。
3. 更新版本号与变更记录。
4. 执行 `pnpm build` 和 `git diff --check`，不运行测试；仅提交本次修改，不推送 GitHub。

## 验收标准

- 手机端长按单个文件夹可见“添加到终端”。
- 点击后关闭文件侧栏、打开当前聊天的终端，并预填目录切换命令；不会自动回车执行。
- 文件、根目录及多选仍不显示该操作。

## 验证结果

- `pnpm build` 通过；Vite 有既存的大 chunk 提示。
- `git diff --check` 通过。
- 未运行测试、未做移动设备手动验收；未部署、未推送 GitHub。
