# 网页聊天 HTTP/HTTPS 链接显示规则

## 需求与范围

用户要求网页聊天中的 AI 回复只显示 HTTP/HTTPS 网址，网址前后的 AI 正文均不显示。按原话实现：只要一条 AI 回复正文包含至少一个 HTTP/HTTPS 链接，该回复正文仅呈现这些网址，多个网址各自可点击；操作记录和交互卡片保持可用。用户消息、纯代码块中的地址和不含 HTTP/HTTPS 链接的 AI 回复继续按原样显示。仅改网页显示，不改保存的原始消息或复制内容。

## 用户可见变化与版本

- 分类：不兼容变更 / MINOR（项目仍处于 `0.x`）。含链接的 AI 回复会隐藏原本可见的说明文字，改变了原有阅读方式。
- 目标版本：`0.87.0-dev.1`。

3. [x] 更新简短版本记录与版本号，构建现有 4173 网页预览，检查差异并仅提交本地仓库；未收到明确请求时不运行测试或推送远端。

## 验收范围

- 含 HTTP/HTTPS 链接的 AI 回复正文只显示完整可点击网址，不显示网址前后的其他正文。
- 多个网址能分别打开；链接目标保持原地址，原始消息记录不被修改。
- 非 HTTP/HTTPS 的消息内容按确认后的范围正常显示。
