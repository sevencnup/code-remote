# 网页侧边栏右键菜单快捷键

## 需求

左侧聊天列表和右侧文件树的右键菜单显示快捷键。菜单打开时，按对应按键执行该菜单项。

## 交互规则

1. 左右菜单各自从 `1` 开始编号；前九个普通操作使用 `1` 至 `9`，第十个使用 `0`。禁用的操作保留快捷键，但不能执行。
2. 两侧菜单的删除操作都显示 `Del`，按键盘 Delete 键执行；删除操作不占数字编号。
3. 小键盘数字与主键盘数字一致。输入框、文本编辑区和输入法组合期间不响应；带 Ctrl、Alt、Meta、Shift 的按键不响应。
4. 快捷键调用对应按钮原有的点击处理，保留上传选择器、删除确认和禁用状态等行为。

## 实施步骤

1. 扩展菜单快捷键处理，让数字键和 Delete 键直接命中对应按钮。
2. 改造左侧聊天菜单与右侧文件树菜单；删除项显示 `Del`，右侧动态菜单的第十项显示 `0`。
3. 更新版本与版本记录，执行构建并提交到本地仓库。
