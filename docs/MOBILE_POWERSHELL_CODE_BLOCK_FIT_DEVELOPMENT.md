# 移动端 PowerShell 代码块自适应开发记录

## 目标

让手机和电脑网页版中的 PowerShell 等代码块都受聊天消息列宽约束，避免长命令撑宽聊天内容或被页面边缘裁切；手机端自动折行，电脑端保留代码块内部横向滚动。

## 根因

聊天代码块 `.chat-message__code` 使用 `white-space: pre`，会保留每一行原始宽度且禁止自动折行。窄屏下虽然代码块自身可横向滚动，但长 PowerShell 命令无法完整呈现在当前屏幕内；桌面端代码块自身已有宽度限制，但消息内容容器未明确限制 `min-width`/`max-width`，超长不可折行内容仍可参与上层固有宽度计算，把聊天列撑出页面。

## 实施步骤

1. 只在窄屏媒体查询下将代码块切换为保留空格与换行的自动折行模式。
2. 对极长且没有可折分隔符的命令启用任意位置软换行，并将代码块盒子限制在消息内容宽度内。
3. 桌面端保留 `white-space: pre` 与代码块内部横向滚动。
4. 将聊天正文和活动时间线限制在消息列宽内，让桌面端长命令只扩大代码块的内部滚动宽度，不影响消息流或页面宽度。
5. 增加移动/桌面代码块样式回归测试，更新版本记录，运行测试与网页生产构建并提交本地 Git；不推送远端。

## 验收标准

- 手机窄屏上的 PowerShell 长命令在代码框内部自动折行，不撑宽消息流或被屏幕边缘裁切。
- 原始换行、缩进和复制出的命令内容保持不变。
- 桌面端长代码仍可在代码块内横向查看。
- 桌面端超长 PowerShell 单行不会再把消息正文或聊天页面撑出可视区域。
- 项目测试、`pnpm build` 和 `git diff --check` 通过。
