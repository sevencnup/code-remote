# 移动端 PowerShell 代码块自适应开发记录

## 目标

让手机网页版中的 PowerShell 等代码块适应屏幕宽度，避免长命令只能显示半截；桌面端继续保留原来的横向滚动体验。

## 根因

聊天代码块 `.chat-message__code` 使用 `white-space: pre`，会保留每一行原始宽度且禁止自动折行。窄屏下虽然代码块自身可横向滚动，但长 PowerShell 命令无法完整呈现在当前屏幕内。

## 实施步骤

1. 只在窄屏媒体查询下将代码块切换为保留空格与换行的自动折行模式。
2. 对极长且没有可折分隔符的命令启用任意位置软换行，并将代码块盒子限制在消息内容宽度内。
3. 桌面端保留 `white-space: pre` 与代码块内部横向滚动。
4. 增加移动/桌面代码块样式回归测试，更新版本记录，运行测试与网页生产构建并提交本地 Git；不推送远端。

## 验收标准

- 手机窄屏上的 PowerShell 长命令在代码框内部自动折行，不撑宽消息流或被屏幕边缘裁切。
- 原始换行、缩进和复制出的命令内容保持不变。
- 桌面端长代码仍可在代码块内横向查看。
- 项目测试、`pnpm build` 和 `git diff --check` 通过。
