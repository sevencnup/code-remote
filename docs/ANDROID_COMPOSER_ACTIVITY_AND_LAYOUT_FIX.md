# Android 回复活动与输入区布局修复

## 目标

原生 Android 回复时显示可用的具体操作和文件名，去掉“正在运行中”前缀；运行中的文件更改摘要以无边框文本置于输入区上方；排队消息置于输入框玻璃容器内部。适度提高回复呼吸动效的可见度。

## 分类与版本

修复 / PATCH：这些状态、文件摘要和排队操作已有，只修正呈现与位置。目标内部测试版本 `0.28.1-dev.4`，Android `versionCode 238`。

## 步骤

1. 核对原生运行状态的数据来源和网页状态行，优先显示当前操作；没有当前操作时显示本轮最近的具体活动，并在没有文件活动时保持普通思考提示。
2. 移除运行提示中的“正在运行中”字样，使文件名或命令摘要在回复期间可见且不会显示上一轮的内容。
3. 将排队消息标题与列表移入输入框容器；将运行中的文件摘要保留在输入框外侧、排队区上方，并去掉摘要边框和底色。
4. 调整原生呼吸动效对比度；递增版本与安装包编号，记录简短更新描述。
5. 构建独立命名的 APK，安装到当前连接的手机并核对版本及实际页面布局；完成本地提交。

## 验收

- 回复时不再出现“正在运行中”；有文件活动时可看到对应文件名，没有文件活动时不捏造文件名。
- 文件摘要为页面文字层，位于排队消息上方；排队消息位于输入框玻璃容器内部，展开操作仍可用。
- 回复时输入框内部可见轻微呼吸变化，空闲时不发光，外侧无额外阴影。
- 新 APK 不覆盖历史安装包；手机安装版本为 `0.28.1-dev.4` / `versionCode 238`。

## 实施记录

- 原生回复状态读取当前轮次的实时操作事件，显示文件名和最近完成的操作；轮次或聊天切换时清理实时状态。
- 文件摘要使用页面文字层，排队消息移入输入框；提高输入框内部呼吸动效的可见度。
- 版本更新为 `0.28.1-dev.4` / `versionCode 238`。
