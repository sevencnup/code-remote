# 移除 AI 群聊开发记录

## 目标

移除 Codex Remote 网页中的 AI 群聊功能，因为现有群聊体验无法满足使用需求。

## 分类与版本

- 分类：不兼容变更。移除现有的 AI 群聊能力；项目仍处于 `0.x`，中版本递增至 `0.62.0-dev.1`。
- 版本记录：`移除 AI 群聊功能`。

## 范围

1. 移除侧边栏群聊入口、群聊创建/加入/退出/重命名/解散菜单及相关对话框。
2. 移除群聊聊天视图、群消息同步与路由逻辑、群聊专用存储代码和群聊专用测试。
3. 移除群聊专属样式及其主题/移动端适配。
4. 保留 Codex 与 Claude 的普通单聊、并发窗口、聊天管理菜单和普通侧边栏分组。
5. 不主动清理浏览器中已有的群聊 localStorage 数据，也不修改或删除原始 Codex/Claude 聊天记录。
6. 保留历史开发文档及已发布版本的 changelog 条目。

## 执行步骤

1. 从主页面移除群聊状态、事件处理、侧边栏入口、菜单、对话框和群聊视图挂载。
2. 删除群聊组件、群聊类型/存储/路由/同步模块、专用测试及样式。
3. 搜索残留引用并清理因移除产生的无用导入或逻辑，同时确认普通并发单聊和侧边栏分组代码仍在。
4. 更新版本号与 changelog。
5. 运行前端构建和 `git diff --check`；不执行测试套件。
6. 仅暂存本次改动并创建本地提交，不推送到 GitHub。
