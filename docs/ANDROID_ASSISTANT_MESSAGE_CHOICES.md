# Android 助手消息快速选择

## 目标与分类

网页版会把助手回复末尾的文字选择题呈现为可点选的“快速选择”。Android 目前只显示原文，无法直接点选。用户补充要求：AI 提问后等待回答；既能选现成答案，也能在题目下输入其他答案；确认后直接发送到当前聊天，AI 接着回答。新增 APP 内的完整回答能力，归类为新增功能 / MINOR。先前只填入主输入框的 `0.76.0-dev.1` 包已生成但未安装，保留该包；最终目标版本 `0.76.0-dev.2`，Android `versionCode 358`。

## 实施步骤

1. 对照网页版的题目解析、启用条件和答案格式，核对 Android 当前聊天的正常发送流程。
2. 在 Android 中解析助手最后一条已完成回复末尾的选择题，跳过代码块与非结尾列表。
3. 在消息下方显示每题选项和“其他答案”输入框；每题选择一个现成答案或输入其他答案，全部完成后点“发送并继续”，在当前聊天提交答案，保留主输入框草稿。
4. 处理刷新重绘、发送中、发送失败和排队消息编辑状态；更新版本与更新记录，构建并安装独立 APK。
5. 核对改动并仅提交到本地 Git。

## 验收

- Codex 与 Claude Code 回复中的多组选项均可逐题点选；普通列表不出现选择按钮。
- 选项与自定义答案互斥生效；点“发送并继续”发送到当前聊天，不清空主输入框草稿，失败可重试。
- 回复未完成和历史消息中不显示可用的选择入口。
- 对普通已完成的文字提问，发送答案会开始同一聊天的下一轮回复；真正暂停在工具调用中的结构化提问需要单独的服务端协议支持。
