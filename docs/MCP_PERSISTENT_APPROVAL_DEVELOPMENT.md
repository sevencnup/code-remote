# MCP 工具持久授权开发文档

本次让用户可以保存此前只能逐次确认的 MCP 工具授权，属于**新增功能 / MINOR**，目标版本 `0.82.0-dev.1`。

## 用户行为

- MCP 工具弹窗保留「允许一次」，增加「此工具始终允许」和「该 MCP 服务器始终允许」。前者仅匹配同一 MCP 服务器与同一工具，后者匹配该 MCP 服务器的所有工具；均跨对话和服务重启生效。
- 设置页展示已保存的授权并支持逐条撤销。撤销后，下一次匹配的调用重新弹窗。
- SSH 服务器自身的启用状态、检查和命令权限继续由 SSH MCP 执行时检查；持久授权只省去 Codex 发出的 MCP 工具调用确认。

## 范围与安全边界

- 仅对 `mcpServer/elicitation/request` 中可严格识别为“允许某 MCP 服务器运行某工具”的空表单调用确认提供持久授权。其他 MCP 表单、验证请求和普通 Codex 审批继续逐次处理。
- 服务端从原始请求独立识别服务器与工具，不能信任浏览器提交的名称。无法识别时不显示持久授权按钮，也不自动放行。
- 授权保存在 Code Remote 服务端的用户数据目录，文件权限限制为服务账户，写入使用原子替换。所有已配对设备共享同一份规则。

## 实施步骤

1. 实现持久授权存储、严格的 MCP 工具请求识别与匹配。
2. 在 Codex App Server 请求入口应用已保存的规则；手工同意时按选择保存工具级或服务器级规则，并按原协议答复。
3. 将可用授权范围随弹窗事件发送给网页，增加三种允许操作；设置页加入已保存规则的读取与撤销。
4. 更新版本与简短更新记录，完成编译检查、本地提交；不推送 GitHub。
