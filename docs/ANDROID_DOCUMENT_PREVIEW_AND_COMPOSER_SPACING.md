# Android 文档附件预览与输入框底部间距

## 目标与分类

Android 聊天里的内嵌文本文档卡片目前不能打开；输入框与屏幕底部之间的空白也偏大。本次新增点击文档卡片查看 Markdown 正文的能力，并收紧输入框外层的底部留白。

文档预览属于新增功能 / MINOR：用户此前无法在 App 中打开聊天引用的文档，现在可以在 App 内阅读。目标版本 `0.50.0-dev.1`，Android `versionCode 309`。

## 实施步骤

1. 在文档附件解析结果中保留正文，并让历史消息和临时消息中的附件卡片都能打开预览。
2. 使用现有 Markdown 渲染组件显示标题、列表、代码、表格和链接；预览面板支持滚动和关闭。
3. 缩小输入框外层的底部空白，不改变系统导航栏和键盘 inset。
4. 更新版本、变更记录与本开发记录，构建独立 APK，安装到手机核对文档预览和底部布局。
5. 执行 `git diff --check` 并创建本地提交，不推送 GitHub。

## 验收标准

- 点击已引用的 Markdown 文档卡片后，App 内打开可滚动的渲染预览。
- 长文档可阅读，关闭预览返回原聊天位置。
- 输入框整体更靠近底部，但不被系统导航栏遮挡。
- APK 构建和手机安装成功，原有聊天及草稿保留。
