# 移动端聊天内容横向溢出修复

## 目标与分类

修复手机聊天中长代码块把消息布局撑出屏幕、右侧内容被裁掉的问题。本次恢复已有聊天内容在窄屏下的正常显示，属于 PATCH，目标版本为 `0.14.1-dev.2`。

## 根因判断

- 消息正文和代码块没有显式的最大宽度约束；代码块虽然设置了 `overflow: auto`，但长行的固有宽度仍可能参与上层消息布局的尺寸计算。远程分支已有的移动端适配还让 PowerShell 等长命令自动换行。
- 现有消息滚动区会裁切横向溢出，因此代码块扩宽时，屏幕只显示其左侧，右边内容落在视口之外。

## 实施步骤

1. 限制消息正文的最小宽度和最大宽度，避免长内容撑开消息列。
2. 将聊天代码块约束在父消息正文宽度内；移动端自动折行，桌面端保留代码块内部横向滚动。
3. 更新补丁版本与简短版本记录；不改 Android 原生代码，不生成安装包，保持 `versionCode`。
4. 检查差异并创建本地提交；不运行测试，不推送 GitHub。保留已有的 `docs/ANDROID_APK_DEVELOPMENT.md` 修改。

## 验收标准

- 手机聊天页面本身没有由代码块引起的横向溢出。
- 移动端长代码自动折行；桌面端长代码仍可在代码块内横向滚动，复制按钮保持可见和可用。
- 普通文本、用户消息、桌面布局不受影响。

## 实施结果

- 消息正文增加 `min-width: 0` 和 `max-width: 100%`；代码块限制为父级宽度。移动端长代码自动折行，桌面端保留内部滚动。
- `pnpm build` 成功；本机 4173 预览返回 HTTP 200，页面引用的新 CSS 也返回 HTTP 200，且包含宽度约束规则。
- 未运行测试；尚未拿到手机实机截图进行目视验收。
