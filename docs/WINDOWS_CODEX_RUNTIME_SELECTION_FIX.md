# Windows Codex 运行时选择修复

## 问题

Windows 启动环境可能继承指向 `.codex/.sandbox-bin/codex.exe` 的 `CODEX_REMOTE_COMMAND`。该内部缓存不一定包含沙箱安装辅助程序，导致手动审批模式在执行命令前失败。审批策略拒绝与辅助程序缺失是两个不同问题。

## 实施步骤

1. 后端识别内部 `.sandbox-bin` 可执行文件，优先解析 PATH 中正式安装的 npm CLI，再尝试现有托管安装路径。
2. 自动发现时跳过内部缓存；保留其他显式配置的可执行文件。没有完整安装入口时返回可操作的错误，不自动更改审批或沙箱权限。
3. 检查差异、记录版本并仅提交本地修改；运行中的会话需在后端重新启动后使用新运行时。

## 验证范围

已定位本机内部缓存缺少 `codex-windows-sandbox-setup.exe`，而 npm 平台包包含该文件。此次不以真实命令触发审批，也不把自动审批策略拒绝视为运行时修复已解决。
