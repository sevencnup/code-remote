# Android 侧边栏定时消息标记

## 目标

同步网页端侧边栏行为：聊天存在定时消息时，在 Android 聊天标题旁显示时钟图标。

## 分类与版本

- 分类：修复 / PATCH。为已有的定时发送功能补齐跨页面可见状态。
- 开发前 package 版本：`0.78.4-dev.1`。
- 开发前 Android 版本：`0.78.3-dev.1`，`versionCode 370`。
- 目标版本：`0.78.4-dev.2`，`versionCode 371`。
- 版本记录：`在 Android 侧边栏标记有定时发送的对话`。

## 实现步骤

1. 通过已有 `/api/v1/codex/queue/scheduled-thread-ids` 接口同步有待发送定时消息的会话 ID。
2. 在会话列表标题行添加时钟图标，并使用现有主题配色与可访问性描述。
3. 在首次加载、所有队列更新、后台恢复和定期会话刷新时更新标记；切换连接时清除旧连接标记。
4. 更新版本记录，检查差异并构建独立 APK；本地提交，不推送 GitHub。

## 范围

定时消息队列和服务端接口已经存在，本次只同步侧边栏指示状态，不发送测试消息，也不改网页端。

## 完成记录

- 使用服务端定时会话接口同步图标状态，复用现有主题适配的定时图标。
- 活跃聊天的远端队列变化也会刷新标记，避免只响应本机队列操作。
- 构建：`./gradlew assembleDebug` 成功；APK 位于 `android/app/build/outputs/apk/debug/code-remote-android-0.78.4-dev.2-debug.apk`。
- 安装：本次请求未要求安装。
