# 网页刷新入口与旧经典文件菜单布局开发文档

## 目标

1. 将聊天记录刷新按钮从左侧栏移到当前聊天页面顶部的水平中心位置，对齐图一所示的页面中心区域；刷新行为保持不变。
2. 重组旧经典主题右侧文件树的右键菜单，将快捷操作、创建操作、文件操作和删除操作分组排布，解决菜单内容拥挤、可读性差及贴近视口边缘时被裁切的问题。

## 范围

- 刷新入口显示在当前选中的聊天窗格，多个聊天窗格中只显示一个。
- 旧经典主题下调整文件树右键菜单；其他主题的菜单外观和文件操作行为保持原样。
- 菜单操作继续使用现有处理函数，不改变绑定目录、插入路径、创建、复制、剪切、粘贴、重命名和删除的语义。
- 本次属于 PATCH 布局与操作便利性调整，版本更新为 `0.37.0-dev.4`；Android `versionCode` 保持不变，不生成安装包。

## 实施步骤

1. 将聊天记录刷新按钮移入当前聊天窗格的顶部栏，并用绝对居中的位置布局；移除侧栏原入口，保留可访问标签、忙碌/交还状态禁用逻辑和刷新回调。
2. 为文件树右键菜单增加语义分组：目录快捷操作、创建、文件管理和危险操作；保留动态显示条件和既有回调。
3. 仅为旧经典主题设置明确的菜单宽度、视口内坐标约束、分组网格、按钮层级与文字对比度；不覆盖文本选择菜单。
4. 更新 Web 与 Android `versionName`、`CHANGELOG.md` 和本开发记录。
5. 运行生产构建和差异检查，创建只包含本次改动的本地提交；不运行测试、不推送远端、不生成 APK。

## 验收标准

- 当前聊天页面顶部中心显示一个刷新聊天记录按钮；点击效果与原侧栏按钮相同，切换窗格不会产生重复入口。
- 旧经典主题的文件树右键菜单分组清楚、文字可辨，并在窄视口和屏幕边缘内完整显示。
- 文件和目录、单选与多选场景的已有操作仍根据原条件出现；其他主题和代码选区菜单不受影响。
- 生产构建与差异检查通过。

## 完成记录
