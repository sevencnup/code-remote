# Android 实时计时小时格式修复

## 分类与版本

- 类型：修复 / PATCH。实时计时已有耗时展示，但超过一小时仍以分钟累计，与网页版格式不一致。
- 目标版本：`0.56.4-dev.6`，Android `versionCode 322`。
- 更新记录：修复 Android 实时计时超过一小时仍显示累计分钟。

## 实施步骤

1. Android 实时计时器复用已有的 `formatTurnDuration`，并保持中英文单位与应用语言一致。
2. 更新版本号、更新记录和本开发记录。
3. 构建新的 Android Debug APK，不覆盖历史安装包；不运行独立测试套件。
4. 检查变更并创建本地提交，不推送 GitHub。

## 实施结果

- 实时计时改为复用 Android 已完成回复耗时使用的格式化函数，精确一小时显示 `1小时0分0秒`；英文界面显示 `Elapsed 1h 0m 0s`。
- `./gradlew :app:assembleDebug` 构建成功；未运行独立测试套件。
- APK：`artifacts/codex-remote-android-0.56.4-dev.6-debug.apk`，SHA-256：`40478420cfb81fd53166b3e1c584444fe3aea0017db29d1caac1738fab7239af`。
- 当前环境没有 `adb` 命令，无法安装或进行实机验收。

## 验收标准

- 59 分钟仍显示分钟；正好 60 分钟显示 `1小时0分0秒`；超过 60 分钟按小时、剩余分钟和秒显示。
- 英文界面使用 `h / m / s` 单位。
- APK 编译成功；设备无法连接时明确记录未完成实机验收。
