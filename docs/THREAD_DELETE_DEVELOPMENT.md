# 聊天删除功能开发文档

## 目标

在左侧对话列表的右键菜单中提供“删除聊天”，让用户可以删除不再需要的本地 Codex 对话，并让电脑端与移动端及时同步列表变化。

## 行为与边界

- 删除入口放在右键菜单底部，使用明确的危险操作样式。
- 点击删除后显示二次确认，确认框展示聊天名称并说明删除后无法恢复。
- 正在回复或正在启动回复的聊天不能删除，服务端返回明确提示；空闲且当前打开的聊天允许删除，删除后关闭对应聊天内容。
- 删除使用 Codex App Server 原生 `thread/delete`，不自行猜测或拼接会话文件路径。
- 删除成功后清理该聊天的排队消息、送达记录、恢复屏障、置顶状态和目录绑定，并通知所有已配对页面刷新聊天列表。

## 实施步骤

1. 在 App Server 适配层增加按聊天编号删除的方法，并拒绝删除仍在运行的聊天。
2. 增加后端 `DELETE /api/v1/codex/threads/{thread_id}` 接口，完成共享状态清理和跨设备通知。
3. 在网页客户端和会话状态 Hook 中增加删除请求及本地缓存清理。
4. 在左侧聊天右键菜单加入删除入口与二次确认框，处理当前聊天和并发窗口关闭后的页面状态。
5. 补充深浅色及自定义主题下的危险操作样式。
6. 将内部测试版本更新为 `0.2.0-dev.1`，执行生产构建并创建本地 Git 提交，不推送到 GitHub。

## 验收标准

- 桌面端右键和移动端长按聊天均能看到“删除聊天”。
- 未确认时不会删除；确认后聊天从所有已连接页面的列表中消失。
- 删除当前空闲聊天后页面回到可继续使用的新对话状态，其它并发窗口不受影响。
- 正在回复的聊天删除失败并保留原聊天及内容。
- 删除后不残留置顶、目录绑定或排队消息状态。
