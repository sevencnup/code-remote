# 明暗主题全局文字对比度开发记录

## 目标

白色主题中的中性界面文字统一为纯黑，黑色主题中的中性界面文字统一为纯白，减少侧栏、聊天、文件区、队列和设置页中低对比度的灰色文字。

## 实施范围

1. 在明暗主题根节点统一覆盖常见界面文字元素和输入占位文字。
2. 将回复活动提示改为随主题显示的纯黑或纯白文字。
3. 保留代码语法高亮、文件增删行颜色以及深色背景按钮的反白文字；差异代码中未单独着色的片段继承黑白主题文字色。
4. 逐项核对右键菜单、编辑器、输入框、折叠/关闭按钮、排队确认、附件、审批/提示卡片、设置控件及弹层的背景与文字配色，避免黑字落在深色表面或白字落在浅色表面。
5. 为白色主题补齐浅色表面；同步检查黑色主题的主要操作按钮，保留代码高亮、状态提示与增删行的语义色。
6. 更新版本记录，检查 CSS 差异并完成本地 Git 提交；不推送 GitHub。
