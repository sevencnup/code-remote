# Android 原生页面安全区与触控修复

## 目标

修复 Android 原生聊天页面顶部工具栏被系统状态栏挤压、底部输入区贴近手势导航区，以及侧栏和输入区控件难以点击的问题。继续使用原生 `EditText` 与系统输入法。

## 分类与版本

本次属于 PATCH：修复现有页面控件无法稳定点击及系统栏布局异常，不改变用户可完成的任务。目标版本为 `0.18.1-dev.4`，Android `versionCode` 为 `135`。

## 实施步骤

1. 在 Android 15+ edge-to-edge 布局中显式处理状态栏、导航栏、刘海和 IME insets；系统栏背景继续跟随应用主题。
2. 压缩顶部工具栏，扩大菜单、模型、思考、权限等按钮的有效点击区域，并略微抬高底部输入区。
3. 为聊天页增加从左侧边缘滑动打开侧栏、侧栏内向左滑动关闭的手势，并保留菜单按钮和遮罩关闭方式。
4. 增加针对 Insets 计算与触控手势的可重复检查；构建独立命名的新 APK，不覆盖既有安装包。
5. 在已连接设备上使用隔离的测试包验证页面和输入区交互；确认后再覆盖安装正式包并复测。
6. 更新 Android 版本记录，检查差异并创建仅包含本次改动的本地提交，不推送 GitHub。

## 验收标准

- 顶部工具栏完整避开状态栏，整体高度比当前版本更紧凑。
- 点击聊天输入框能稳定调起原生输入法；键盘显示和收起时，输入区跟随 IME 且不被底部系统栏遮挡。
- 菜单、模型、思考、权限、发送、附件控件均可点击；边缘滑动可以打开/关闭侧栏。
- 新 APK 使用 `0.18.1-dev.4` 和独立文件名；旧 APK 保留；覆盖安装不清除配对信息。

## 验证结果

- `./gradlew assembleDebug` 构建成功；APK 为 `versionCode 135`、`0.18.1-dev.4`。
- Android 16 实机的隔离界面验证确认状态栏和手势导航区域有安全留白；原生输入框可获得焦点，键盘弹出后输入区仍可见。
- 隔离界面中模型菜单可打开并选择；UI 树确认侧栏、附件、模型、思考、权限和发送控件都有有效点击区域。测试没有发送消息或改动正式聊天。
- 覆盖安装后，正式界面启动并载入原有聊天；安装版本核对为 `0.18.1-dev.4`，旧安装包仍保留。
