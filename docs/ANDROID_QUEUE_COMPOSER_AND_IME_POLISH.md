# Android 排队编辑、附件提示与键盘动画修复

## 需求

1. 添加图片或文件成功后不再弹出成功提示；普通消息进入排队后不再弹出“已加入排队”。失败仍提示原因。
2. 排队编辑时右下角始终显示打勾确认，不能因回复状态刷新而变成暂停按钮。
3. 展开排队消息时直接看到图片缩略图，无需先进入输入框编辑。
4. 键盘升起时减少消息列表每帧滚动造成的停顿，保留聊天内容跟随可见区域的效果。

## 开发步骤

1. 统一计算发送按钮状态，让排队编辑优先于回复中的暂停状态；统一点击行为与文字说明。
2. 删除两处成功 Toast，保留附件读取及发送失败提示。
3. 对排队消息中的图片异步解码缩略图并复用现有图片缓存，控制主线程开销。
4. 调整输入法动画期间的滚动跟随频率，只在打开与结束阶段定位到底部。
5. 递增 Android 测试版本，构建独立 APK 并安装到设备。

分类：PATCH / 修复已有排队编辑、预览与输入法体验。
