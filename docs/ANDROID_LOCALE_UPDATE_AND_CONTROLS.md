# Android 侧栏、排队操作、语言与回复控制

## 目标

修正侧栏底部按钮换行、键盘打开时侧栏仍可拉出、排队消息按钮难辨认的问题；增加中英文语言切换和检查更新；让主动停止回复后保留清楚的继续入口。语音转文字先评估现有输入法能力，不在本次重复接入录音服务。

## 开发步骤

1. 压缩侧栏底部按钮的图标与文字间距，保证“切换配置”单行显示。
2. 为排队消息的修改、立即发送、删除使用独立图标资源，不更改其它位置的全局图标；确认三个动作的图标语义。
3. 保留键盘显示时的侧栏侧滑手势；侧栏打开时主动收起键盘并移开输入焦点，顶部菜单按钮同样处理。
4. 在设置页增加中文、英文选项，保存选择并重绘界面；翻译 Android APP 的用户可见文案，保留用户输入、聊天正文、文件内容和模型名原文。
5. 在设置页增加检查更新入口，查询项目公开发布信息，比较版本并明确提示“新版本”“当前已是最新”或“尚无可检查的发布”；不自动下载安装。
6. 核对 Codex 和 Claude Code 的暂停能力；如果只有中断接口，不把中断伪称为可原样恢复的暂停。提供独立停止及一键继续入口，继续动作明确作为新消息发送。
7. 更新版本与版本记录，构建独立 APK，安装到当前 ADB 设备并本地提交。

## 分类

MINOR：中英文界面与检查更新是新增能力，其余为已有交互修复。

## 注意

目前服务端只有 `turn/interrupt` / Claude 中断能力，没有保留同一轮生成状态的暂停和恢复接口；“继续”只能创建后续请求，不能恢复被停止的生成进程。
