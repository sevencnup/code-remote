# Android 启动页透明 Logo 调整

## 问题与目标

上一版为了让启动图标边界可见，使用了浅冷灰启动背景和白色自适应图标底板。实际效果会形成明显的圆角方块，用户希望启动页只显示 Logo 本体。

目标是去掉可见的圆角底板，恢复纯白启动页，同时继续使用启动页专用安全边距，避免 Logo 被系统蒙版裁切。

## 分类与版本

- 分类：修复 / PATCH。只调整启动页视觉呈现，不改变应用能力或操作方式。
- 目标版本：`0.90.6-dev.1`，Android `versionCode 388`。
- 本次属于小幅视觉调整，不单独增加 `CHANGELOG.md` 条目。

## 实施步骤

1. 启动页直接使用带安全边距的透明 Logo 前景，不再使用自适应图标白色底板。
2. 将系统启动图标背景设为透明，启动页背景恢复纯白。
3. 删除不再使用的启动页自适应图标资源。
4. 更新版本、构建独立 APK、覆盖安装到手机并本地提交。

## 验收标准

- 启动页只显示 Logo，不出现白色圆角方块。
- Logo 四周完整，不贴近系统裁切范围。
- 桌面图标保持不变。
- 新 APK 不覆盖历史产物。

## 完成记录

- Android 12+ 启动页改为纯白背景，并直接显示带 21dp 安全边距的透明 Logo 前景。
- 启动图标背景设为透明，已删除不再使用的启动页自适应图标资源；桌面图标未修改。
- Android 构建成功，产物为 `artifacts/code-remote-android-0.90.6-dev.1-debug.apk`。
- 新版本已覆盖安装到手机，设备报告 `versionCode 388`；历史 APK 未覆盖。
