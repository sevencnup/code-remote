# 侧栏对话右键操作开发记录

## 目标

为左侧对话列表的右键菜单增加置顶、导出和引用功能，并调整菜单顺序。

## 交互与约束

- 菜单顺序固定为：并发、置顶、导出、引用、重命名；移除“切换到此对话”。
- 置顶在当前浏览器保存，对话列表按置顶状态优先，再按原有更新时间排序；菜单文本随状态显示“置顶”或“取消置顶”。
- 导出将目标对话完整整理为 UTF-8 Markdown 文件并下载，包含标题、对话 ID、工作目录、时间和用户/Codex 消息；不上传任何内容。
- 引用读取目标对话的完整历史并整理为 Markdown 文档附件，添加到当前正在查看的聊天输入框；不自动发送，也不替换已有草稿或附件。
- 引用内容复用现有文档附件限制；超过单个附件可承载的内容时，保留开头与结尾并明确写出已截断。
- 保留已有并发打开、重命名、对话历史缓存和跨设备同步行为。

## 实施步骤

1. 增加可复用的对话 Markdown 整理函数，并为导出与引用统一使用。
2. 增加浏览器本地置顶状态存储、排序和右键菜单状态。
3. 将完整对话引用接入 Composer 既有文档附件入口，并添加加载/失败反馈。
4. 调整右键菜单项目、图标、禁用状态和样式。
5. 添加必要的纯函数测试，运行测试、生产构建和差异检查。
6. 更新版本记录并创建本地 Git 提交；只有收到明确命令后才推送 GitHub。

## 验收标准

- 右键菜单只显示并发、置顶、导出、引用、重命名，且顺序正确。
- 置顶状态刷新页面后仍保留，置顶会话始终排在普通会话前面。
- 导出的 Markdown 含有完整可读对话内容。
- 引用后当前输入框出现可辨认的对话 Markdown 附件，用户可补充提问后按原有发送流程交给 Codex。

## 实施结果

- 已完成置顶本地存储、列表排序和图钉状态标识。
- 已完成完整对话 Markdown 导出，以及将历史作为 Markdown 附件引用到当前输入框。
- 已为对话整理、文件名清洗和长内容截断补充纯函数测试。
- 已通过完整测试、生产构建和差异格式检查。
