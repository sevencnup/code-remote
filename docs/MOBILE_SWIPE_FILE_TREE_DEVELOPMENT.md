# 移动端侧滑打开文件树开发记录

## 目标

保留现有左侧对话栏的开关手势，并让右侧文件树也支持按住跟手拖动、松手吸附开关。以聊天页面水平中线划分左右手势区，手势目标在触摸开始时锁定。

## 交互约束

- 页面左半区只操作左侧栏：关闭时右滑打开，打开时左滑关闭。
- 页面右半区只操作文件树：关闭时左滑打开，打开时右滑关闭。
- 手势目标按触摸起点所在半区锁定；滑动越过中线也不能改变目标。
- 左侧栏打开时，右半区手势不打开文件树；文件树打开时，左半区手势不打开左侧栏。
- 两个面板互斥打开；打开其中一个时先关闭另一个。
- 移动端文件树从右侧以全高抽屉形式滑入，不使用居中弹窗。
- 文件树抽屉打开和关闭时都应跟随手指水平位移；松手后按当前展开比例或手势方向吸附到打开/关闭状态。
- 文件树拖动时遮罩按可见比例渐变，最大不透明度保持轻薄（20%）；取消触摸时恢复拖动开始前的状态。
- 松手吸附时必须保留最后一帧的抽屉偏移和遮罩透明度，再进入目标状态的过渡；不得先恢复默认遮罩造成页面闪烁。
- 输入框、独立操作按钮、代码块、文件预览对话框和设置/菜单弹层不参与面板切换手势；对话列表和文件树列表行允许作为关闭手势起点，成功滑动时取消行点击。
- 仅在单指、水平位移超过阈值且明显大于纵向位移时触发，纵向滚动不改变面板。

## 实施步骤

1. 将全局手势起点记录改为带左右半区的状态，并在触摸开始时根据聊天页面中线锁定目标区。
2. 为右侧文件树增加独立拖动偏移和吸附判断；打开面板内部的非交互区域可向右拖回，关闭面板可从右半区向左拖入。
3. 抽取纯方向判定和拖动几何函数，确保每个半区只改变对应面板，且两面板不会因手势同时打开。
4. 增加左右面板拖动偏移、吸附方向、遮罩比例、阈值和纵向滚动的单元测试。
5. 更新版本记录，运行前端测试、构建和差异检查，并创建本地提交；不推送 GitHub。
6. 回归检查拖动后松手关闭、拖动后回弹打开两条路径，确保遮罩变量在吸附动画启用后再清理。

## 验收标准

- 左半区右滑打开左侧栏，左滑关闭左侧栏。
- 右半区左滑打开文件树，右滑关闭文件树。
- 跨越中线的手势仍只影响触摸起点所在半区对应的面板。
- 任一面板打开时，另一半区的手势不会打开另一个面板。
- 文件树从关闭状态拖入时抽屉随手指从右侧进入；从已打开状态拖出时抽屉随手指向右退出。
- 文件树松手后根据手势方向或展开比例吸附；取消触摸时恢复原来的开关状态。
- 文件树松手收回或回弹时画面连续，不出现遮罩突然变深或页面闪白/闪黑。
- 纵向滚动、短距离滑动及控件/代码区域手势不误触面板切换。
