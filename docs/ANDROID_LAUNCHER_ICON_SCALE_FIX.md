# Android 桌面图标比例修复

## 问题与目标

Android 清单当前把带透明区域的普通图片直接作为桌面图标。系统会把这种旧式图标再次缩进并包进启动器底板，导致 Code Remote 标识在桌面图标内部显得偏小。

目标是改用项目已有的 Android 自适应图标，并放大前景标识，同时保留足够的安全边距，避免不同启动器裁切标识。

## 分类与版本

- 分类：修复 / PATCH。桌面入口和使用方式不变，仅修正应用图标的显示比例。
- 目标版本：`0.89.1-dev.2`，Android `versionCode 378`。
- 这是小幅视觉调整，不单独写入 `CHANGELOG.md`。

## 实施步骤

1. 将应用清单的普通图片图标切换为 Android 自适应图标资源。
2. 使用 Android 自适应图标的 18dp 标准安全边距，使标识不再被旧式图标二次缩小，同时避免触碰圆形、圆角方形蒙版边界。
3. 使用白色自适应图标底板，保持标识原有蓝绿色对比度。
4. 更新 Android 与项目版本，构建独立 APK，并仅提交本次修改到本地 Git。

## 验收标准

- Android 桌面不再把普通透明图片额外缩小包装。
- 内部 Code Remote 标识比上一版明显更大，常见启动器形状下不裁切主体。
- 新 APK 文件名和版本号不覆盖历史包。

## 完成记录

- 应用清单已改用 `@mipmap/ic_launcher` 自适应图标，启动器不再把透明 PNG 当旧式图标重复包装。
- 首次校准使用 12dp 缩进，真机显示过大并贴近蒙版边缘；最终恢复 18dp 标准安全边距，仅移除旧式图标的额外系统缩放。
- 自适应底板改为白色，Android 最终产物为 `artifacts/code-remote-android-0.89.1-dev.2-debug.apk`。
- `0.89.1-dev.1` 校准包作为历史产物保留，不覆盖旧 APK。
- 最终校正版已覆盖安装到手机，设备报告 `versionCode 378`。
