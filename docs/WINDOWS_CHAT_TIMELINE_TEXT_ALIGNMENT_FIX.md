# Windows 网页聊天文字与操作记录错位修复

## 用户可见变化与版本

- 分类：修复 / PATCH。已有回复文字应完整显示；修复操作记录误插入句子中间的问题，不改变聊天能力。
- 目标版本：`0.86.4-dev.1`。

## 问题与原因

Windows 截图中，“连续操作”卡片插在“兼容模式”等词中间。网页依据活动时间线保存的各消息段长度切分整条助手回复；当流式记录、缓存或历史快照中的长度与当前正文不一致时，仍按旧长度切分，剩余正文再作为尾段显示。字体只影响软换行，不会让操作卡片插进词中。

## 实施步骤

1. [x] 切分前检查消息段 ID、长度和段间分隔符是否与当前正文一致。
2. [x] 不一致时完整显示正文，并把操作记录合并放在正文后面；一致时保留原有交错顺序。
3. [x] 更新网页版本和版本记录；检查修改范围，不新增或运行测试。
4. [x] 仅提交本次改动到本地仓库，不推送远端。

## 验收范围

- Windows 历史回复中的词句不再被“连续操作”卡片拆开。
- 对齐的聊天仍按正文与操作的原始顺序显示，操作详情可展开。
- Linux 和 Windows 使用相同的网页修复；Windows 端需更新网页代码后生效。
