# Android 终端直接输入

## 目标与分类

移除 Android 终端底部独立的命令草稿框和发送按钮。用户点终端输出区域调出系统键盘后，按键直接发送到当前 PTY，让命令行与交互式程序都能使用。文件树的“加入终端”操作继续只预填目录切换命令，不自动执行。

本次属于新增功能 / MINOR：移动端终端从“整行发送命令”扩展到逐字交互。最终版本为 `0.62.0-dev.2`，Android `versionCode 326`。

## 实施步骤

1. 为终端增加不显示在界面上的 Android 输入目标，转发输入法提交的文字、回车、退格、方向键和常用控制键到 PTY。
2. 点击终端显示区域或“键盘”按钮时打开系统键盘；移除独立输入框和发送按钮，保留终端方向键、控制键及复制到聊天输入框操作。
3. 将文件树“加入终端”的目录命令改为发送到 PTY 提示符，不附带回车。
4. 更新 Android 版本与简短版本记录，构建新的 APK，安装并检查终端界面和键盘焦点；不覆盖历史 APK。
5. 检查差异并创建只含本次修改的本地提交，不推送 GitHub、不运行测试套件。

## 验收标准

- 终端界面没有单独的命令输入框和“发送”按钮。
- 点终端显示区域或“键盘”按钮可唤起键盘；输入字符会直接送入 PTY，回车、退格及控制键按终端按键处理。
- 返回键先收起终端键盘，再关闭终端；关闭终端时键盘正确隐藏。
- “加入终端”命令显示在 shell 提示符中，未按回车前不执行。
