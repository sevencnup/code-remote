# 网页文件更改卡片吸顶控件

## 目标

展开网页聊天中的文件更改卡片后，卡片顶部信息与底部展开/收起控制条在滚动浏览差异时保持可见。

## 步骤

1. 核对文件更改卡片的展开结构、聊天滚动容器及已有顶部吸顶规则。
2. 为展开态的底部控制条增加底部吸顶，并检查它不会遮住卡片外部内容或影响未展开态。
3. 验证 CSS 与构建，按用户可见影响记录版本并本地提交。

## 验收

- [x] 展开卡片后标题栏与底部控制条都使用 sticky 定位，底部控制条贴住滚动容器底部。
- [x] 底部吸顶只作用于展开态；未展开态布局不变。
- [ ] 浏览器实机滚动检查。

分类：PATCH / 改善已有文件更改卡片展开后的滚动操作，不增加新的任务能力；目标版本 `0.28.2-dev.1`。
