# 移动端顶部高度与侧滑灵敏度调整

## 目标

减少移动端聊天顶部栏占用的垂直空间，让从屏幕左右半区侧滑打开对应侧栏时更容易触发，并让左侧对话栏在拖动过程中跟随手指。

## 实施步骤

1. 只将窄屏聊天顶部工具栏对应的网格行从 56px 调整为 50px，不改系统状态栏安全区及桌面布局。
2. 将侧滑手势最小横向距离从 64px 降到 44px，继续要求横向移动显著大于纵向移动。
3. 左侧对话栏在触摸移动期间实时更新位移，触摸结束时根据手势方向或面板过半位置吸附打开/关闭；取消触摸时恢复原状态。
4. 添加布局与手势回归测试，验证拖动位移、吸附选择、稍短有效侧滑及纵向/反向移动。
5. 更新修复版本记录，运行完整测试、生产构建和差异检查，并创建本地 Git 提交；不推送远端。

## 验收标准

- 窄屏聊天顶部栏高度为 50px，系统状态栏及其安全区不变。
- 横向移动 44px 以上且方向正确的手势可触发侧栏；短于阈值、以纵向为主或方向错误的手势不触发。
- 侧栏在手指按住拖动时实时跟随，松手吸附到打开/关闭位置，取消拖动恢复原状态。
- 桌面布局及已经打开的侧栏关闭手势保持不变。
- 项目测试、`pnpm build` 和 `git diff --check` 通过。
