# 并发窗口输入区高度稳定修复

## 目标

电脑端在有排队消息和无排队消息的并发窗口间切换时，共用输入区及聊天视口不再因临时提示或占位尺寸不同而上下跳动。

## 实施步骤

1. 检查共用输入框切换窗口时的挂载、手动调整高度、图片草稿恢复、排队卡片和运行中文件变更提示，确认各自对布局高度的影响。
2. 将图片草稿恢复提示移到输入区已有的控件位置，不在切换时临时增加一行内容。
3. 在多窗口模式下，为队列和运行中文件变更提示保留与实际组件相同的布局槽位；保留用户手动调整的共用输入框高度。单窗口和移动端不额外占位。
4. 添加针对切换窗口时布局槽位与恢复提示的回归检查，运行相关测试、生产构建和差异检查。
5. 记录本次更新描述并提交本地 Git；不推送远端，也不触碰其它未提交改动。

## 验收

- 队列折叠时，在有队列和无队列窗口间往返，聊天视口底边不移动。
- 后台窗口有运行中文件变更时，切换到它或切走不改变输入区占用高度。
- 图片草稿异步恢复期间不插入临时状态行；图片仍可正常恢复，恢复前不能误发送。
- 手动拖高或缩短共用输入框后，切换并发窗口不会重置为默认高度。
- 队列展开属于用户主动改变布局；移动端不保留空白占位。
