# 工作区文件编辑开发记录

## 目标

在右侧文件预览中增加文本文件编辑和保存能力，保存目标为运行 Codex 的本机工作区；保留现有只读预览、语法高亮及差异查看。

## 安全与交互约束

- 写入接口复用现有 Bearer 认证、工作目录解析和相对路径/符号链接边界校验，不允许越出选定工作区。
- 仅支持现有预览可读取的 UTF-8 文本文件，并沿用 1 MiB 和 20,000 行限制；二进制、非 UTF-8、超限文件拒绝编辑/保存。
- 保存时携带读取时的文件版本摘要；若磁盘内容已被 Codex 或其他程序修改，返回冲突，不覆盖新内容。
- 采用显式“编辑 / 保存 / 取消”操作；保存失败保留草稿，离开或重新加载有未保存修改的文件时先确认。
- 保存成功后更新预览内容和版本信息，并刷新文件树中的文件大小。
- 不新增编辑器依赖；桌面和移动端共用编辑能力，输入框适配现有预览区域。

## 实施步骤

1. 为文件读取结果增加内容摘要，并实现受认证的文件保存接口、大小/行数/编码校验及版本冲突保护。
2. 在 API 客户端增加保存方法和类型。
3. 在右侧预览工具栏增加编辑状态、草稿编辑区、保存/取消及未保存保护。
4. 增加服务端路径、安全边界、文件约束、冲突和成功写入测试；运行前端测试、服务端测试、构建及差异检查。
5. 更新版本记录并创建本地提交；不推送 GitHub，除非收到明确命令。

## 验收标准

- 可以从右侧文件树打开文本文件、进入编辑、保存并重新读取确认内容已写入本机。
- 取消编辑不改动磁盘；保存失败或冲突时保留用户草稿并给出明确提示。
- 越界路径、外部符号链接、二进制/非 UTF-8、超大/超行数内容和过期版本均不能写入。
- 保存后的代码预览仍有语法高亮，移动端和桌面端均可操作。
