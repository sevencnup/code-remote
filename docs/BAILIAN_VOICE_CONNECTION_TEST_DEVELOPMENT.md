# 百炼语音连接测试开发文档

## 目标

在网页版百炼语音设置中提供“测试连接”入口。用户可在不录音、不发送音频的情况下，验证当前填写的 API Key、Workspace、地域及模型能否由运行 Codex Remote 的服务器连接并初始化百炼实时语音会话。

## 实施步骤

1. 在服务端百炼设置存储层增加临时测试配置解析：优先使用本次请求非空 API Key，否则沿用项目已保存 Key 或服务器环境变量；本次填写的 Workspace、地域和模型仅用于测试，不自动保存。
2. 在百炼 WebSocket 会话层增加连接测试：建立真实上游 WebSocket，发送与正式转写一致的会话配置，等待 `session.updated` 或可识别的服务端错误；不发送任何音频，并确保所有结束路径都关闭上游连接。
3. 将 WebSocket 状态码、DNS/网络/超时、鉴权、地域/资源和模型权限错误映射为可操作且不包含密钥、响应头或原始敏感内容的提示。
4. 增加受现有配对令牌保护的测试 API；测试 API 不持久化请求配置或密钥。
5. 在网页版百炼语音设置中增加“测试连接”按钮和独立的进行中、成功、失败状态；测试使用当前表单值，测试成功后明确提示未保存的配置仍需点击“保存配置”。
6. 补充服务端单元测试和 API 测试，覆盖上游就绪、认证失败、网络失败、会话配置失败、始终关闭连接及测试配置不落盘。
7. 执行相关测试及前端构建，并按新增功能更新版本与更新记录。

## 验收标准

- 用户可从设置页主动测试百炼连接，无需启动麦克风或发送音频。
- 成功代表服务端连接到百炼并收到 `session.updated`，而非仅检查 DNS 或网页服务器自身健康。
- 错误提示能区分常见网络、鉴权、地域/资源和权限问题，且不泄露 API Key。
- 测试请求不会更改服务器已保存配置；现有语音输入连接行为不回归。
- 所有成功、失败、超时和取消路径都会关闭短时测试连接。
