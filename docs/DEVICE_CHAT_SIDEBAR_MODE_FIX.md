# 设备群聊使用侧栏模式

## 分类与目标

修复 / PATCH，目标版本 `0.68.1-dev.3`。普通聊天与设备群聊切换时，左侧栏切换内容模式；右侧继续使用同一套聊天标题、消息流和输入框。群聊列表、创建/加入、成员和邀请码属于群聊侧栏，不再生成右侧页面或成员浮层。

## 步骤

1. 左侧栏加入普通聊天 / 设备群聊模式切换；普通聊天列表只在普通模式显示。
2. 群聊模式的侧栏显示当前群聊入口、创建/加入、成员和邀请管理；点群聊入口在手机端收起侧栏。
3. 删除右侧房间面板和群聊标题栏的管理浮层入口，群聊消息复用现有消息气泡，右侧继续共用标题、消息流和输入框。
4. 检查窄屏输入框、消息区可见性，更新版本记录。
5. 类型检查、构建、相关测试及差异检查；本地提交并同步此前指定的 Gitea。

## 验证

TypeScript 检查、Vite 构建和差异检查通过。前端测试 165 项通过 160 项；剩余 5 项为修改前已有的移动布局与主题变量断言失败。当前运行中的 4173 服务已返回最新构建资源。
