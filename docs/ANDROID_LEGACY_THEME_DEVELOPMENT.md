# Android 系统老主题开发

## 需求与分类

在原生 Android 应用的设置中增加可切换的 Android 8 风格主题。用户可以选择此前没有的界面样式，分类为新增功能（MINOR），目标版本 `0.30.0-dev.1`，Android `versionCode` 为 `250`。

## 设计范围

- 采用 Android 8 Oreo 时期的浅色 Material 风格：浅灰页面、白色面板、蓝色操作强调、清晰的灰色分隔及较小的卡片圆角。
- 覆盖聊天、侧边栏、设置、输入框和系统状态栏。Codex 与 Claude 的品牌区别继续保留。
- 作为主题选项保存到本机偏好；切换时保留当前会话和输入草稿。
- 原有主题维持原样，网页主题选项不随本次 Android 专属样式增加。

## 实施步骤

1. 在 Android 主题配置中加入 Oreo 配色及浅色系统栏处理。
2. 将主题加到设置列表，调整典型容器和输入框的 Oreo 风格形状。
3. 更新版本号与版本记录，构建新的 APK，安装到已连接的手机。
4. 检查主题选择、页面主要区域和切换后草稿保留。

## 按参考图调整为 Android 5 Lollipop（0.30.1-dev.1 / PATCH）

用户提供的参考图是 Android 5 时期的 Material UI。按图将既有主题改为蓝色顶栏、深蓝状态栏、白色内容区、浅色卡片和圆形蓝色主操作按钮。此为现有主题的视觉调整，归类为 PATCH；Android `versionCode` 为 `251`。

1. 将主题选项命名为“Android 5”，保留 `oreo` 和 `gingerbread` 本地偏好映射，升级时继续选中该主题。
2. 为聊天页、侧栏、设置页、输入框、消息气泡和系统栏应用对应的 Material 色彩与控件形状；保留 Codex 与 Claude 品牌图标。
3. 以新版本构建 APK 并安装，检查状态栏和导航栏颜色、主题选择和主要操作入口。

## 状态栏配色修正（0.30.1-dev.2 / PATCH）

在 Android 15 的边到边布局中，系统忽略了单独设置的状态栏颜色。为主题窗口背景加入对应的状态栏和导航栏区域绘制，确保状态图标和导航手势条具有清晰对比。

## 完整覆盖 Lollipop 控件与图标（0.30.1-dev.5 / PATCH）

首版反馈指出，仅调整主色和少数圆角不足以呈现 Android 5 风格，聊天、侧栏、设置、文件树、排队、操作记录等模块仍沿用现代玻璃卡片与细线图标。本次将旧主题落实为完整的 Material Design 1 组件语言。

1. 统一应用栏/状态栏蓝色色阶、页面底色、卡片层级和控件形状，应用栏使用 Android 5 的 56dp 高度与 20sp 标题。
2. 给所有通用导航、文件操作、排队和模块图标换成实心 Material 图标；Codex/Claude 品牌图标和普通主题资源不变。
3. 将输入框改为不透明的平面表面与轻微阴影，移除本主题中的玻璃渐变和呼吸光晕；保留发送/暂停行为。
4. 侧栏、设置区、文件树、排队卡片、最近编辑文件和操作记录统一使用扁平行、浅蓝选中态、分隔线和 2dp 卡片角。
5. 更新 PATCH 版本，构建新 APK 并在设备上检查主要模块和图标。

## 图标覆盖复查（0.30.1-dev.6 / PATCH）

安装检查发现对话列表仍重复显示 Codex/Claude 品牌标志，文件树与已编辑文件又将不同扩展名统一显示成普通文件图标。对话条目改用 Material 聊天气泡并通过 Codex/Claude 强调色区分模式；保留模式切换与跨模式通知中的品牌标志。文件树、操作记录及编辑列表恢复按扩展名显示文件图标，并将进行中操作改为真正旋转的进度指示器。

1. 对照所有 `ImageView`/`ImageButton` 的资源分支，核实旧主题页面没有落回普通主题细线资源。
2. 补齐对话、文件类型及运行状态图标，并保留其他主题原有图标行为。
3. 递增 PATCH 版本和 Android `versionCode`，构建新 APK 并在已连接手机上检查对话列表、文件树、编辑记录和操作记录。

## 操作入口图标统一（0.30.1-dev.7 / PATCH）

回查页面控件时发现文件树“上级/跟随聊天”、终端发送、文件保存/重载及授权操作还用纯文字或字符箭头。仅在 Android 5 主题下为这些入口加上实心 Material 图标，并保留其他主题的原按钮样式。

## 进一步还原 Android 2.3 Gingerbread（0.30.1-dev.9 / PATCH）

用户反馈 Android 5 外观仍然太新，字体与旧系统不符，终端标题栏两侧还露出底色。本轮将主题视觉退回 Gingerbread：深色金属标题栏、深灰内容面、橄榄绿强调色、直角/小圆角控件和 Android 2.3 的 Droid Sans / Droid Sans Fallback 字体；主题内部偏好键继续使用 `lollipop`，避免升级后重置用户已选主题。字体从 Android Open Source Project 的 Android 2.3.7 源码获取，随 APK 打包并附 Apache 2.0 NOTICE，保证新系统不会把 Droid Sans 别名映射成 Roboto。

1. 在设置中将该选项标为 Android 2.3，并切换到 Gingerbread 深色调色板、旧式渐变标题栏与按钮状态。
2. 将通用文字、编辑框、聊天消息和 Markdown 文本统一使用 Droid Sans，并让中文回退字体使用 Droid Sans Fallback；保留终端输出的等宽字体。
3. 终端面板去除左右内边距，让标题栏铺满窗口宽度，维持其他主题的布局不变。
4. 递增 PATCH 版本和 Android `versionCode`，构建新的 APK 并安装到已连接手机，检查主题选择、聊天文字、标题栏和终端。

## 按新参考图调整为 Android 1.0（0.30.1-dev.10 / PATCH）

用户补充了 Android 1.0 的整套界面截图，明确之前的 Gingerbread 仍不够老。本轮以该图为准，将标题栏和系统状态区改为银灰金属渐变、应用内容保留深色经典列表面、按键使用旧式灰阶高光与凹凸边线、主操作采用亮绿；主题名称改为 Android 1.0。继续使用 Android 2.3 开源 Droid 字体资源作为同一早期 Droid 字体家族，保留其 Apache 2.0 NOTICE 和内部 `lollipop` 偏好键。

1. 将设置里的主题选项改为“Android 1.0”，状态栏改为浅银灰并显示深色图标，应用栏改为银灰高光渐变和深色标题/图标。
2. 将旧主题的常用控件、列表行和操作按钮改成 Android 1 风格的灰阶金属层次与边线，亮绿只用于选中和主操作。
3. 终端标题栏继续全宽铺满，但换成银灰金属渐变并检查两侧不露底色。
4. 递增 PATCH 版本和 Android `versionCode`，构建新 APK 并安装，按参考图检查状态栏、标题栏、按钮、字体和终端。
