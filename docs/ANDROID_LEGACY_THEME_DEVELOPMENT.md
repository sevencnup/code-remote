# Android 系统老主题开发

## 需求与分类

在原生 Android 应用的设置中增加可切换的 Android 8 风格主题。用户可以选择此前没有的界面样式，分类为新增功能（MINOR），目标版本 `0.30.0-dev.1`，Android `versionCode` 为 `250`。

## 设计范围

- 采用 Android 8 Oreo 时期的浅色 Material 风格：浅灰页面、白色面板、蓝色操作强调、清晰的灰色分隔及较小的卡片圆角。
- 覆盖聊天、侧边栏、设置、输入框和系统状态栏。Codex 与 Claude 的品牌区别继续保留。
- 作为主题选项保存到本机偏好；切换时保留当前会话和输入草稿。
- 原有主题维持原样，网页主题选项不随本次 Android 专属样式增加。

## 实施步骤

1. 在 Android 主题配置中加入 Oreo 配色及浅色系统栏处理。
2. 将主题加到设置列表，调整典型容器和输入框的 Oreo 风格形状。
3. 更新版本号与版本记录，构建新的 APK，安装到已连接的手机。
4. 检查主题选择、页面主要区域和切换后草稿保留。

## 按参考图调整为 Android 5 Lollipop（0.30.1-dev.1 / PATCH）

用户提供的参考图是 Android 5 时期的 Material UI。按图将既有主题改为蓝色顶栏、深蓝状态栏、白色内容区、浅色卡片和圆形蓝色主操作按钮。此为现有主题的视觉调整，归类为 PATCH；Android `versionCode` 为 `251`。

1. 将主题选项命名为“Android 5”，保留 `oreo` 和 `gingerbread` 本地偏好映射，升级时继续选中该主题。
2. 为聊天页、侧栏、设置页、输入框、消息气泡和系统栏应用对应的 Material 色彩与控件形状；保留 Codex 与 Claude 品牌图标。
3. 以新版本构建 APK 并安装，检查状态栏和导航栏颜色、主题选择和主要操作入口。

## 状态栏配色修正（0.30.1-dev.2 / PATCH）

在 Android 15 的边到边布局中，系统忽略了单独设置的状态栏颜色。为主题窗口背景加入对应的状态栏和导航栏区域绘制，确保状态图标和导航手势条具有清晰对比。
