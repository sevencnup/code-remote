# Android 文件更改卡片对齐网页版

## 目标与分类

体验优化 / PATCH：原生文件更改卡片已有预览、审核、插入对话与展开能力，但排版与网页版不一致。目标内部版本 `0.28.1-dev.8`，Android `versionCode 242`。

## 实施步骤

1. 对照网页版文件卡片：图标方框、标题与增删统计上下排列、独立审核按钮、分隔文件行、独立插入按钮和底部查看更多。
2. 重排原生卡片，默认只显示首个文件；展开和审核时显示全部，保留文件预览和插入对话操作。
3. 按浅色与深色主题设置卡片、分隔线和按钮颜色；保持窄屏下路径截断、按钮可点击。
4. 更新内部版本，构建独立 APK，安装到已连接手机并核对版本，完成本地提交。

## 验收

- 首行结构与网页版一致，增删统计在标题下面，审核为独立按钮。
- 文件行有分隔线，路径、增删统计、插入对话按钮各占自己的区域。
- 默认只显示第一个文件；查看更多、收起、审核、文件预览和插入对话正常。
- 安装版本 `0.28.1-dev.8` / `versionCode 242`。

## 实施结果

- 原生卡片已改为与网页版相同的标题、统计、审核、文件行和底部展开层级，新增文件行中的对话图标。
- 默认显示首个文件，展开与审核显示全部文件；路径预览和插入对话沿用现有操作。
- APK 构建并安装成功，手机报告 `versionCode 242`、`versionName 0.28.1-dev.8`。
