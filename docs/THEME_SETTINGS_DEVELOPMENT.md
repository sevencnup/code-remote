# 主题设置开发文档

## 目标

在聊天侧边栏底部增加设置入口，提供白色、黑色、暖色和自定义主题。自定义主题允许选择界面背景色、全局字体颜色和背景透明度，并将偏好保存在当前浏览器。

## 实施步骤

1. 将 `wotty-Personal-Note` 最新主题实现中的偏好持久化、主题变量和透明度思路迁移到当前 React 页面，不引入笔记项目的业务代码。
2. 在 `CodexRemotePage` 侧边栏底部增加设置按钮，移动端点击后关闭抽屉并进入设置面板。
3. 新增主题设置面板和四种主题选项；自定义主题展示背景色、文字颜色和透明度控件，修改后即时预览。背景图片沿用 `wotty-Personal-Note` 的处理方式：原图最大 20 MB，上传后在浏览器中缩放并转为 WebP，压缩到适合 `localStorage` 保存的大小。
4. 通过根节点主题 class 与 CSS 变量覆盖侧栏、聊天区、消息卡片、输入框、弹窗和按钮的主要表面，保持 Codex API、WebSocket 和聊天行为不变。
5. 自定义主题透明度只作用于独立的全局背景层（背景色与背景图），不随滑块改变侧栏、设置卡片等界面模块透明度；用固定透明度维持模块可读性。
6. 侧边栏当前选中的对话只使用一条 SVG 矩形路径跑马灯，虚线周期固定为一个亮段和一个空段，按钮原生边框、旧伪元素和额外外发光全部禁用；亮段沿带圆角的完整路径连续移动并经过四个转角；多开模式下当前窗口改为呼吸边框。黑色主题为纯白，白色主题为黑色，暖色主题为深棕色，自定义主题跟随自定义字体色；颜色直接写入活动窗口和选中条目的内联变量，避免旧主题 CSS 覆盖，多开窗口使用边框透明度和光晕周期变化，兼容桌面浏览器与 Android WebView。
7. 更新版本记录，执行生产构建、差异检查和现有测试，并提交本地 Git 仓库。

## 验收标准

- 侧边栏底部存在“设置”入口，桌面端和移动端均可打开。
- 白色、黑色、暖色主题可即时切换，刷新后主题保持。
- 自定义主题可修改背景色、字体颜色和背景透明度，刷新后设置保持；透明度滑块直接淡化全局背景色/图片，不改变设置卡片和侧栏等模块的透明度。
- 大于 2 MB 且不超过 20 MB 的背景原图可上传，自动压缩后持久保存，刷新后仍显示图片而非仅显示背景色。
- 当前选中的侧边栏对话有与主题匹配的单色动态边框，不使用彩色渐变。
- 多开窗口的选中边框使用同一主题色，不再显示彩色跑马灯。
- 设置面板不影响 Codex 会话、流式输出、审批、附件和发送功能。
- `pnpm build` 成功，`git diff --check` 无输出。
