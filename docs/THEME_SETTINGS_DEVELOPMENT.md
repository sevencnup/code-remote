# 主题设置开发文档

## 目标

在聊天侧边栏底部增加设置入口，提供白色、黑色、暖色和自定义主题。自定义主题允许选择界面背景色、全局字体颜色和背景透明度，并将偏好保存在当前浏览器。

## 实施步骤

1. 将 `wotty-Personal-Note` 最新主题实现中的偏好持久化、主题变量和透明度思路迁移到当前 React 页面，不引入笔记项目的业务代码。
2. 在 `CodexRemotePage` 侧边栏底部增加设置按钮，移动端点击后关闭抽屉并进入设置面板。
3. 新增主题设置面板和四种主题选项；自定义主题展示背景色、文字颜色和透明度控件，修改后即时预览。
4. 通过根节点主题 class 与 CSS 变量覆盖侧栏、聊天区、消息卡片、输入框、弹窗和按钮的主要表面，保持 Codex API、WebSocket 和聊天行为不变。
5. 侧边栏当前选中的对话和多开模式下当前窗口显示单色外部跑马灯边框：黑色主题为白色，白色主题为黑色，暖色和自定义主题为深棕色；使用加长加粗且在转角处重叠的四条边线按顺时针依次移动，并保留连续低亮度边框连接转角，兼容桌面浏览器与 Android WebView。
6. 更新版本记录，执行生产构建、差异检查和现有测试，并提交本地 Git 仓库。

## 验收标准

- 侧边栏底部存在“设置”入口，桌面端和移动端均可打开。
- 白色、黑色、暖色主题可即时切换，刷新后主题保持。
- 自定义主题可修改背景色、字体颜色和背景透明度，刷新后设置保持。
- 当前选中的侧边栏对话有与主题匹配的单色动态边框，不使用彩色渐变。
- 多开窗口的选中边框使用同一主题色，不再显示彩色跑马灯。
- 设置面板不影响 Codex 会话、流式输出、审批、附件和发送功能。
- `pnpm build` 成功，`git diff --check` 无输出。
