# Android 启动页 Logo 右下角修复

## 问题与目标

当前 Android 12+ 启动页已经去掉自适应图标底板和系统圆角蒙版，但品牌素材本身的 R 形右下末端带有大圆弧，真机上看起来像右下角被裁掉。

本次只为启动页制作独立的方角素材，补齐右下末端的透视端面。侧边栏、关于页、桌面图标和网页继续使用原品牌 Logo。

## 分类与版本

- 分类：修复 / PATCH。修正已有启动页 Logo 的视觉缺口，不改变应用能力或操作方式。
- 最终版本：`0.90.7-dev.2`，Android `versionCode 390`。
- 这是小幅视觉修复，不单独增加 `CHANGELOG.md` 条目。

## 实施步骤

1. 从现有透明 Logo 生成启动页专用 PNG，只补齐 R 形右下末端的方角轮廓。
2. 启动页前景改为引用专用素材，并保留当前安全边距。
3. 更新网页包与 Android 版本号。
4. 构建独立 APK，覆盖安装到已连接手机并核对版本。
5. 本地提交，不推送 GitHub；清理本次临时图像和调试进程。

## 验收标准

- 启动页 R 形右下末端呈完整的锐利方角，不再像被裁掉。
- Logo 其余轮廓和位置不变；整体只缩入足以完整显示方角的系统安全区。
- 应用内品牌 Logo 与桌面图标不受影响。
- 新 APK 使用独立文件名，历史安装包不被覆盖。
