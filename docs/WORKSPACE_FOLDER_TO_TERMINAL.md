# 右侧文件夹添加到终端开发说明

目标版本：`0.34.0-dev.1`（新增功能 / MINOR）。

## 目标

电脑端在右侧文件树的文件夹右键菜单中增加“添加到终端”。选择后打开当前聊天对应的本机终端，并把进入该目录的命令预填到命令行；不自动回车执行，最终执行由用户确认。

## 设计边界

- 仅电脑端显示该菜单项，手机端文件菜单保持不变。
- 只对单个真实文件夹显示入口，不对根目录或多选操作添加。
- 终端未打开时自动打开；终端已连接时直接填入当前命令行。
- 路径须按后端实际 shell 转义，涵盖 POSIX shell、PowerShell 和 cmd。
- 不改 Android 原生界面、不生成或安装 APK、不推送远端。

## 实施步骤

1. 扩展右侧文件树右键菜单，桌面端单文件夹显示入口，并将绝对目录路径请求传给当前聊天窗格。
2. 将目录请求桥接到对应终端；终端连接就绪后按 shell 类型生成 `cd`/目录切换命令并粘贴到当前输入行，不发送回车。
3. 添加 shell 命令转义测试，更新开发文档、版本记录和语义化版本号。
4. 运行相关测试、生产构建和差异检查，创建仅包含本次文件的本地提交；不构建 Android 包、不推送远端。

## 验收标准

- 电脑端右键单个文件夹可见“添加到终端”；手机端、根目录、文件和多选菜单不出现该入口。
- 点击后打开当前聊天的终端，并预填能够进入目标目录的命令；不得自动执行。
- 终端已打开时不重建会话，命令仍进入该终端。
- 路径含空格或引号时按对应 shell 规则正确引用。
- 路径转义测试、`pnpm build` 和 `git diff --check` 成功。
