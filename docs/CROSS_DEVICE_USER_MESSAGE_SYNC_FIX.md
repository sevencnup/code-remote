# 跨端用户消息同步修复

## 问题

同一对话在电脑端与移动端显示不一致：助手回复与操作记录可以同步，但另一端看不到用户消息。

## 原因定位

- 本机 rollout 与历史读取结果都包含完整的 `userMessage`，历史解析和页面样式没有丢失消息。
- 跨端接收依赖 WebSocket item 通知；Codex 可能直接发送带完整内容的 `item/completed`，不保证先发送可用的 `item/started`。
- 前端原来只在 `item/started` 中插入远端用户消息，`item/completed` 仅处理助手消息和操作记录，因此另一台设备只能看到 AI 回复。

## 实施步骤

1. 统计真实 rollout 中消息事件的字段结构，不记录消息正文。
2. 让 `item/started` 与 `item/completed` 共用远端用户消息解析、去重、排序和图片恢复逻辑。
3. 更新开发版本号与版本记录。
4. 执行 TypeScript 与生产构建检查。
5. 提交到本地 Git 仓库。

## 验收标准

- 电脑端发送的用户消息可在移动端同一对话中看到。
- 移动端发送的用户消息可在电脑端同一对话中看到。
- 助手回复、图片、附件和实时流式内容仍正常显示。
- 历史刷新与跨端实时通知不会产生重复用户消息。
