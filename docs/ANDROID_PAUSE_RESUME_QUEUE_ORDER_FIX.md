# Android 暂停续接与排队顺序修复

## 目标

- 输入框右侧按钮在回复中用于暂停，暂停后再次点击用于续接。
- 手动暂停后排队消息保持等待；只有用户点击该条的“立即发送”，或续接后的回复正常结束，才自动推进队列。
- 撤掉临时网页 APK 下载文件和无效下载地址。

## 步骤

1. 核对 Android 按钮、续接请求和共享队列的状态流。
2. 给服务端共享队列保存暂停状态，阻止暂停期间的自动推进；提供优先续接当前回复的操作。
3. 调整 Android 按钮优先级与状态刷新，让草稿和排队消息不抢占暂停、续接按钮。
4. 移除临时下载文件，更新版本记录，构建 APK 并安装；检查差异并本地提交。

分类：PATCH / 修复现有暂停续接与排队发送顺序；原目标版本 `0.28.4-dev.2` 已有安装包，接手后的新包为 `0.28.4-dev.3`，Android `versionCode` 248。

验证：`assembleDebug` 已通过并生成新包；当前环境无 `adb`，安装与真机交互待设备可用时验证。Codex 续接改为无用户消息的空输入回合，Claude 保留原续接文本。
