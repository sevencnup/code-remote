# Android 暂停续接与排队顺序修复

## 目标

- 输入框右侧按钮在回复中用于暂停，暂停后再次点击用于续接。
- 手动暂停后排队消息保持等待；只有用户点击该条的“立即发送”，或续接后的回复正常结束，才自动推进队列。
- 撤掉临时网页 APK 下载文件和无效下载地址。
- 思考等级选项固定使用英文；将附件加号放到发送按钮左侧。
- 将回复中活动状态调整为单行运行命令/文件信息与计时器，不显示“搜索中”“编辑中”等状态文案。

## 步骤

1. 核对 Android 按钮、续接请求和共享队列的状态流。
2. 给服务端共享队列保存暂停状态，阻止暂停期间的自动推进；提供优先续接当前回复的操作。
3. 调整 Android 按钮优先级与状态刷新，让草稿和排队消息不抢占暂停、续接按钮。
4. 移除临时下载文件，更新版本记录，构建独立 APK；设备连接时安装，检查差异并本地提交。

分类：PATCH / 修复现有暂停续接与排队发送顺序，并调整输入框和回复状态的显示；目标版本 `0.29.0-dev.2`，Android `versionCode` 249。

验证：网页构建与 Android `assembleDebug` 已通过；当前没有连接的 ADB 设备，安装与真机交互待设备可用时验证。Codex 续接使用空输入回合，Claude 续接保留原续接文本。
