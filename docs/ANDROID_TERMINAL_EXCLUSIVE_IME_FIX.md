# Android 终端独立输入与键盘布局修复

## 问题与分类

用户截图显示键盘弹出时聊天输入框仍占据终端下方，聊天光标可见；终端提示符在后续刷新中消失，只剩 tmux 状态行。上一版只处理滚动，没有让终端成为键盘打开时唯一可见的输入区域，也没有处理终端屏幕重绘。

本次属于修复 / PATCH：恢复已有移动终端的输入可见性和交互稳定性。首次构建为 `0.62.0-dev.4` / `versionCode 328`，修正真机发现的焦点与重绘问题后为 `0.62.0-dev.5` / `versionCode 329`。

## 实施步骤

1. 复查手机当前界面和 Android 终端输出、输入焦点，确定截图所示状态的直接原因。
2. 终端打开时收起聊天输入区；终端面板底边直接跟随键盘顶部。关闭终端后恢复聊天输入区及草稿。
3. 固定终端输入焦点，避免键盘打开后落到聊天输入框；终端输入仍直接发送到 PTY，不新增整行发送框。
4. 修正终端屏幕处理与 tmux 重绘相关的错误，确保提示符和状态行保持在正确位置。
5. 更新版本与变更记录，构建独立 APK、安装到手机并检查键盘开合、终端视口和焦点，不覆盖旧包。
6. 只提交本次源码和文档到本地 Git，不推送 GitHub。

## 验收标准

- 终端打开时不出现“发送消息”聊天输入框；键盘打开后终端内容区扩展到键盘上方。
- 点击“键盘”或终端内容区时，输入焦点属于终端，输入内容由 PTY 回显在终端中。
- 终端提示符和 tmux 状态行在重绘后仍位于各自位置，不因清屏或滚屏消失。
- 关闭终端后聊天输入框和原有草稿恢复。

## 真机复查与补充修复

`dev.4` 真机画面表明，终端独立布局已生效，但完全透明的 1 像素输入控件未能稳定取得输入焦点；键盘按钮点过后，输入法服务的焦点仍落在页面根容器。键盘尺寸变化期间还会连续向 tmux 发出 resize，清屏与重绘在不同输出块中到达时出现瞬时空白。

`dev.5` 将终端输入控件保持为可聚焦的 2 像素透明文本框，主动请求输入法；尺寸变化稳定后再同步 PTY 行列数，并合并连续输出块的绘制。真机复查确认输入焦点已正确落到终端控件，但微信输入法仍没有显示键盘。同一设备的聊天输入框可正常显示键盘，因此 `dev.6` 把透明的终端输入控件叠在终端内容底部，赋予正常的触控高度，不新增发送框或占用终端之外的空间。

`dev.6` 真机确认键盘正常显示、终端随键盘缩到上方。继续输入单个字母时，微信输入法切换成候选浮层，系统报告的 IME 高度暂时变小；APP 因此误发终端 resize，tmux 清屏后提示符暂时消失。`dev.7` 在终端输入获得焦点后锁住本次已展开的最大键盘高度，候选浮层不能缩小终端视口；返回收起键盘或关闭终端时释放锁定高度。

`dev.7` 真机复查仍可复现：这台设备在候选浮层出现时直接改变根布局的可用高度，单看 IME inset 不足以阻止终端扩张。`dev.8` 同时锁定终端面板的最小可用底边；仅在输入法真正收起且没有输入法组合文字时解除锁定。

继续记录布局和输出日志后确认：用户输入字母时，终端没有收到新的 PTY 输出，也没有再次 resize；终端文字控件因默认可选中而自行滚动，导致顶部提示符离开可视区。`dev.9` 普通输入时关闭控件选择模式并固定其内部滚动位置，长按时临时启用文字选择。

## 后续反馈：隐藏状态行并修正清屏

用户要求去掉终端底部的 tmux 状态行，并反馈打开输入法时顶部的终端文字仍然消失。`dev.9` 实机 UI 层级确认：终端文字控件的内容本身只剩空行和 tmux 状态行，提示符并非被滚动遮住；服务端 `tmux capture-pane` 同时仍有提示符。复查发现 APP 已发送新的行列数，PTY 尺寸也已更新，但 tmux 客户端没有收到 `SIGWINCH`，仍按旧尺寸绘制。向该终端客户端定点发送 `SIGWINCH` 后，tmux 使用新尺寸重画，顶部提示符恢复。

1. 在服务端写入 PTY 新尺寸后向对应的存活子进程发送 `SIGWINCH`，让 tmux 立即重画；进程恰好退出时忽略信号错误。
2. Android 收到持久终端的 `ready` 事件后，在显示文本时排除末尾的 tmux 状态行，不修改服务端会话，也不裁掉普通终端的末行。
3. 删除临时诊断日志，递增至 `0.62.0-dev.10` / `versionCode 334`，构建独立 APK 并装机检查键盘开合、顶部提示符及底部状态行。
4. 只提交本次源码和文档到本地 Git，不推送 GitHub。

## `dev.10` 检查结果

- Android `assembleDebug` 构建成功，新包已覆盖安装在 `10.126.126.2:5555`，旧 APK 文件保持不变。
- 手机上的终端视图已不显示 tmux 底部状态行；打开键盘时终端区域缩到键盘上方，顶部旧会话内容仍可见。屏幕上 `已切换到 codex (deepseek-flash)` 与分行的 `root@...#` 是原 tmux 会话的历史输出和 shell 提示符。
- 用独立的临时终端会话将 PTY 从 `40x30` 改到 `40x12`，tmux 客户端同步变成 `40x12`。检查完已关闭并删除该临时会话。
- 现有网页服务承载当前开发对话，重启会中断本对话；部署服务端修复时在本轮回复完成后再定时重启。此前手机上的键盘截图仍连接旧服务端进程，不能作为完整的线上修复验收。
