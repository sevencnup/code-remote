# 配对码三次错误锁定

## 分类与目标

本次属于修复 / PATCH：收紧现有配对码的连续猜测次数，并让锁定状态在页面上清楚可见。当前版本为 `0.42.1-dev.1`，目标版本为 `0.42.2-dev.1`。

## 实施步骤

1. 将服务端连续错误次数上限从 8 次调整为 3 次；第三次错误后暂停配对 60 秒，并通过 `429` 与 `Retry-After` 返回剩余时间。
2. 配对页必须输入完整 8 位码才允许提交；保留前两次错误的即时提示，收到服务端锁定响应时禁用输入和提交按钮并显示倒计时。
3. 倒计时结束后恢复输入；服务端仍负责拒绝锁定期间的请求，页面状态不作为安全边界。
4. 更新网页和后端版本记录，执行生产构建并检查修改范围。

## 验收标准

- 前两次错误立即提示配对码错误。
- 第三次连续错误开始 60 秒锁定，页面显示倒计时且不能继续输入或提交。
- 锁定结束后可以重新尝试；再次连续错误 3 次会再次锁定。
