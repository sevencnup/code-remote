# 工作区文件树下载原文件

本次属于**新增功能 / MINOR**：右侧文件树目前可以预览或上传，但不能把服务端原文件下载到浏览器。目标版本 `0.85.0-dev.1`。

## 实施步骤

1. 服务端提供经配对鉴权的下载准备接口，校验所选工作区内的单个普通文件，签发短期、单次使用的随机下载地址。下载响应按原始字节流传输并设置附件文件名，不受文本或图片预览大小限制。
2. 下载地址只对一次请求有效，过期和无效地址拒绝访问；重新检查路径，禁止目录、工作区越界路径及符号链接目标。短期地址数量受限，避免无人领取的地址持续占用内存。
3. 网页客户端封装准备请求；在文件树单个文件的右键菜单加入“文件下载”，文件夹、根目录及多选菜单不显示。失败时在文件树显示原因。
4. 更新版本和简短版本记录，执行网页构建、Python 语法检查及差异检查；不新增或运行测试。
5. 只在本地仓库提交，不推送 GitHub，不生成 Android 安装包。

## 验收条件

- 文本、图片和其它二进制文件均下载原始内容及原文件名；大文件由服务端流式传输。
- 文件夹右键菜单没有下载项；多选时不显示单文件下载项。
- 未配对请求不能申请下载；过期、已使用或路径越界的地址不能再次读取文件。

## 完成记录

- 文件右键菜单已添加“文件下载”；文件夹、根目录和多选菜单不会显示该项。
- 服务端下载地址单次有效，并在传输时保留原始字节，不经过通用 gzip 压缩。
- TypeScript 编译、Vite 构建、Python 语法检查和 `git diff --check` 均通过；未运行测试或生成 Android 安装包。
- 本次仅进行本地 Git 提交，不推送 GitHub。后端进程需要重启后才会加载新增接口。
