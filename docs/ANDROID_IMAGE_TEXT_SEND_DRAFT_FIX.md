# Android 图片加文字发送后草稿残留

## 现象与原因

用户同时附加图片和输入文字发送后，图片进入对话，刚发送的文字仍留在输入框。Android 端已将文字和图片组装为同一份 `queue/submit` 请求；发送前立即清空输入框，但输入法提交中的文字或异步界面恢复可能在请求结束前重新写回。

## 处理步骤

1. 发送时先结束输入法的文字组合状态，再读取正文并组装图片和文字。
2. 服务端确认接收后，如输入框仍是本次已发送文字，则清理该残留；发送期间用户新输入的不同内容保留。
3. 保持失败时恢复文字与附件的现有行为；递增测试版本、构建独立 APK 并安装。

分类：PATCH / 修复已有图片加文字发送流程中的草稿残留。

`0.23.0-dev.4` 已离线构建并安装到手机，设备报告 `versionCode=209`。未代替用户向真实聊天发送图片与文字，因此具体输入法上的原始场景尚未实机复现验证。
