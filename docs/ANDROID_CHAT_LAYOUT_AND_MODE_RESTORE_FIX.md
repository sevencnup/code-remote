# Android 聊天布局与模式返回修复

## 目标

修复 Android 聊天区被输入框容器挤成零高度，以及 Codex / Claude 切换回来时丢失原聊天的问题。

## 步骤

1. 用真机布局层级确认输入框发光层导致容器按整屏测量；让发光层跟随输入框实际高度，避免参与初始高度计算。
2. 切换模式时保存离开模式的聊天 ID，恢复目标模式上次选中的聊天；目标模式没有历史选择时展示新聊天。
3. 递增 Android PATCH 测试版本与 `versionCode`，更新版本记录。
4. 构建新 APK、覆盖安装保留应用数据，核对聊天区和模式切换，完成本地提交。

## 验收

- 聊天区占据顶栏与底部输入框之间的剩余空间，历史消息能显示。
- Codex → Claude → Codex 返回原 Codex 聊天，Claude 也独立记住上次聊天。
- 已有 APK 文件不被覆盖。

## 实施结果

- 真机布局层级在旧包中显示聊天 `ScrollView` 高度为 `0`、输入框容器高度为 `2328px`；修复后聊天 `ScrollView` 高度为 `1740px`，截图确认历史消息与底部输入框正常显示。
- 模式切换现在按连接和模式保存、恢复最后选中的聊天 ID；切换目标没有记录时才进入新聊天。
- `0.28.1-dev.1` / `versionCode 235` 已离线构建并覆盖安装，旧 APK 文件保留。手机在进一步点击切换验证时进入锁屏，因此模式往返仅完成代码路径检查，待解锁后可实机确认。
