# 网页代码块复制按钮可见性修复

## 问题与分类

PowerShell 等长单行代码块在网页中看不到复制按钮。代码块目前把复制按钮放在横向滚动的 `<pre>` 内，并且回复仍在生成时会主动隐藏该按钮。

这是修复 / PATCH：恢复现有代码复制入口，不增加新的用户任务。目标版本为 `0.87.2-dev.1`。

## 实施步骤

1. 将代码块复制按钮移到横向滚动区域外，固定在代码框右下角。
2. 对已经闭合并渲染成代码块的内容始终显示复制按钮；整条回复的复制按钮仍按回复完成状态显示。
3. 更新版本与简要版本记录，构建 `4173` 页面产物，检查差异并本地提交。

## 验收标准

- 长单行 PowerShell 代码无需横向滚动即可看到复制按钮。
- 正在生成的回复中，已闭合的代码块可直接复制完整代码。
- 代码块仍可横向滚动，复制结果不包含语言标签。
