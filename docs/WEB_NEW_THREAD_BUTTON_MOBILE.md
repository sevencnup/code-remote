# 移动端新建对话入口调整

## 目标与分类

让移动网页版也从聊天输入框左下角新建当前模式的对话，和桌面版使用同一入口。属于 PATCH / 体验优化：新建对话能力不变，只统一入口位置并适配触控操作。目标版本为 `0.56.4-dev.9`。

## 交互要求

- 手机竖屏、横屏和桌面端都在输入框左下角显示“聊天 + 加号”图标按钮。
- 按钮沿用当前选中聊天面板的新建逻辑、禁用条件、无障碍名称和提示文本。
- 从侧边栏移除旧的新建对话按钮，保留 Codex / Claude 模式筛选。
- 移动端按钮至少为 36 × 36 px，适配触控；继续适配 Claude、Retro、Pixel、自定义等主题。

## 实施步骤

1. 移除侧边栏的新建对话入口，保留模式筛选按钮。
2. 让输入框按钮在所有屏幕尺寸与方向显示，并为触控设备设置合适尺寸。
3. 更新版本和 CHANGELOG；运行生产构建及差异检查，不新增或运行测试。
4. 检查差异并创建仅包含本次修改的本地提交，不推送 GitHub。

## 验收标准

- 移动端与桌面端均可从输入框左下角新建当前模式对话。
- 侧边栏不再出现新建对话按钮，模式筛选仍可用。
- 主题样式和触控目标可辨识、可操作。
- `pnpm build` 成功；`git diff --check` 无输出；不新增或运行测试。

- 移除了侧边栏的新建对话按钮，Codex / Claude 筛选保留。
