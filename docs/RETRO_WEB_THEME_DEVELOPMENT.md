# 旧网页主题开发说明

新增功能 / MINOR：增加一种此前不能选择的界面主题。目标版本为 `0.29.0-dev.1`；本次只改网页主题能力，Android `versionCode` 不递增。

## 目标

新增一个可保存、可即时切换的“旧网页”主题，呈现更早期的单页网站观感：桌面端以居中的白色正文页为主，采用朴素标题、细分隔线、传统蓝色下划线文字链接和原生方形控件；不把聊天记录、文件树等功能做成常驻并列模块。功能入口仍保留为简单文字导航，面板按需打开，不删除能力；手机端布局和无障碍焦点状态不变。

## 实施步骤

1. 在主题类型和偏好恢复逻辑中加入新主题，不影响旧版本已保存的主题设置。
2. 在主题设置中增加“旧网页”选项及对应预览，并保持即时切换和本地持久化。
3. 为旧网页主题补充覆盖样式，统一覆盖应用外壳、导航、对话、文件区、输入区、菜单、弹窗和设置面板；桌面端可改为单页呈现，侧栏和文件区通过文字链接按需打开。
4. 检查状态栏图标对比度及重要的按钮、禁用态、悬停态和键盘焦点态；主题样式不得串改其他主题。
5. 更新主题偏好测试，运行测试和生产构建，并按新增功能规则记录版本。

## 验收标准

- 设置中可选择“旧网页”，刷新后仍保留选择。
- 桌面默认视图是单个正文页面，不常驻显示现代多栏模块；聊天记录和文件区仍可通过文字入口访问。
- 主要文字、链接、交互状态和键盘焦点清楚可辨，现有功能和手机端布局保持可用。
- 其他主题的外观和存储行为不变。
