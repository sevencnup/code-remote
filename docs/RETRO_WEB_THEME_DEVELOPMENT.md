# 旧网页主题开发说明

新增功能 / MINOR：增加一种此前不能选择的界面主题。目标版本为 `0.29.0-dev.1`；本次只改网页主题能力，Android `versionCode` 不递增。

## 目标

新增一个可保存、可即时切换的“旧网页”主题，呈现约 2000 年代末至 2010 年前后常见的门户/后台网页观感：明显的蓝色渐变标题栏、灰白分栏、紧凑列表、凸起式方按钮、传统蓝色下划线链接；不引入装饰性玻璃效果、胶囊按钮或额外功能模块。保留现有布局、交互、响应式断点和无障碍焦点状态。

## 实施步骤

1. 在主题类型和偏好恢复逻辑中加入新主题，不影响旧版本已保存的主题设置。
2. 在主题设置中增加“旧网页”选项及对应预览，并保持即时切换和本地持久化。
3. 为旧网页主题补充覆盖样式，统一覆盖应用外壳、导航、对话、文件区、输入区、菜单、弹窗和设置面板；使用现有布局，仅改变配色、边框、圆角、阴影和装饰。
4. 检查状态栏图标对比度及重要的按钮、禁用态、悬停态和键盘焦点态；主题样式不得串改其他主题。
5. 更新主题偏好测试，运行测试和生产构建，并按新增功能规则记录版本。

## 验收标准

- 设置中可选择“旧网页”，刷新后仍保留选择。
- 页面整体是清晰朴素的浅色经典网页风格，没有现代玻璃/强阴影装饰。
- 主要文字、链接、交互状态和键盘焦点清楚可辨，现有功能和响应式布局保持可用。
- 其他主题的外观和存储行为不变。
