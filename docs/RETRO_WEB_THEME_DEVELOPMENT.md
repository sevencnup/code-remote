# 旧网页主题开发说明

新增功能 / MINOR：增加一种此前不能选择的界面主题。目标版本为 `0.29.0-dev.1`；本次只改网页主题能力，Android `versionCode` 不递增。

## 目标

新增一个可保存、可即时切换的“旧网页”主题，桌面端参考最早期 WWW 文档页面：白色页面、浏览器默认衬线排版、朴素黑色正文和蓝色下划线链接，不使用侧栏仪表盘、卡片或现代装饰。聊天记录和文件等应用操作通过简单文字入口按需打开，不删除能力；手机端布局和无障碍焦点状态不变。

## 实施步骤

1. 在主题类型和偏好恢复逻辑中加入新主题，不影响旧版本已保存的主题设置。
2. 在主题设置中增加“旧网页”选项及对应预览，并保持即时切换和本地持久化。
3. 为旧网页主题补充覆盖样式，统一覆盖应用外壳、导航、对话、文件区、输入区、菜单、弹窗和设置面板；桌面端以默认 HTML 文档排版为主，应用功能按需打开。
4. 检查状态栏图标对比度及重要的按钮、禁用态、悬停态和键盘焦点态；主题样式不得串改其他主题。
5. 更新主题偏好测试，运行测试和生产构建，并按新增功能规则记录版本。

## 验收标准

- 设置中可选择“旧网页”，刷新后仍保留选择。
- 桌面默认视图是铺满页面的白底正文，不常驻显示侧栏或现代卡片模块；聊天记录、文件区和设置仍可通过文字入口访问。
- 主要文字、链接、交互状态和键盘焦点清楚可辨，现有功能和手机端布局保持可用。
- 其他主题的外观和存储行为不变。

## 最早期 WWW 纯文档风格（0.30.1-dev.3 / PATCH）

需求是将桌面旧主题进一步靠近参考图中的早期 WWW 页面，而非仅做 90 年代个人主页配色。只模拟网页内容区；浏览器菜单、工具栏和地址栏由浏览器控制，不在页面内仿造。

1. 桌面内容区恢复浏览器默认文档观感：纯白背景、约 8px 页面边距、Times 系衬线字体、原生标题/段落间距和蓝色下划线链接。
2. 去除常驻左侧导航、彩虹线、卡片、气泡、分隔装饰和仪表盘式外框；聊天文本像普通文档流一样排列。
3. 保留“聊天记录”“文件”等纯文字入口，按需打开现有功能；隐藏时不能影响焦点和操作可达性。
4. 只覆盖桌面端，不改变移动端布局；运行构建和测试并记录 PATCH 版本。

完成记录：桌面旧主题现以默认 WWW 文档的白底、8px 页面边距、衬线字、普通标题间距和蓝色下划线链接为基调；消息、输入区和按需打开的历史记录/文件区去除卡片式外观。正文字号继续跟随应用字号设置，移动端保持原样。`pnpm build` 通过；`pnpm test` 为 111 项中 107 项通过，4 项失败仍是既有客户端 data URL 模块解析错误和移动端 CSS 断言，与本次桌面主题改动无关。版本更新为 `0.30.1-dev.3`。
