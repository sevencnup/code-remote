# 自定义主题字体颜色修复开发文档

## 目标

让自定义主题选择的字体颜色覆盖输入框及表单控件，避免输入内容、占位提示和光标继续使用旧主题颜色而与背景融为一体。

## 实施步骤

1. 在自定义主题样式中统一覆盖可见表单控件的文字颜色。
2. 为消息输入框增加占位符、光标和移动端文字填充色的主题变量覆盖。
3. 保持颜色选择器、透明度滑块和隐藏文件选择器的原生交互样式。
4. 更新版本记录，执行生产构建和差异检查，并提交本地 Git 仓库。

## 验收标准

- 自定义主题修改字体颜色后，消息输入框中的文字立即使用新颜色。
- 输入框占位提示和光标与自定义字体颜色保持可读对比。
- 模型、思考、授权、发送和停止等控件的文字不再保留旧主题的固定颜色。
- 生产构建成功，`git diff --check` 无输出。
