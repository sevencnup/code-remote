# 网页字间距设置覆盖范围修复

## 问题与目标

`0.88.0-dev.1` 的字间距滑块只修改了继承字距。标题、侧栏标签、配对页及旧网页主题等位置有独立的 `letter-spacing`，拖动滑块时仍保持固定，因此“全局字间距”的描述不准确。

本次属于修复（PATCH），继续完善尚在开发阶段的 `0.88.0` 功能，版本为 `0.88.0-dev.2`。保持默认 2% 时的既有设计字距；调整滑块时让网页版普通界面文字整体跟随。代码块、终端与文件编辑器继续保持正常字距。设置仍按当前浏览器的显示偏好保存。

## 实施步骤

1. 列出网页版所有显式字距规则，确认需要排除的代码、终端与编辑器规则。
2. 从偏好值计算相对默认 2% 的字距变化，并传给应用根节点及脱离根节点的浮层。
3. 让界面文字的显式字距在原设计值上叠加该变化，包含不同主题与响应式规则；保留代码等距内容的排除规则。
4. 更新版本名与简短版本记录，构建网页并检查改动范围。
5. 更新当前预览使用的网页产物，仅提交本次文件到本地仓库。

## 验收标准

- 默认 2% 时，标题、侧栏、聊天正文及各主题沿用原来的字距。
- 调整滑块时，聊天、侧栏、设置页、配对页及相关浮层文字跟着变化。
- 代码块、终端和文件编辑器维持等宽排版；刷新后字间距选择保留。
- 网页构建通过，未跟踪的安装包不进入提交。
