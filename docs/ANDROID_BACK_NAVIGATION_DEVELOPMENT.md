# Android 分层返回开发文档

## 目标

让 Android 返回键和侧滑返回手势按网页当前打开的界面层级逐层关闭，避免用户在移动端打开侧边栏或菜单后直接退出 App。

## 返回层级

返回操作按以下顺序只处理一层：

1. 关闭输入框中的模型、思考强度或授权菜单。
2. 关闭对话记录的上下文菜单。
3. 关闭移动端侧边栏。
4. 关闭设置页面。
5. 若 WebView 有浏览历史，返回上一页。
6. 没有可关闭层时退出 App。

## 实施步骤

1. 让网页端暴露一个同步的返回处理函数，并在处理一层后返回 `true`。
2. 让输入框菜单通过同一个句柄关闭一层，避免 Android 原生层直接操作 React 状态。
3. 在 `MainActivity` 中通过 `evaluateJavascript` 调用网页处理函数；网页未处理时再使用 WebView 历史或退出 Activity。
4. 同时接入 Android 13 及以上的 `OnBackInvokedDispatcher`，让系统侧滑返回与实体返回键走同一条路径。
5. 更新版本记录，构建 APK，并在真机上验证每次返回只关闭一层。

## 验收标准

- 打开模型、思考或授权菜单后返回一次只关闭菜单。
- 打开右键上下文菜单后返回一次只关闭上下文菜单。
- 打开侧边栏后侧滑一次只关闭侧边栏。
- 打开设置页后返回一次只关闭设置页。
- 没有可关闭层时才退出 App。
- `pnpm build`、Android Debug APK 构建和 `git diff --check` 成功。
