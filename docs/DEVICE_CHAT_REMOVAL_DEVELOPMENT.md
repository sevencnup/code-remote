# 设备群聊功能移除开发文档

## 目标

移除 Code Remote 的跨设备群聊能力。保留普通 Codex / Claude Code 聊天、聊天记录、文件树、工作区和其他远程设备功能。

## 数据处理

删除群聊页面、客户端状态、API 和服务端运行逻辑；不主动删除或修改设备上的 `device-chat.sqlite3` 文件。移除功能后，历史群聊数据暂时保留在原位置。

## 执行步骤

1. 从主聊天页面移除群聊模式状态、侧栏入口、群聊面板、消息展示、群聊专属输入和工作区分支，恢复单聊使用普通聊天组件的路径。
2. 删除群聊专属前端组件、Hook、消息排序模块及 API 类型和客户端方法；清理只服务于设备群聊的样式和测试。
3. 从服务端移除群聊管理器的初始化、生命周期、请求模型、HTTP/WebSocket 路由及群聊专属模块和测试；确保普通会话接口不受影响。
4. 更新 README 中的功能说明、CHANGELOG 和项目版本。该变更移除了已发布功能，项目为 `0.x`，按仓库版本规则递增 MINOR 至 `0.73.0-dev.1`。
5. 搜索确认运行代码和用户文档不再提供设备群聊；执行必要的前端构建检查，不运行测试套件。
6. 本地提交改动。保留历史变更记录文档和运行时群聊 SQLite 文件。
