# Android 状态栏沉浸显示开发文档

## 目标

让手机网页主题背景延伸至 Android 状态栏区域，去掉白色主题顶部的深色横带，同时保持正文和浮层避开状态栏图标。

## 根因

Android WebView 外层容器为状态栏预留了顶部空间，窗口状态栏颜色又固定为深色。网页无法绘制到状态栏区域，浅色主题下因此出现深色空带。

## 实施步骤

1. Android WebView 页面绘制到状态栏后方；连接地址页保留原有安全边距。
2. 将原生状态栏高度传给网页，用于下移正文和保护固定侧栏、文件栏及配对页内容。
3. 根据当前界面主题设置状态栏图标明暗，覆盖明亮、暖色、深色和自定义主题。
4. 更新 Android 版本号和版本记录，构建网页并生成独立版本 APK。
5. 使用已提供的手机地址安装新 APK，确认安装成功，并创建仅包含本次修改的本地提交。

## 验收标准

- 状态栏背景与当前页面主题连续，白色主题不再出现深色横带。
- 状态栏图标与背景保持可读对比。
- 聊天标题、配对页内容和侧边浮层不被状态栏遮挡。
- 底部导航栏、键盘和输入框的现有边缘处理继续生效。
- 新 APK 使用独立版本名，历史 APK 保留。
