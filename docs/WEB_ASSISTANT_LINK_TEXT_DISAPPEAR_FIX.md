# 网页 AI 回复含链接时正文消失修复

## 问题与目标

当前 `MessageBubble` 只要发现 AI 回复中有 HTTP/HTTPS 链接，就给整条消息启用“仅显示链接”分支。流式回复前段文字能看到，后段出现链接时，整条消息的非链接正文会被隐藏。截图中的操作记录和两条 GitHub 地址仍在，符合该渲染分支的表现；原始消息没有被删除。

用户确认目标：保留 AI 回复的全部说明文字；HTTP/HTTPS 链接本身只显示纯网址并保持可点击。用户消息、代码块、操作记录与选择卡片继续按原规则显示。

这是修复（PATCH）：纠正现有显示规则导致的正文丢失。目标版本 `0.88.1-dev.1`。

## 实施步骤

1. 核对消息链接解析与普通正文、流式时间线和选择卡片的渲染路径。
2. 移除“只要有链接就隐藏整条正文”的渲染分支；在 AI 文本的行内链接上仅把链接标签改成网址，保留相邻文字、表格和代码块。
3. 更新简短版本记录及网页、Android 版本名，构建网页并检查差异。
4. 更新现有 4173 网页预览构建产物，仅本地提交本次文件，不推送远端。

## 验收标准

- AI 回复即使包含网址，流式过程中和回复结束后也保留全部正文。
- Markdown 链接显示原始网址，裸网址保持可点击；不改变复制消息的原始内容。
- 围栏代码块不自动改写，操作记录和选择卡片继续显示。
- 网页构建通过，提交不包含工作区既有未跟踪文件。
