# 网页侧边栏模式筛选开发

## 变更分类

新增功能 / MINOR：在已有的 Codex 与 Claude 混合聊天列表中增加按模式筛选入口，扩展聊天记录的浏览能力。当前版本为 `0.47.1-dev.1`，本次目标版本为 `0.48.0-dev.1`。

## 目标

在左侧栏“新建对话”按钮下增加 Codex、Claude 两个品牌图标筛选按钮。点击图标只显示对应模式的聊天，再次点击当前图标恢复全部聊天。筛选与搜索叠加，且不改变当前聊天或新建对话模式。

## 实施步骤

1. 在侧栏聊天列表过滤逻辑中加入模式筛选；将没有 `engine` 字段的旧会话按 Codex 处理，与现有会话行显示一致。
2. 在“新建对话”下方加入两个可访问的图标按钮，提供名称、提示和按下状态；活动筛选有清楚的视觉反馈。
3. 调整侧栏新增控制区的布局，兼容常规主题、复古主题、窄屏与触屏布局，不挤压聊天列表。
4. 添加筛选逻辑回归测试，验证 Codex、Claude、旧会话默认值、全部模式和叠加搜索行为。
5. 运行相关测试、`pnpm build` 与 `git diff --check`，更新版本与变更记录，仅本地提交本次修改。

## 验收标准

- Codex 图标只显示 Codex 会话；Claude 图标只显示 Claude 会话；再次点击已选图标恢复全部。
- 搜索词与模式筛选同时生效；筛选不会切换当前聊天或创建聊天。
- 旧会话的默认模式与现有列表图标一致，按 Codex 处理。
- 控件有可访问名称和明确活动状态，在桌面、手机及复古主题侧栏中均可辨认和操作。
