# 移动端图片与文件统一附件入口开发记录

## 目标

将移动端聊天输入区的图片和文件选择合并到同一个附件入口。用户可从一次文件选择中添加支持的图片、文档和源码文件。

## 实施步骤

1. 移动端使用一个原生文件输入控件，接收现有支持的图片类型和文档类型；桌面端保留现有文档选择范围。
2. 按文件类型将选择结果分发到现有图片读取/草稿保存流程或文档提取/PDF 上传流程，保留各自的校验、数量限制和模型能力提示。
3. 调整 Android WebView 文件选择器以遵循网页传入的 accept 类型，并保留多选能力，使混合附件入口可以选择文档和图片。
4. 更新 Android 应用版本元数据和 CHANGELOG；新增 APK 时使用未占用的文件名，不覆盖旧包。
5. 运行生产构建，检查差异格式，并提交本地 Git 仓库；不推送远端。

## 验收标准

- 移动端聊天输入区只显示一个附件入口。
- 同一入口可选 PNG、JPEG、WebP、GIF 和已有支持的文档/源码文件。
- 图片继续遵循模型支持、单张大小、数量限制和待发送草稿逻辑；文档继续遵循格式、大小、数量限制及原始 PDF 上传逻辑。
- Android WebView 文件选择器允许选择 accept 范围内的图片和文档，并可多选。
- 桌面端原有文档附件行为保持不变。
