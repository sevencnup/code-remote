# AI 群聊接入聊天工作区

## 需求分类

新增功能 / MINOR。群聊从独立弹窗改为主聊天区的一种可切换会话，并支持从侧边栏在群聊与普通聊天之间导航。

## 开发步骤

1. 将群聊视图改为普通工作区内容，不再使用遮罩层和模态对话框语义。
2. 让侧边栏群聊项切换主聊天区；选择普通会话时返回普通聊天区。
3. 普通会话暂时显示时保留当前群聊控制器挂载，使群成员已启动的回复仍能同步。
4. 在窄屏布局提供打开侧边栏的入口，并保留原有群聊成员、消息、发送和错误处理。
5. 递增 MINOR 版本，更新版本记录；执行前端生产构建并检查差异。
6. 只提交本次开发文档、前端改动和版本记录。

## 界面统一跟进

用户反馈上一版仍像独立聊天窗口。本次按修复 / PATCH 处理：群聊复用普通聊天的 `remote-chat`、`message-stream`、`chat-message` 和 `message-composer` 布局，只保留群聊必需的成员重命名、双模式状态和互相回应操作。版本更新为 `0.53.1-dev.1`。

开发步骤：

1. 将群聊头部、消息流、消息气泡和输入框改为普通聊天工作区使用的 DOM 与样式类。
2. 删除专用卡片式消息和输入框样式，保留群聊的成员、错误和接力能力。
3. 执行前端生产构建并检查差异，只提交本次前端和版本记录。

## 截图反馈跟进

截图显示空群聊时的输入区偏高，且底栏重复说明如何加入会话。本次按修复 / PATCH 处理：输入区高度恢复为普通聊天默认值，底栏仅显示简短连接状态。版本更新为 `0.53.2-dev.1`。
