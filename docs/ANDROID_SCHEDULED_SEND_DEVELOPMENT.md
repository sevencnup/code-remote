# Android 定时发送同步

## 目标

将网页端的定时发送能力接入 Android 原生聊天输入框，并让队列项显示预定发送时间。队列模型与思考等级只显示名称，不再显示中文字段前缀。

## 分类与版本

- 分类：新增功能 / MINOR。Android 用户可以定时发送此前无法完成的消息。
- 当前版本：`0.77.1-dev.1`，Android `versionCode 366`。
- 目标版本：`0.78.0-dev.1`，Android `versionCode 367`。
- 版本记录：`Android 支持定时发送消息`。

## 实现步骤

1. [x] 在 Android 输入栏增加定时发送入口，依次选择本地日期和时间，并拒绝过去时间。
2. [x] 将消息和 ISO 8601 时间戳提交到现有 `/api/v1/codex/queue/{threadId}/schedule` 接口；无活动聊天时先创建空聊天。
3. [x] 成功后清除输入草稿并刷新共享队列；失败时恢复文本和附件。
4. [x] 队列卡片显示本地预定时间；模型与思考等级仅显示名称，默认值显示 `Default`。
5. [x] 更新版本记录，构建独立 APK 并安装到 `10.126.126.2:5555`；核对安装版本并本地提交，不推送 GitHub。

## 完成情况

- `assembleDebug` 成功，包版本 `0.78.0-dev.1`、`versionCode 367`。
- 安装器确认更新成功，设备包信息与目标版本一致。
- 没有实际排入定时消息，避免往用户真实聊天中写入测试内容。

## 范围

服务端已经支持 `scheduledAt`、到期自动发送以及队列编辑/删除，本次不改服务端协议或网页端行为。
