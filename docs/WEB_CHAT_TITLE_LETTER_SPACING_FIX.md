# 网页聊天标题字间距修复

## 问题与目标

聊天列表条目使用 `button.thread-row` 包裹标题。浏览器对表单控件设置的默认字距会挡住页面根节点的继承字距，使左侧聊天标题没有随“字间距”滑块变化；并发聊天窗的标题也需要确认继续使用同一设置。

本次属于修复（PATCH），继续修正开发阶段的字间距功能，版本为 `0.88.0-dev.3`。

## 实施步骤

1. 核对左侧列表标题、并发聊天窗标题的 DOM 和字距规则。
2. 让普通按钮、输入框和下拉框继承设置字距；保留代码块、终端和文件编辑器的字距排除规则。
3. 检查标题相关样式的覆盖顺序，更新版本名与简短版本记录。
4. 构建网页、检查差异、更新当前预览产物，并仅本地提交本次文件。

## 验收标准

- 左侧聊天列表标题和并发聊天窗标题均随滑块变化。
- 默认 2% 时标题保持可读，代码、终端和编辑器排版不受影响。
- 网页构建通过，提交不包含既有未跟踪文件。
