# 网页字间距设置

## 目标与分类

在网页版设置页“字体大小”下方增加“字间距”滑块，让用户自行调整普通界面文字的疏密，并沿用现有显示偏好的即时预览与浏览器本地保存。默认值保持当前的 `0.02em`；旧偏好自动补齐默认值。代码块、终端和文件编辑器维持原有字距。

这是新增功能（MINOR）：用户获得原先没有的字间距调节能力。目标版本为 `0.88.0-dev.1`。本次不构建 Android 安装包。

## 实施步骤

1. 核对现有字体大小设置、偏好读写、网页默认字距及代码和终端例外规则。
2. 给显示偏好增加字间距字段，将输入限制在 0%～8%，默认 2%，并把设置值应用到网页和浮层。
3. 在“字体大小”正下方增加“字间距”滑块，调整时立即预览并保存。
4. 同步现有偏好测试数据的对象结构；更新网页、Android 的版本名和简短版本记录。
5. 构建网页、检查差异并更新当前预览使用的网页产物；仅暂存本次文件并本地提交，不推送远端。

## 验收标准

- 旧浏览器偏好和新用户默认显示 2% 字间距，与当前网页观感一致。
- 拖动滑块时聊天等普通界面文字立即变化，刷新页面后设置保留。
- 代码块、终端、文件编辑器不随字间距滑块改变。
- 网页构建通过，提交不包含工作区已有的安装包等未跟踪文件。
