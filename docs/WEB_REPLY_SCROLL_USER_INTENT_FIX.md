# 网页回复自动跟随误停止修复

## 用户可见变化与版本

- 分类：修复 / PATCH。已有回复自动跟随在内容变化时误停，修复后用户留在底部可持续看到新内容；主动上翻仍保留当前位置。
- 目标版本：`0.86.6-dev.1`。

## 原因

聊天区仅凭 `scrollTop` 变小判断用户主动上滑。流式回复、运行状态和消息布局改变高度时，浏览器自身也可能调整滚动位置，误将自动跟随关闭并显示“回到底部”。

## 实施步骤

1. [x] 记录滚轮、触摸拖动、鼠标拖动和键盘导航产生的向上滚动意图；仅在此类交互实际使聊天区离开底部时暂停跟随。
2. [x] 保持切换会话、新发消息和“回到底部”后的自动跟随；回复区域高度变化引发的滚动事件不改变跟随状态。
3. [x] 更新版本和简短版本记录；构建本机预览页面、静态检查改动并仅提交本地仓库。不新增或运行测试，等待明确指令再推送远端。

## 验收范围

- 底部等待回复时，新消息、操作记录和流式文字持续留在可视区域。
- 用户主动上滑后保持阅读位置；回到底部后恢复跟随。
- 多并发窗口各自维护滚动状态，互不影响。

## 完成记录

- 自动跟随只在用户向上滚动离开底部时暂停；跟随期间禁用浏览器滚动锚定，主动上翻后保留滚动锚定和阅读位置。
- `pnpm --filter code-remote build` 成功，现有 4173 预览服务读取新构建产物；未新增或运行测试。
