# 工作区文件管理开发文档

## 目标

为右侧工作区文件树补齐日常文件管理能力：新建文件、新建文件夹、重命名、删除、复制、剪切和粘贴。目标版本为 `0.15.0-dev.1`，属于新增功能。

## 设计边界

- 所有操作都以当前文件树绑定的服务端目录为边界，拒绝绝对路径、父目录穿越和越界符号链接。
- 新建和重命名不覆盖同名项目；复制、移动遇到同名目标时明确报错，避免静默覆盖。
- 删除支持文件、非空文件夹和多选项目，执行前显示永久删除确认。
- 复制和剪切使用当前文件树内的临时剪贴板；切换文件树根目录时清空，避免把相对路径错误应用到另一个根目录。
- 目录右键菜单可以在该目录中新建和粘贴；文件右键菜单提供复制、剪切、重命名和删除；文件树空白处与顶部新增入口操作根目录。
- 操作成功后只刷新受影响目录，并清理失效的展开、选中和预览状态。

## 实施步骤

1. 在服务端增加创建、重命名、删除和复制/移动工作区项目的请求模型、路径校验函数及 API。
2. 在浏览器客户端封装对应接口。
3. 扩展文件树右键菜单、根目录菜单和剪贴板状态，支持多选复制、剪切和删除。
4. 增加统一的新建/重命名输入对话框和删除确认对话框，并展示操作失败原因。
5. 操作后刷新源目录和目标目录，关闭指向已删除或已移动路径的预览。
6. 更新版本记录，执行 TypeScript/Vite 构建、Python 编译和差异检查，然后创建本地提交，不推送远端。

## 验收标准

- 可在根目录或任意子目录新建空文件和文件夹。
- 单个文件或文件夹可重命名，已存在同名项目时不覆盖并给出提示。
- 单选或多选项目可复制、剪切，再粘贴到目标文件夹。
- 单选或多选文件、非空文件夹可在确认后删除。
- 目录穿越、绝对路径、根目录删除以及复制到自身子目录等危险操作会被服务端拒绝。
- 成功操作后文件树及时更新；失败操作保留当前树并显示原因。
- 各主题与移动端布局中的菜单和对话框可正常使用。
