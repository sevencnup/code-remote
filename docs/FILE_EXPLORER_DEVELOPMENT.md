# 右侧文件资源管理器开发文档

## 目标

在桌面端聊天区最右侧增加类似 VS Code 资源管理器的文件树。文件树根目录跟随当前聊天窗口的 `cwd`，切换并发窗口时加载对应目录。文件可以拖入聊天输入框，作为文档附件随下一条消息发送。

## 方案

1. 后端提供受配对令牌保护的工作区目录和文件读取接口，只允许访问当前会话工作目录以内的路径，并限制目录深度、条目数量和文本文件大小。
2. 前端为每个聊天窗口读取并缓存自己的文件树；当前窗口切换时只显示当前窗口的树，避免多个窗口互相覆盖。
3. 资源管理器支持目录展开、文件选择、拖拽和文件右键菜单。文件拖入输入框或选择“加入当前对话”后读取文件内容；文件夹选择“加入路径到输入框”时只追加绝对路径，不读取整个目录。拖拽同时写入自定义 MIME 和带前缀的纯文本数据，兼容会清理自定义 MIME 的浏览器。
4. 移动端隐藏右侧面板，保留现有聊天布局和输入框行为。

## 实施步骤

1. 增加后端路径校验、目录树和文本文件读取接口。
2. 增加前端 API 类型、资源管理器组件和按窗口加载逻辑。
3. 扩展输入框拖拽区域，显示待发送文件并纳入发送请求。
4. 增加桌面端右侧布局及主题样式，移动端隐藏资源管理器。
5. 更新版本记录，执行 TypeScript/Vite 构建和差异检查，并创建本地 Git 提交。

6. 工作台进入聊天页后屏蔽浏览器原生右键菜单；资源树文件使用自定义菜单操作，避免右键时丢失“加入当前对话”入口。

## 限制

- 只读取文本类文件；二进制文件显示为不可预览，避免把大型二进制内容直接塞进提示词。
- 单文件和目录条目都有大小限制；文件树按目录懒加载。
- 后端不会接受工作目录外的绝对路径或 `..` 穿越路径。
