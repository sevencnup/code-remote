# Android 输入框主题描边与呼吸光晕

## 目标与分类

修复 / PATCH：调整已有输入框的明暗主题描边和运行时呼吸光晕，不改变输入行为。目标版本 `0.28.1-dev.11`，Android `versionCode 245`。

## 步骤

1. 对照网页版明暗主题输入框的描边和运行时渐变。
2. 分别设置浅色、深色、暖色和自定义主题的描边，避免共享显眼的亮色线条。
3. 增强运行时光晕的明暗变化，保持柔和渐变与输入框圆角裁剪。
4. 构建新 APK、安装到已连接手机并核对布局和版本；保留旧包，完成本地提交。

## 验收

- 白色主题输入框使用浅灰描边；黑色主题使用贴近深色背景的描边。
- 运行时能看见柔和、持续变化的光晕；停止后消退。
- 输入框保持底部位置，聊天区正常显示。

## 实施结果

- 修正描边绘制覆盖原始透明度的问题；浅色使用浅灰，深色使用接近输入框背景的深灰，暖色和自定义主题各自沿用对应颜色。
- 运行时光晕使用更宽的柔和渐变，并扩大 2.8 秒呼吸周期内的亮度变化；结束后仍淡出。
- `0.28.1-dev.11` / `versionCode 245` 已离线构建并覆盖安装。真机深色截图确认输入框仍在底部、聊天内容正常，系统报告版本正确；未向真实对话发送消息，运行中的光晕未做真机动态对比。
