# Android 聊天附件隔离与返回行为

## 需求

- 侧栏聊天行去掉三点及置顶图标，保留长按菜单中的打开、置顶、重命名、删除。
- 聊天主页面按返回键退到桌面，不显示关闭应用确认框，也不结束进程。
- 图片附件草稿按连接、模式和聊天隔离；发送与附件读取异步完成时不得写到后来切换的聊天。

## 实施

1. 检查聊天切换、模式切换、连接切换、附件选择及发送回调的状态流。
2. 将附件草稿按聊天上下文保存与恢复，约束异步回调；调整侧栏和返回处理。
3. 递增版本，构建独立 APK、安装核对并本地提交。

## 分类

修复与体验优化，目标版本 `0.25.2-dev.1`。用户原有任务未扩展，修正了附件跨聊天串用及操作入口。
