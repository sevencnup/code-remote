# DSH 风格前端改造开发文档

## 目标

在不改变现有 Codex Remote API、WebSocket 事件和配对流程的前提下，参考 DeepSeek Harness 的 Web UI 视觉语言，优化 `/code/codex-remote` 的桌面端和移动端聊天界面。

## 实施步骤

1. 盘点现有页面结构，保持会话、消息、审批、附件和输入框的业务组件不变。
2. 为应用补充统一的 DSH 风格设计变量，调整侧栏、标题栏、消息流、消息操作和输入区的层次与间距。
3. 增加轻量的工作区标识和当前模型提示，让标题栏和输入区的信息结构更接近 DSH。
4. 保持移动端抽屉、底部安全区和输入框横向留白规则，验证窄屏下不产生横向溢出。
5. 更新版本记录，执行生产构建与差异检查，并提交本地 Git 仓库。

## 验收标准

- 现有 Codex 对话、流式输出、审批、附件和发送流程行为不变。
- 桌面端侧栏、标题栏、消息卡片和输入框呈现统一的 DSH 风格层次。
- 移动端仍可打开侧栏，消息和输入框两侧保持 16px 留白，无横向滚动。
- `pnpm build` 成功，`git diff --check` 无输出。
