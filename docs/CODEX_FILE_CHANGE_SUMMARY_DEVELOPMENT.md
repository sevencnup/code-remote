# Codex 文件改动汇总卡片开发文档

## 目标

将同一轮 Codex 产生的多个文件改动汇总为一张接近官方 Codex 样式的卡片，展示修改文件数、总增删行数、逐文件路径与增删行数，并支持展开剩余文件和审核 diff。

## 技术边界

- 使用 App Server `fileChange` item 已提供的路径、diff 和状态，不额外扫描工作区。
- 同一路径在一轮内被多次修改时合并为一行，并累加增删行数。
- 默认显示前三个文件，剩余文件通过卡片底部按钮展开或收起。
- “审核”在当前页面展开或收起各文件的 diff。
- 不提供虚假的“撤销”按钮；App Server 的 `thread/revert` 只撤回对话历史，不会恢复本地文件。

## 实施步骤

1. 将消息流中的多个文件改动卡片改为单张轮次汇总卡片。
2. 在卡片组件内按文件路径合并改动并计算总增删行数。
3. 实现前三项预览、剩余文件展开、diff 审核和进行中状态。
4. 调整桌面端与移动端样式，使卡片结构、间距、颜色和操作区接近 Codex。
5. 更新版本记录，执行生产构建和差异检查，并创建本地 Git 提交。

## 验收标准

- 同一轮的多个 `fileChange` item 只显示为一张卡片。
- 卡片顶部显示文件总数与总增删行数。
- 每个文件行显示路径及该文件的增删行数。
- 超过三个文件时可以展开和收起剩余文件。
- 点击“审核”可以查看或收起 diff；没有 diff 的文件显示改动类型。
- 移动端路径不会挤压增删统计或溢出卡片。
- `pnpm --filter codex-remote build` 成功，`git diff --check` 无输出。
