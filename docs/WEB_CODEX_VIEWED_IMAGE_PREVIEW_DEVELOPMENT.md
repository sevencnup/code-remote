# 网页预览 Codex 查看过的图片

## 分类

PATCH：修复已有的“打开图片”入口无法预览工作区外图片的问题，不改变用户可完成的任务。目标网页版本：`0.44.1-dev.1`。

## 目标

网页可打开 Codex 在当前会话中通过 `imageView` 查看过的图片，包括工作目录外的路径。服务端必须从该会话的 Codex 历史确认图片路径后才读取图片，不开放任意绝对路径访问。

## 步骤

1. 为图片预览新增会话关联的请求入口，读取指定 Codex 会话历史并确认请求路径出现在 `imageView` 操作中。
2. 仅在历史路径匹配后读取图片，并沿用受支持的图片格式、大小和内容签名校验。
3. 网页从图片操作记录打开预览时传递原始路径和会话编号；工作区文件树及聊天附件的预览流程保持现状。
4. 将网页版本递增至 `0.44.1-dev.1` 并记录变更。
5. 检查最终差异与路径授权边界；本次不新增或运行测试。

## 验收

- [x] 当前会话 `imageView` 记录中的图片路径可在网页预览，包括工作目录以外的图片。
- [x] 未出现在指定会话 `imageView` 历史中的绝对路径仍不可读取。
- [x] 图片格式、大小及内容签名校验仍然生效。
- [x] 工作区内图片与托管聊天图片预览继续使用原有入口。
