# 终端长选区转文档附件开发文档

## 目标

终端右键“粘贴到输入框”时，短选区继续插入输入框光标处；长选区复用输入框现有的长文本转文档附件行为，避免把大量终端内容直接塞进草稿。

## 交互与约束

- 复用 Composer 的 `longPasteThreshold`（4,000 字符）：少于阈值时保留现有光标插入行为，达到或超过阈值时添加 `terminal-output.md` 文档附件。
- 长选区沿用 Composer 已有文档附件数量限制、去重、提示和发送流程。
- 添加长选区附件时保留输入框已有草稿及其他附件，不自动发送。
- 不修改终端连接、选区或右键菜单行为。

## 实施步骤

1. 在 `CodexRemotePage` 的终端文本回调中按现有阈值分流短文本与长文本，长文本通过 Composer 的 `addDocumentAttachment` 加入附件。
2. 更新开发文档、`CHANGELOG.md`、`package.json` 与 Android `versionName`；Android `versionCode` 递增 1。本次属于新增能力，版本从 `0.5.0-dev.1` 递增到 `0.6.0-dev.1`。
3. 执行 `pnpm build` 和 `git diff --check`；不新增或运行测试。
4. 仅提交本次相关文件到本地 Git，不推送 GitHub；保留已有的 Android 开发文档修改。

## 验收标准

- 3,999 字符及以下的终端选区仍插入输入框当前光标处。
- 4,000 字符及以上的终端选区显示为 `terminal-output.md` 文档附件，不进入输入框正文。
- 长选区处理后，已有输入框草稿和其他附件保留，消息不会自动发送。
- 生产构建与差异检查通过。
