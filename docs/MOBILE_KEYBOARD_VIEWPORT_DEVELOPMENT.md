# 移动端键盘视口布局开发文档

## 目标

修复 Android WebView 唤起输入法后，输入框下方出现大块空白的问题，让输入框继续贴在键盘上方。

## 根因

Android WebView 在输入法显示时可能保持布局视口高度，同时把可视视口通过 `offsetTop` 向上平移。页面只使用 `visualViewport.height` 设置应用高度时，应用高度会缩短一次，而可视区域仍保留原布局底部，因而在输入框和键盘之间留下空白。

## 实施步骤

1. 计算视口高度时同时考虑布局视口高度和可视视口的偏移量。
2. 键盘导致可视视口发生平移时，保留布局视口底部作为应用底部；键盘只缩小可视视口而没有平移时，使用缩小后的高度。
3. 构建网页资源和 Android APK，安装到已连接真机。
4. 在输入框获得焦点、键盘显示和键盘收起三种状态下检查输入框位置与可用空间。
5. 更新版本记录并创建本地 Git 提交。

## 验收标准

- 键盘显示时输入框底部贴近键盘顶部，不出现大块空白。
- 输入法仍能正常唤起、输入候选词并发送消息。
- 键盘收起后页面恢复完整高度。
- 旧版本 APK 保留，新 APK 使用独立版本号。
