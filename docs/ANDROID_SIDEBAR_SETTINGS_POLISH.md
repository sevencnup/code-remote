# Android 侧栏与设置视觉优化

## 目标

- 聊天长按菜单打开和关闭更顺畅，实时更新不打断菜单操作。
- 设置页在白色主题下使用浅灰页面、纯白分组和无描边按钮；其余主题保留相应色彩。
- 侧栏底部设置、切换配置、重连三个按钮等宽且内容居中。

## 侧栏重连按钮复用已保存配对（后续打包 / PATCH）

侧栏底部“重连”误打开匹配码输入框，重复了重新配对流程，也没有按按钮含义恢复现有连接。修正为使用当前已保存的地址和令牌验证连接、重建 WebSocket 并刷新聊天数据；仅在服务端确认令牌失效时要求重新配对。此为既有操作入口修正，归类为 PATCH；按用户要求本次不打包。

1. 点击侧栏“重连”时复用当前连接配置，不弹匹配码输入框。
2. 验证连接后刷新状态、对话列表、当前聊天和队列，并重新建立 WebSocket。
3. 服务不可达时保留配对信息并继续自动重试；只有 401 配对失效时回到配对流程。
4. 后续打包时检查重连、数据刷新和失效配对的提示。

## 步骤

1. 检查长按菜单、侧栏刷新和设置页分组的绘制逻辑。
2. 减少菜单关闭时同步重建聊天列表，给菜单增加短时过渡。
3. 调整设置页卡片和选中项的背景，统一底部按钮的布局权重。
4. 递增修复版本，构建独立 APK，在手机上检查菜单、设置和底栏，再提交本地仓库。
