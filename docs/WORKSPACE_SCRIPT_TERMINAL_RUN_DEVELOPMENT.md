# 文件树脚本终端运行开发文档

## 目标

在右侧文件树的脚本文件右键菜单中增加“终端运行”。点击后打开当前聊天对应的本机终端，以脚本所在目录为工作目录，自动执行脚本并显示输出。

## 范围与约束

- 只在单选、已识别的脚本文件上显示入口。首批支持 Python（`.py`）、Node.js（`.js`、`.mjs`、`.cjs`）、Shell（`.sh`）、PowerShell（`.ps1`）以及 Windows 批处理（`.bat`、`.cmd`）。不猜测没有明确运行方式的文件。
- 根据终端实际 shell 生成命令，始终正确引用路径；拒绝控制字符及无法安全引用的路径。
- 每次“终端运行”开启独立的非持久终端会话，避免把命令送到已有终端中正在运行的程序或尚未提交的输入。脚本输出仍在现有终端界面显示；关闭运行窗口会结束该专用会话。
- 原有目录“添加到终端”行为保持不变：只填入切换目录命令，不自动执行。
- 终端连接失败时不执行脚本；重连不自动重复运行同一脚本。

## 实施步骤

1. 扩展文件树右键菜单与终端请求，区分添加目录和运行脚本。
2. 根据脚本路径选择解释器并生成适配 bash/zsh/sh、PowerShell、cmd 的安全命令。
3. 在终端连接就绪后只执行一次脚本命令，运行时使用脚本所在目录。
4. 更新版本和版本记录，执行构建并检查资源；创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 支持的单个脚本文件显示“终端运行”；目录、多选及其他文件不显示。
- 点击后终端打开，工作目录是脚本所在目录，命令自动提交，输出可见。
- 路径包含空格或引号时不会改变命令含义；不安全路径不执行。
- 现有终端中的正在运行程序不会收到脚本命令；终端重连不会重跑脚本。
- 目录“添加到终端”仍只把命令放入输入行。
