# AI 群聊成员点名与配置指令开发文档

## 目标

让群聊成员的自定义名称在实际对话中可用。用户点名某个成员时只向该成员发送消息；用户按名称要求切换模型或思考等级时，由网页匹配成员及其可用选项并直接保存设置，不依赖模型自行理解昵称或修改会话配置。

## 范围与决策

- 每次发给群成员的提示都说明当前成员和另一成员的自定义显示名称，以及对应的实际引擎身份。
- 消息以 `@成员名称` 或成员名称开头时视为点名，只路由给匹配的成员；未点名仍并发发送给两边。
- 成员名称匹配不唯一时提示用户消歧，不发送消息。
- 识别明确的模型或思考等级配置指令时，网页将值映射到该成员当前可用选项，并更新该成员关联聊天的偏好。配置请求不调用模型。
- 不支持的模型、当前模型不支持的思考等级、或含糊的配置指令会显示错误并停止发送；自然语言权限修改会提示用户通过现有设置面板显式选择，不传给模型。
- 普通点名消息保留原文并只发送给被点名成员；不带成员名称的普通消息保持双发行为。
- 本次属于 MINOR / 新增功能；版本从 `0.54.0-dev.1` 更新至 `0.55.0-dev.1`，更新 CHANGELOG。

## 实施步骤

1. 扩展群聊面板：生成成员身份上下文、解析名称前缀、按目标成员路由消息。
2. 解析可用模型/思考等级的明确设置命令，校验选项后更新对应聊天偏好，并在群消息流显示结果。
3. 为重名、无效选项和无效配置增加可见反馈，并提示可用的命令格式。
4. 更新 package 版本和 CHANGELOG。
5. 运行 `pnpm build` 与 `git diff --check`；不新增或运行测试。
6. 检查差异并本地提交本次跟踪文件，不推送 GitHub；保留现有未跟踪 APK 和部署产物。

## 验收标准

- 对某成员的点名消息只进入对应引擎；未点名消息仍同时进入两个引擎。
- 每个引擎收到的提示都能知道自己的群聊昵称及另一成员昵称。
- 自定义昵称可定位模型/思考等级设置，并保存到正确的关联聊天。
- 重名或无效设置不会误发给任何成员。
- `pnpm build` 成功，`git diff --check` 无输出。
