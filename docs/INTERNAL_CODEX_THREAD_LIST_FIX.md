# Codex 内部子任务误显示为聊天修复

## 问题与目标

APP 侧边栏出现 UUID 标题的新聊天，内容只有 AI 的子任务报告。截图对应的会话在 Codex 索引中明确记录了 `source.subagent.thread_spawn`、父会话和 `/root/inspect_logo_corner`。共享列表接口合并本地历史与运行时会话时，没有排除内部子任务。

目标是在网页与 Android 共用的列表接口中隐藏内部子任务和审核任务，正常聊天、手动分支、历史读取与主聊天回复保持可用。不会删除或改写用户的历史文件。

## 分类与版本

- 修复 / PATCH：恢复聊天列表的正确范围，不新增用户能力。
- 目标版本：`0.90.8-dev.1`。同步 Android 版本名，不生成 APK，`versionCode` 保持 `390`；问题位于共享服务端。
- 在 `CHANGELOG.md` 记录简短的用户可见修复描述。

## 实施步骤

1. 根据真实会话来源、子任务路径和父子生成关系识别内部会话，兼容旧版无相应字段的索引。
2. 在扫描文件时缓存第一条会话元数据的内部标识；列表合并后再次过滤，避免运行时记录把子任务加回来。
3. 增加有针对性的回归测试：本地索引、纯文件、运行时分页、审核任务、普通分支、离线回退、直接读取历史。
4. 运行相关测试并用真实截图会话做只读验证；更新版本并本地提交。
5. 根据当前服务运行情况安排安全启用。服务重启会终止当前回复，必须等待运行中的聊天完成后再重启，并核对健康状态。
