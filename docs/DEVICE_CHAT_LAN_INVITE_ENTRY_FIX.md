# 设备群聊局域网加入入口修复

## 用户可见变化与分类

在房间设备侧栏直接展示局域网链接和设备加入码，并提供可编辑的地址与复制操作。加入设备仍使用链接和一次性加入码连接。已有连接能力因地址隐藏、`localhost` 无法跨设备使用而不易完成，属于体验优化 / PATCH，目标版本 `0.69.1-dev.1`。

## 实施步骤

1. 房间侧栏将“连接另一台设备”置于成员和聊天记录选择之前，展示可编辑的房间网页地址、复制地址、加入码及重新生成入口。
2. 页面通过局域网地址访问时预填当前地址；通过 `localhost` 或回环地址访问时，由后端提供本机局域网 IP 候选并预填可用地址，允许手动修改，不复制无效的回环链接。
3. 在未加入房间的设备侧栏明确说明应打开该设备自己的 Code Remote 网页，并填写房间设备地址和设备加入码；区分网页登录配对码与设备加入码。
4. 更新版本记录与版本名，执行 TypeScript 检查、前端构建和差异检查，提交本地仓库。按此前用户要求推送 Gitea，不推 GitHub。

## 验收

- 创建房间后，不翻找按钮即可看到可分享的地址和加入码。
- 本机从 `localhost` 打开时，UI 不会把该地址当作跨设备链接复制。
- 加入设备能在自己的网页中填写地址与加入码，原有连接 API 和消息流程保持可用。

## 验证结果

- 本机房间创建测试确认邀请码和局域网地址候选进入状态响应。
- TypeScript 检查、Vite 生产构建、Python 编译检查和差异检查通过。
