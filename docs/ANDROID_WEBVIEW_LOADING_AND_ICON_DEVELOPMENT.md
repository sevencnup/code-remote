# Android 网页加载与图标修复开发记录

## 目标

修复手机端停在“正在加载电脑网页…”且无法自行恢复的问题，并将项目图标实际打入新的 Android 安装包。

## 已确认现象

- 手机已安装的 0.0.85 APK 构建于图标资源更新之前，因此仍显示旧图标。
- 手机经局域网地址可取得网页入口、Vite 脚本和图标；卡住时 WebView 文档停在 `interactive`、React 根节点为空，`onPageFinished` 未触发。
- 同一 WebView 从手机端重新加载后可以进入聊天页面，说明原生加载遮罩必须独立处理“完成回调永不到达”的情形。

## 实施步骤

1. 为 WebView 增加独立于 `onPageFinished` 的页面挂载检测：React 根节点就绪即可移除遮罩。
2. 加入加载超时状态，提供重新加载和修改电脑地址的入口；失败后仍允许页面稍后成功挂载。
3. 更新 Android 版本号，使用现有项目图标资源构建不覆盖历史文件的新 APK。
4. 更新版本记录，构建并安装到当前连接的手机，检查图标、页面加载和重试入口；最后创建本地 Git 提交，不推送远端。

## 验收标准

- 网页实际加载成功时不再被原生遮罩挡住。
- 加载持续不成功时不会无限只显示“正在加载”，能重试或修改地址。
- 手机上安装的是新版本 APK，显示项目图标且保留原有配对数据。
