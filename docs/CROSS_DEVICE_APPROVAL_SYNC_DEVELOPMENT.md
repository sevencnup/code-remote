# 跨设备审批同步开发文档

## 目标

保留审批请求跨聊天提醒的能力，同时明确请求所属对话；任一设备完成批准、拒绝或取消后，其他设备立即关闭同一请求。

## 根因

- Codex Remote 会向所有已连接设备广播审批请求，方便用户在当前页面及时处理。
- 服务端收到审批决定后只从本机待处理表删除请求并回复 Codex，没有向其他浏览器广播“已处理”事件。
- 审批卡没有展示来源对话，因此跨聊天出现时容易被误认为串台。

## 实施步骤

1. 从审批参数及当前活动轮次补全来源对话 ID。
2. 服务端成功提交决定后广播带请求 ID 的审批完成事件。
3. 前端所有窗口按请求 ID 清理审批卡，避免清掉随后到达的其他请求。
4. 审批卡展示来源聊天名称，并支持点击打开来源聊天。
5. 切换或新建聊天时保留全局审批提醒，直到请求被处理或运行时关闭。
6. 更新开发版本和版本记录，完成构建与差异检查后创建本地提交。

## 验收标准

- 其他聊天触发审批时，当前页面仍能收到提醒，并明确显示来源聊天。
- 在电脑或手机任一端处理后，另一端的同一审批卡立即消失。
- 重连设备不会重新收到已经处理的审批。
- 多个请求相邻到达时，完成旧请求不会误清除新请求。
