# 聊天记录自定义名称开发文档

## 目标

允许用户为 Codex 会话设置自定义名称，并在聊天记录列表和当前会话标题中显示；名称应保存在 Codex 会话中，在同一服务连接的手机、电脑及刷新后保持一致。

## 约束

- 优先使用 Codex App Server 对会话名称的正式接口，不把名称只存在浏览器本地。
- 仅配对认证用户可重命名；由 Codex App Server 校验会话 ID，并限制名称长度、空白和控制字符。
- 不改变会话 ID、工作目录、消息历史或 Codex 自动生成的消息内容。
- 现有聊天记录右键/长按菜单应增加重命名入口；编辑时提供确认和取消，并保留清晰的失败提示。
- 不推送 GitHub，修改完成后按项目约定创建本地提交。

## 实施步骤

1. 已通过当前 Codex App Server JSON Schema 确认会话改名方法为 `thread/name/set`，参数为 `threadId`、`name`，会话列表通过 `thread/name/updated` 通知同步；已按该协议接入。
2. 已在后端增加配对认证的会话改名接口，规范化空白，限制 72 个字符并拒绝控制字符，再调用 App Server。
3. 已在前端客户端和会话控制器接入改名请求；成功后即时更新列表、活动标题和本地缓存，并处理服务端异步通知。避免在改名后立即重拉列表，以免读到短暂的旧名称覆盖新值。
4. 已在聊天记录上下文菜单中加入“重命名”；电脑可右键，移动端可长按。输入界面支持确认/取消、失败提示以及 Escape/Android 返回键关闭。
5. 已增加 App Server、后端 API 和前端客户端测试；执行生产构建、前端测试、后端测试和 `git diff --check`。
6. 已更新 `CHANGELOG.md` 的 `0.0.180` 记录；验证完成后创建本地 Git 提交，未经用户明确要求不推送。

## 验收标准

- 用户能从聊天记录菜单设置会话名称，并能在手机和桌面端看到相同名称。
- 刷新或重新连接后名称仍然保留，活动会话标题与聊天列表一致。
- 空名称、过长名称或 App Server 拒绝时显示明确错误，不误改本地状态。
- 不影响会话切换、并发打开、自动生成名称和既有上下文菜单功能。
