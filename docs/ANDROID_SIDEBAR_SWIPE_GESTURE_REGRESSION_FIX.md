# Android 侧栏滑动手势回归修复

## 目标

恢复 Android 聊天区域内向左/向右滑动打开侧栏和文件树，同时继续保护输入框、字体滑杆及文本选择手势。

## 根因与方案

根视图将普通聊天 `ScrollView` 和可选择文本也判定为必须独占触摸的交互目标，导致侧滑手势在聊天区域起手时被取消。普通聊天区的竖向滚动不会与水平侧滑方向冲突；文字长按仍可发起选择。编辑框、滑杆、横向滚动条及可点击控件继续保留自己的触摸序列。

## 实施步骤

1. 从侧滑手势排除条件中移除普通 `ScrollView`。
2. 保留编辑、滑杆、横向滚动及文本选择的手势保护。
3. 更新 PATCH 版本和简短版本记录，构建新的 Android debug APK，安装到已连接设备，检查差异并提交本地 Git；不强行切换设备前台应用。

## 验收标准

- 从聊天内容区域水平滑动可打开左右侧栏。
- 聊天区域竖向滚动正常。
- 输入框编辑、滑杆拖动及文字长按选择仍能完成。
