# 用户消息右边缘布局开发文档

## 目标

让用户发送的消息在桌面宽屏中保持合理的右侧留白，同时避免回到原先过窄的消息行；移动端继续使用聊天区域的正常页面边距。

## 根因

用户消息最初沿用了普通消息的 `900px` 最大行宽，在宽屏中右侧空白过大。首次修复将消息行直接放宽到 `100%`，又使气泡紧贴聊天区域右边缘。消息行需要在这两个尺寸之间设置独立的桌面宽度。

## 实施步骤

1. 为桌面端用户消息行设置比正文更宽的上限，并始终预留最小两侧空间。
2. 保持气泡靠右，不改变气泡自身的内容宽度和最大宽度。
3. 移动端取消额外桌面留白，继续使用消息流现有页面边距。
4. 更新内部测试版本并执行网页生产构建。
5. 创建本地 Git 提交，不推送到 GitHub。

## 验收标准

- 桌面宽屏中的用户气泡不会贴到聊天区域最右边框，也不会出现原先的大块空白。
- 移动端用户气泡继续按消息流边距靠右显示。
- 短消息仍保持内容宽度，不被拉伸成整行。
- 长消息换行、图片消息和复制按钮功能不受影响。
