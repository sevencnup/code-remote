# 用户消息右边缘布局开发文档

## 目标

让用户发送的消息气泡右边缘与底部输入框右边缘对齐，并在桌面端和移动端保持一致的布局基准。

## 根因

用户消息原本沿用普通消息的 `900px` 内容宽度，这一宽度和输入框的 `900px` 上限及两侧边距一致。将用户消息行单独放宽到整个聊天区域后，气泡失去了输入框的对齐基准并贴近右边框；另设折中宽度同样无法保持准确对齐。

## 实施步骤

1. 让用户消息行继续使用普通消息行的宽度和居中规则，使其右边缘与输入框一致。
2. 保持气泡靠右，不改变气泡自身的内容宽度和最大宽度。
3. 移动端继续使用消息流和输入框现有的相同页面边距。
4. 更新内部测试版本并执行网页生产构建。
5. 创建本地 Git 提交，不推送到 GitHub。

## 验收标准

- 桌面端和移动端的用户气泡右边缘均与输入框右边缘对齐。
- 调整聊天区域宽度时，用户消息和输入框继续使用同一条右侧基准线。
- 短消息仍保持内容宽度，不被拉伸成整行。
- 长消息换行、图片消息和复制按钮功能不受影响。
