# 用户消息右边缘布局开发文档

## 目标

让用户发送的消息气泡右边缘与消息流和输入框的可用右边界对齐，消除消息行最大宽度造成的额外右侧空白。

## 根因

用户消息沿用了普通消息的 `900px` 最大行宽，并在消息流中居中。气泡虽然在这一行内右对齐，但整行右边界没有跟随消息流容器，宽屏或部分移动端视口下会出现额外空白。

## 实施步骤

1. 只放宽用户消息行，不改变用户气泡自身的内容宽度和最大宽度。
2. 让用户消息行占满消息流可用宽度，并取消额外的自动居中外边距。
3. 保持气泡靠右，继续与输入框的水平边距一致。
4. 更新版本记录并执行网页生产构建。
5. 创建本地 Git 提交，不推送到 GitHub。

## 验收标准

- 用户气泡右边缘贴合消息流可用右边界。
- 短消息仍保持内容宽度，不被拉伸成整行。
- 长消息换行、图片消息和复制按钮功能不受影响。
