# 移动端代码选区备注框避让开发记录

## 目标

修复移动端“添加到对话”备注框覆盖代码选区的问题，让用户输入备注时仍能看见刚选中的内容。

## 交互约束

- 移动端备注框采用紧凑高度，减少遮挡面积。
- 有可测量的文本选区时，优先将备注框放到选区下方；空间不足时放到上方，并限制在屏幕范围内。
- 桌面端原有菜单定位不变。
- 文件预览编辑器中的选区也应按所选行估算位置；选区不可测量时才回退到触发点。

## 实施步骤

1. 增加可测试的选区菜单定位逻辑，依据屏幕尺寸、菜单高度和选区上下边界选择放置位置。
2. 从预览文本选区或编辑器所选行获取定位边界，并仅在移动端启用避让定位。
3. 调整移动端备注框高度和样式，补充定位测试。
4. 更新版本记录，运行测试、生产构建和差异检查后创建本地提交；不推送 GitHub。

## 验收标准

- 选区下方空间足够时，菜单完全移到选区下方。
- 下方放不下时，优先放在选区上方；菜单仍限制在可视屏幕内。
- 移动端备注框明显变矮，桌面端外观和行为保持不变。
