# 桌面网页版新建对话入口调整

## 目标与分类

将桌面网页版左侧边栏的“新建对话”按钮移到聊天输入框左下角，并使用聊天气泡加号图标。属于 PATCH / 体验优化：新建对话能力不变，只调整入口位置与识别图标。目标版本为 `0.56.4-dev.8`。

## 交互要求

- 桌面宽度下，输入框左下角提供图标按钮；无论 Codex 或 Claude 模式，均为当前选中的面板创建对应模式的新对话。
- 按钮继续沿用现有连接、加载中和 Claude 可用性禁用条件，并提供可访问名称与悬浮说明。
- 桌面左侧边栏保留模式筛选，仅隐藏原新建按钮。
- 移动端沿用左侧边栏中的原按钮，不额外在输入框添加按钮。
- 新按钮使用聊天气泡与加号组合图标，并适配现有主题与 Claude 模式强调色。

## 实施步骤

1. 在输入框底部操作区加入新建对话入口，并连接现有当前面板创建逻辑。
2. 按桌面/移动宽度控制输入框与侧边栏入口显示状态，适配主题样式。
3. 更新版本和 CHANGELOG；运行生产构建及差异检查，不新增或运行测试。
4. 检查差异并创建仅包含本次修改的本地提交，不推送 GitHub。

## 验收标准

- 桌面宽度下边栏不显示新建按钮，输入框左下角显示组合图标；创建后的对话使用当前模式。
- 移动端侧边栏新建入口保持可用，输入框不出现重复入口。
- Codex、Claude、Retro、Pixel 等主题下按钮可辨识。
- `pnpm build` 成功，`git diff --check` 无输出；不新增或运行测试。
