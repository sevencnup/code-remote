# Android 终端键盘布局与滚动修复

## 目标与分类

修复 Android 终端在键盘弹出和收到 PTY 输出时上下跳动的问题。键盘弹出时，终端面板应跟随聊天输入框上移并缩小；用户手动滚动查看内容后，新输出不能把视口强行拉回底部。压缩终端底部快捷键区，给终端内容留下更多空间。

本次属于修复 / PATCH：改善现有终端的布局稳定性和可见性，不改变用户能完成的任务。目标版本 `0.62.0-dev.3`，Android `versionCode 327`。

## 实施步骤

1. 在每次窗口插入更新和 IME 动画帧中，同步终端浮层底边到聊天输入框顶部。
2. 终端仅在更新前已接近底部时自动跟随 PTY 输出；用户手动滚动期间及离开底部后保留其滚动位置。
3. 移除限制终端视口高度的最小高度，并压缩底部方向键和“复制到输入框”区域。
4. 更新 Android/package 版本和变更记录，构建新 APK 并检查键盘动画、布局和滚动行为；不向真实 PTY 发送测试命令。
5. 检查差异并创建仅包含本次修改的本地提交，不推送 GitHub，不覆盖历史 APK。

## 验收标准

- 键盘上升或收回时，终端面板随聊天输入框同步缩小或扩展，底部控制区保持在可见范围内。
- 手动向上滚动后，收到终端输出不会强制跳到底部；位于底部时仍可自动跟随新输出。
- 终端底部控制区比现有布局更紧凑，键盘打开时留给输出内容的高度增加。
