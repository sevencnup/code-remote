# Android 聊天链接打开

## 目标

让 Android App 中的助手 Markdown 链接和消息里的普通网址可以点击，并交由 Android 系统按设备上可用的应用打开。

## 步骤

1. 为助手 Markdown 文本启用链接点击处理，覆盖普通消息和操作时间线中的助手内容。
2. 将用户消息中的普通网址转换为可点击链接，同时保留文本选择。
3. 让外部链接使用 Android 的 `ACTION_VIEW` 应用解析器；多个应用可用时由系统提供打开方式选择。
4. 后续打包时检查助手 Markdown 链接、用户文本网址及无浏览器处理器时的错误反馈。

分类：PATCH / 修复已有聊天消息中的链接点击行为。

## 完成记录
