# Android 聊天链接打开

## 目标

让 Android App 中的助手 Markdown 链接、助手正文裸网址和用户消息普通网址都可以点击，并由 Android 系统交给浏览器打开。

## 步骤

1. 为助手 Markdown 文本启用链接点击处理，覆盖普通消息和操作时间线中的助手内容。
2. 将助手与用户消息里的普通网址转换为可点击链接，同时保留文本选择。
3. 裸域名补为 HTTP(S) 网页链接，并使用 Android 的 `ACTION_VIEW` 解析；多个应用可用时由系统提供打开方式选择。
4. 后续打包时检查助手 Markdown 链接、助手裸网址及用户文本网址的跳转行为。

分类：PATCH / 修复已有聊天消息中的链接点击行为。

## 完成记录

- 助手 Markdown 链接和操作时间线中的助手正文已启用点击，由 Android 系统按 `ACTION_VIEW` 解析可用应用。
- 助手正文里的普通网址通过 Markwon Linkify 自动识别；没有协议的 Markdown 链接由 Markwon 补为 HTTPS。
- 用户消息中的普通网址已自动识别并启用点击，链接使用当前模式强调色，裸域名由 Android Linkify 转成 HTTP(S) 链接。
- 多个浏览器或网页处理应用可用时由 Android 显示系统选择器；具体是否直接打开默认浏览器由设备的默认应用设置决定。
- 本次未构建或安装 APK；真机确认和版本号递增留到后续打包时完成。归类为修复 / PATCH，因为恢复了聊天中已有链接的预期打开行为。
