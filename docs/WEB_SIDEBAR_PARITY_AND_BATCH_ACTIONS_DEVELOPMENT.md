# 网页侧边栏视觉与批量操作开发

## 目标

网页侧边栏沿用 Android APP 的主要视觉层级：搜索与新建对话突出，聊天按置顶和时间分组，当前聊天有清晰选中态。新增选择模式，允许批量置顶及批量删除。移动网页版侧滑或点击打开侧栏时收起聊天输入法，保留草稿。

## 实施步骤

1. 核对网页版会话列表、单条置顶/删除、侧栏手势和 Android 批量操作的现有行为。
2. 调整网页版会话列表的分组与侧边栏样式，分别适配桌面紧凑密度和移动触控尺寸，以及已有主题。
3. 增加会话选择状态、选择入口和批量操作栏；批量置顶复用现有持久化行为，批量删除使用确认流程并处理部分失败。
4. 在移动网页版侧栏由按钮、侧滑或程序入口打开时收起当前聊天输入框与软键盘，不清空草稿，不触发自动重新聚焦。
5. 增加必要的行为验证，执行构建和相关测试，检查实际差异。
6. 按用户可见能力分类、记录版本，并仅本地提交本次文件。

## 验收标准

- 网页侧栏能够显示置顶、今天、最近 7 天等分组，并明确标出当前会话。
- 选择模式中可选中多条会话、批量置顶、批量删除，并能取消选择模式。
- 删除前展示选中数量和不可撤销提示；操作结束后选中状态与列表一致。
- 移动网页打开侧栏时输入法收起，输入草稿保留。
- 深色、浅色、暖色和自定义主题下状态及文字清晰，桌面列表不过度稀疏。
