# 输入框定时发送与手机设置菜单修正

## 目标与分类

修复手机端设置面板被聊天区域裁剪的问题，并移除重复的标题和字段文字。新增定时发送：用户输入内容和时间后，消息进入当前对话的持久化排队；到点且轮到该消息时，由电脑端服务自动发送。没有当前对话时先创建新对话承载定时消息。属于能力新增 / MINOR，目标版本 `0.77.0-dev.1`。

## 实施步骤

1. 将手机设置面板通过 portal 渲染到聊天容器外，并根据可视视口计算位置；隐藏“对话设置、模型、思考、授权”重复文字，保留完整无障碍名称。
2. 在输入框工具栏加入定时发送入口，使用本地时区的日期时间选择器；确认后将草稿、附件和当前模型设置写入共享队列。
3. 由后端共享队列按 `scheduledAt` 延后发送，保持 FIFO、回复完成等待、编辑暂停、手动立即发送和删除行为；时间写入现有持久化消息，服务重启后继续生效。
4. 在排队卡片显示预定时间，并确保编辑消息保留预定时间。
5. 更新版本记录、网页版本与 Android 版本号；运行网页构建，不新增或运行测试；本地提交，不推送 GitHub。

## 完成记录

- 手机设置面板、模型选项和定时面板统一传送到页面顶层，并按可视视口计算位置，避免被聊天容器裁切；设置菜单保持三列平铺，按钮不再显示重复字段标题，同时保留无障碍名称。
- 输入框新增本地日期时间选择器；定时消息写入服务端持久队列，按原队列顺序在到期且对话可发送时自动发送。排队项显示预定时间，编辑时保留时间；没有当前对话时自动先创建对话。
- 阻止前端自动发送路径提前发送未到期消息；后端校验未来时间并在服务重启后从持久队列恢复。
- 更新版本记录至 `0.77.0-dev.1`，Android `versionCode` 更新至 `365`。`pnpm build` 通过；未新增或运行测试。
