# AI 群聊 Claude 推理强度参数修复

## 需求分类

修复 / PATCH。Claude 在群聊中因收到无效的 `default` 推理强度参数而拒绝消息，导致已有群聊发送能力无法按预期使用。

## 开发步骤

1. 检查群聊并发发送、互相接力以及普通聊天对 Claude 推理强度的处理方式。
2. 在群聊调用 Claude 前，仅传递接口接受的 `low`、`medium`、`high`、`xhigh`、`max`；默认值或其他未知值不传。
3. 更新应用版本和变更记录至 `0.53.3-dev.1`。
4. 执行前端生产构建和差异检查，不新增或运行测试。
5. 只提交本次相关文件到本地 Git，不推送 GitHub。

## 验收标准

- 群聊并发发送和互相接力不会向 Claude 传递 `default` 或未知推理强度值。
- 显式选择的五种合法推理强度仍按原值传递。
- `pnpm build` 成功且 `git diff --check` 无输出。
