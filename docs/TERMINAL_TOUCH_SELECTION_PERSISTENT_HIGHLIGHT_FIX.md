# 移动网页终端长按选区持久高亮修复

## 目标与分类

用户反馈 `0.39.1-dev.1` 中长按选中文字后，松手仍立即失去高亮。本次属于修复 / PATCH：恢复已有的选中文字、复制和插入输入框流程。目标版本为 `0.39.1-dev.2`，仅涉及网页端。

## 原因与方案

- 上版依赖 xterm 内部选区：松手后重新调用 `terminal.select()`，但触摸结束后的浏览器模拟鼠标事件及 xterm 后续刷新仍可清除它；只缓存文字并不能保证高亮留在屏幕上。
- 长按确认后保存选中文字与缓冲区位置。手指松开时，在终端屏幕上绘制独立、不可交互的选区高亮；浏览器模拟的鼠标事件不得触发 xterm 的新选择。自定义右键菜单应先于 xterm 的原生处理接管事件，避免隐藏输入区获焦引起移动端视口变化。
- 高亮跟随终端滚动和尺寸变化，所选行内容变化时清除旧高亮，避免标错文字。右键菜单和复制、插入操作读取同一份缓存文本。

## 实施步骤

1. 增加按缓冲区选区与当前视口计算高亮矩形的辅助函数。
2. 在终端屏幕内维护触摸选区高亮层；长按松手后交由它显示，新的触摸、鼠标选择或输入再清除。
3. 拦截长按之后由浏览器合成的鼠标事件，避免 xterm 再次清空或误选。
4. 更新网页内部测试版本和版本记录，并在本地仓库提交。

## 验收标准

- 长按终端文字并松手，高亮仍清晰可见，右键菜单可复制或插入该文字。
- 点击别处开始新操作时旧高亮消失；滚动、调整终端尺寸时高亮仍对准原文字。
- 桌面鼠标选择和终端输入不受影响。
