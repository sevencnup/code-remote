# 左侧对话栏窄幅收起开发记录

## 目标

为桌面端左侧对话记录栏增加收起按钮。收起后保留窄栏和“聊天对话记录”标题，不将侧栏完全隐藏；移动端抽屉式侧栏行为保持不变。

## 实施步骤

1. 将带无障碍标签的收起/展开按钮放在顶部品牌标识右侧，与 Logo 和应用名称同行。
2. 桌面端窄幅状态将侧栏宽度调整至约 132px，保留对话列表及必要操作，并压缩品牌、设置和状态信息的占位。
3. 限定窄幅样式为桌面指针布局，不改变移动端侧滑抽屉及横屏触控布局。
4. 运行前端测试、生产构建和差异检查；保留已有用户修改，只创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 桌面侧栏可在原宽度与约 132px 窄栏之间切换，窄栏仍显示“聊天对话记录”标题与会话入口。
- 再次点击可恢复原宽度，聊天区和右侧文件区域不会被裁剪。
- 移动端侧滑开关行为与当前一致。
