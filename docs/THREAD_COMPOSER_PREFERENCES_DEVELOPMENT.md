# 会话级输入设置开发文档

## 目标

将模型、思考强度和授权模式从单一全局选择改为按 Codex 聊天会话分别保存。切换聊天时，输入框恢复该聊天自己的设置；新建聊天继承当前选择作为初始值。

## 设计边界

- Codex App Server 的 thread 返回对象不保证携带模型、思考强度或授权模式，因此不依赖其内部会话记录。
- 使用浏览器 `localStorage`，以 `threadId` 为键保存会话设置；设置只在当前浏览器生效，不会跨设备同步。
- 保留已有全局设置作为旧数据兼容和新聊天的默认值。历史聊天没有已存设置时使用该默认值，并在用户首次修改时创建自己的记录。
- 自动创建的首条消息也必须写入对应会话设置，不能只覆盖“新建对话”按钮路径。

## 实施步骤

1. 增加会话 ID 到输入设置的本地存储映射，并兼容既有全局偏好键。
2. 让输入框当前显示值由活动会话对应的设置派生，切换会话时不再复用上一个聊天的状态。
3. 调整显式新建和首次发送自动建会话路径，创建成功后写入当前设置快照。
4. 保持模型和思考强度的可用性校验；失效设置回退到当前可用默认值并只更新对应会话。
5. 更新版本记录，执行前端生产构建、后端测试和差异检查，并创建本地 Git 提交。

## 验收标准

- 聊天 A 与聊天 B 可选择不同模型，来回切换后各自选择保持不变。
- 思考强度和授权模式也按聊天独立恢复。
- 新建聊天和无活动聊天时首次发送创建的会话，均保存创建时的设置。
- 原有历史聊天和已有 `composer-preferences` 数据仍能正常使用。
- `pnpm build`、后端单元测试成功，`git diff --check` 无输出。
