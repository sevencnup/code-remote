# 手机端输入框设置菜单

## 目标与分类

手机端将模型、思考和权限入口折叠到一个三横线按钮中，展开后按钮变为关闭图标；桌面端维持现有布局。该调整保留已有设置能力，属于布局与操作便利性修复 / PATCH，目标版本 `0.76.16-dev.1`。

## 实施步骤

1. 桌面端继续显示现有模型、思考和权限菜单。
2. 手机端用带有 `aria-expanded` 状态的三横线 / 关闭按钮替代三个并列入口；展开后复用原有菜单及其当前选择、禁用和变更逻辑。
3. 为展开面板补充适配移动端的定位、主题样式和点击区域；菜单展开时保留关闭按钮可见。
4. 更新 `CHANGELOG.md`、`package.json` 和 Android `versionName`；不修改 Android `versionCode`，不构建 APK。
5. 运行网页构建并审阅差异，不新增或运行测试；完成后本地提交，不推送 GitHub。

## 完成标准

- 桌面端三个设置菜单的位置和行为保持不变。
- 手机端收起时只显示菜单图标；展开时图标变成关闭符号，三个设置仍可操作。
- 所有主题下按钮和展开面板均清晰可用。

- 桌面端设置控件仍以内联方式显示。
