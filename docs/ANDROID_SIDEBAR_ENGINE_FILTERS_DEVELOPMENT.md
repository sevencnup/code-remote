# Android 侧边栏 Codex / Claude 聊天筛选开发记录

## 变更分类与版本

- 分类：PATCH / 导航体验优化。Android 已能通过顶部模式切换进入另一模式的聊天；侧边栏增加同款筛选入口，减少往返切换并让聊天标题可直接浏览。
- 目标版本：`0.55.1-dev.5`，Android `versionCode 314`。
- 版本记录：在 Android 侧边栏按 Codex 或 Claude 筛选聊天。

## 目标行为

复刻网页版侧边栏的两个模式筛选图标：默认显示 Codex 与 Claude Code 的全部聊天；点某一模式图标后仅显示该模式，再点同一图标恢复全部。搜索继续与模式筛选组合。选择另一模式的聊天后，打开该原聊天并切换到对应模式；“新建对话”仍在当前模式下创建。

## 实施步骤

1. [x] 在 Android 新建对话按钮右侧加入 Codex 与 Claude Code 筛选图标，并提供选中状态及无障碍描述。
2. [x] 将侧边栏列表过滤改为可选的引擎过滤，默认不限制模式；搜索同时匹配标题和预览。
3. [x] 更新列表标题、空状态及批量选择/置顶/删除，使其支持跨模式聊天。
4. [x] 更新中英文文案、版本号和变更记录。
5. [x] 运行 `:app:compileDebugKotlin` 做编译检查；不生成 APK、不安装。

## 验收标准

- 默认列表显示两种模式的聊天，筛选按钮可独立过滤与清除过滤。
- 搜索、日期分组、置顶和批量选择在过滤状态下仍正确工作。
- 点击 Claude 或 Codex 聊天会打开相应原聊天；新建聊天继续使用当前模式。
- Kotlin 编译成功；不创建或覆盖安装包。

## 实施结果

- Android 侧边栏默认展示两种模式的聊天；Codex / Claude 图标可单独筛选，再点当前筛选可恢复全部。
- 搜索匹配聊天标题和预览，筛选结果标题及空状态会随搜索和模式变化。
- 跨模式批量操作按每个会话记录的引擎处理；新建聊天仍使用当前模式。
- `:app:compileDebugKotlin` 编译成功；没有执行 APK 打包或安装。
