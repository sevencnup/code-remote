# Android 侧边栏图标辨识度调整

## 目标

让 Android 左侧对话栏和右侧文件树中的线性图标更容易看清，重点加粗加号、目录返回和路径跳转箭头。保持按钮点击范围和现有操作不变，并让文件树路径栏的两个箭头可通过长按查看说明。

## 分类与版本

本次属于修复 / 体验优化（PATCH）：只调整已有侧边栏图标的辨识度和操作说明，不增加新的用户任务能力。目标版本为 `0.21.6-dev.2`，Android `versionCode` 为 `175`。

## 实施步骤

1. 为 Android 侧边栏创建较粗的线性图标资源，并用于对话栏和文件树中的图标按钮及加号。
2. 文件树路径栏保留左侧“返回上级目录”和右侧“跳转到输入路径”的行为，增加长按提示。
3. 更新 Android、Web 和服务端版本标识及简短变更记录。
4. 构建新的 Android Debug APK，使用 `adb install -r` 更新现有安装；保留历史 APK，并创建本地 Git 提交。

## 验收标准

- 对话栏和文件树中的按钮图标与加号线条比现有版本更醒目，按钮点击区域不变。
- 文件树路径栏左箭头仍返回父目录；右箭头仍跳转到输入路径；长按能读到对应说明。
- Debug APK 构建成功，版本号与 `versionCode` 正确。
