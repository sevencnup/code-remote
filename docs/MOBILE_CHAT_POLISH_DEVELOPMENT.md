# 移动端聊天细节优化开发文档

## 目标

修正移动端授权卡片和输入框的横向对齐，避免用户消息在窄屏下被压成竖排，并为每个代码块提供独立复制按钮。

## 实施步骤

1. 统一消息流内授权卡片的居中和宽度规则。
2. 调整用户消息的换行和可用宽度，保留右侧气泡布局。
3. 将代码块复制按钮放在代码框底部，复制后显示短暂反馈。
4. 更新版本记录，执行生产构建和差异检查，提交本地 Git 仓库。

## 验收标准

- 手机网页中授权卡片左右边缘与输入框一致。
- 用户消息保持右侧显示，中文和英文混排不会逐字竖排。
- 每个代码块底部有复制按钮，点击后能复制该代码块内容并显示“已复制”。
- `pnpm --filter codex-remote build` 成功，`git diff --check` 无输出。
