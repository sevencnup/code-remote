# CPA Usage Authentication Error Diagnostics

## 用户可见分类与版本

- 分类：修复 / PATCH。统计连接测试已能请求 Manager，但把不同的上游拒绝原因合并显示，导致排障提示不准确。
- 目标版本：`0.58.1-dev.1`。

## 目标

区分 CPA Manager analytics 接口返回的 HTTP 401 与 HTTP 403，让用户能分别处理管理密钥认证失败、远程管理策略拒绝或来源 IP 封禁。

## 实施步骤

1. 将上游 HTTP 401 和 403 映射为不同的可操作错误提示，不记录或回传管理密钥。
2. 更新 CHANGELOG、版本号和本开发文档。
3. 执行 Python 语法检查与差异检查；按仓库的安全重启流程在对话空闲后重启 Codex Remote。
4. 本地提交，不推送远端；不修改 CPA Manager 上游配置。

## 验收要点

- 上游 401 提示管理密钥认证失败，并提示核对管理密钥。
- 上游 403 提示检查远程管理访问策略和来源 IP。
- 管理密钥不进入错误文案、日志或前端响应。
