# Android 启动图标与侧栏品牌区修复

## 问题与目标

1. Android 12 及以上的系统启动页直接复用桌面自适应图标。图标底板和启动背景都是白色，圆角底板完全融入背景；现有前景高度也略超自适应图标安全区，因此视觉上像四边被裁掉。
2. 左侧边栏顶部 Logo 被面板边框和内边距包裹，标识本体偏小，并且和右侧两行品牌文字的上下范围不齐。

目标是为启动页提供独立且完整的安全区图标，让白色圆角底板清晰可见；侧栏 Logo 则去掉所有包裹，直接显示并与两行文字垂直对齐。

## 分类与版本

- 分类：修复 / PATCH。修正现有启动页与侧栏品牌区的显示效果，不改变操作方式。
- 目标版本：`0.90.5-dev.1`，Android `versionCode 387`。
- 本次属于小幅视觉修复，不单独增加 `CHANGELOG.md` 条目。

## 实施步骤

1. 为 Android 12+ 新增独立启动主题，使用浅冷灰背景衬托白色图标底板。
2. 新增启动页专用自适应图标，Logo 使用 21dp 安全边距；桌面图标继续使用现有比例。
3. 左侧边栏顶部 Logo 移除面板背景、像素边框和内部留白，使用完整图片直接显示。
4. 让 Logo 和右侧两行文字使用相同高度并在品牌栏中居中。
5. 更新版本、构建独立 APK、覆盖安装到手机，并仅提交本次文件到本地 Git。

## 验收标准

- 启动页能看到完整的白色圆角图标区域，Logo 四周不贴近系统蒙版。
- 桌面图标大小不受启动页调整影响。
- 侧栏顶部 Logo 无外框、无内边距，并与右侧两行文字上下对齐。
- 新 APK 不覆盖历史产物。

## 完成记录

- Android 12+ 启动页使用独立自适应图标：21dp 前景安全边距、白色图标底板和浅冷灰启动背景；桌面图标资源未改动。
- 左侧边栏顶部 Logo 已移除普通主题与像素主题的外框、背景和内边距，并与两行品牌文字使用相同布局高度。
- Android 构建成功，产物为 `artifacts/code-remote-android-0.90.5-dev.1-debug.apk`。
- 新版本已覆盖安装到手机，设备报告 `versionCode 387`；历史 APK 未覆盖。
