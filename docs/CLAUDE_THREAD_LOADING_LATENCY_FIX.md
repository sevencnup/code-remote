# Claude 对话加载延迟修复

## 问题与根因

分类：修复 / PATCH。打开已有 Claude 对话会等待侧栏元数据刷新；服务端元数据接口扫描本机 Claude 项目会话文件，之后指定对话的读取接口还会再触发一次全局扫描。已登记在服务数据库中的会话无需等待这两次扫描。

## 版本与记录

- 版本：`0.59.3-dev.1`
- 版本记录：`缩短侧栏 Claude 对话打开等待时间`
- 不生成 Android 安装包，不递增 Android `versionCode`。

## 实施步骤

1. 打开已有 Claude 对话时，不等待侧栏元数据请求完成；并行刷新元数据，先读取用户选中的会话。
2. 指定 Claude 会话的读取接口直接读取已登记的会话记录，不扫描整个本机 Claude 项目目录。
3. 保留线程列表刷新时的本机历史导入，以及现有会话更新通知。
4. 更新版本记录，执行前端生产构建、Python 语法编译与 `git diff --check`；不新增或运行测试。
5. 只提交本次文件到本地 Git，不推送 GitHub。

## 验收标准

- 打开已有 Claude 对话不再等待线程列表刷新完成。
- 读取已登记的 Claude 对话不触发本机项目目录全量扫描。
- 线程列表仍可发现新的本机 Claude 会话，并在导入完成后通知页面刷新。
- 构建、Python 语法编译和差异检查通过。
