# 移动网页终端触摸选区松开后丢失修复

## 目标

修复移动网页版终端长按选中文字后，手指松开时选区消失，导致“复制”或“粘贴到输入框”拿不到文本的问题。

本次属于修复 / 体验优化（PATCH）：保留鼠标/触摸选择的内容，使用户随后可以通过右键菜单发到输入框；目标版本 `0.21.7-dev.4`，仅修改网页端，不生成 APK。

## 诊断

- 移动端长按计时器触发时，网页会在 xterm 中按触点选中一个词或一行。
- xterm 在 `document` 级别处理 `touchend`，比容器监听器更晚，可能在网页读取选区后清除程序化选区。
- 释放时立即读取实时选区或弹出菜单，会与 xterm 及浏览器后续的触摸/鼠标收尾事件竞争，导致选区不可见或右键菜单拿不到文本。

## 实施步骤

1. 长按和鼠标选择时缓存实际选中文字及选区范围。
2. 手指或鼠标松开后，在 xterm 完成事件处理后恢复选区；松开时不抢先弹菜单。
3. 后续右键打开菜单时使用缓存的选区文本，使“粘贴到输入框”能取得正确内容。
4. 触摸取消或开始新的鼠标选择时清理缓存，避免误用旧选区。
5. 添加回归断言，更新 PATCH 版本记录，运行专项测试、生产构建和差异检查；本地提交，不推送远端、不构建 APK。

## 验收标准

- 移动网页版长按终端文字或桌面用鼠标选择后松开，选区仍可见。
- 随后右键打开菜单时，“粘贴到输入框”保留正确的选区文本。
- 移动取消、触摸取消和终端卸载时不残留旧选区状态。
- 专项测试、生产构建和 `git diff --check` 通过。
