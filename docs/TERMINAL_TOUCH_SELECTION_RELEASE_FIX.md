# 移动网页终端选区保持修复

## 目标

修复移动网页版终端长按选中文字后，手指松开时选区短暂恢复又被设备清除，导致用户看不到选中状态、无法继续使用右键菜单的问题。

本次属于修复 / 体验优化（PATCH）：长按选区在下一次终端操作或打开上下文菜单前保持可见，并继续支持复制和粘贴到输入框；目标版本 `0.39.1-dev.1`，仅修改网页端，不生成 APK。

## 诊断

- 移动端长按计时器触发时，网页会在 xterm 中按触点选中一个词或一行，并缓存文字与缓冲区范围。
- 松手后的单次 `requestAnimationFrame` 恢复仍会被 xterm 或设备稍后的选区清理覆盖；`touchcancel` 也不能无条件丢掉已确认的长按选区。
- 缓存的选区应在后续选区清理事件中恢复，并在用户开始新的选择或打开上下文菜单时结束保留，避免恢复过期范围。

## 实施步骤

1. 长按和鼠标选择时缓存实际选中文字及选区范围。
2. 松手或取消事件后恢复已确认的选区，并在 xterm 后续清除选区时继续恢复。
3. 用户开始新的触摸/鼠标选择或打开右键菜单时结束保留；菜单使用缓存文本执行复制或插入输入框。
4. 更新 PATCH 版本记录并提交网页端修改；不生成 APK、不推送远端。

## 验收标准

- 移动网页版长按终端文字后松开，选区保持可见，直到用户打开菜单或开始新操作。
- 右键菜单中的“复制”和“粘贴到输入框”使用本次选中的文本。
- 未形成选区的触摸取消、新选择和终端卸载不会复用旧选区。
