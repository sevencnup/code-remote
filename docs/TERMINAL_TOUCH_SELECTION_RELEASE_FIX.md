# 移动网页终端触摸选区松开后丢失修复

## 目标

修复移动网页版终端长按选中文字后，手指松开时选区消失，导致“复制”或“粘贴到输入框”拿不到文本的问题。

本次属于修复 / 体验优化（PATCH）：恢复已有的终端选区操作，不改变用户可完成的任务；目标版本 `0.21.7-dev.1`，仅修改网页端，不生成 APK。

## 诊断

- 移动端长按计时器触发时，网页会在 xterm 中按触点选中一个词或一行。
- xterm 在 `document` 级别处理 `touchend`，比容器监听器更晚，可能在网页读取选区后清除程序化选区。
- 菜单在 `touchend` 才读取 `terminal.getSelection()`，因此会得到空文本，选区菜单操作随之不可用。

## 实施步骤

1. 长按成功时立即缓存实际选中文字、选区范围和触点坐标。
2. 手指松开时等当前触摸事件及 xterm 的 `document` 监听处理完，再恢复原选区并用缓存文本打开菜单。
3. 触摸取消或移动取消长按时清理缓存，避免后续触摸误用旧选区。
4. 添加回归断言，更新 PATCH 版本记录，运行专项测试、生产构建和差异检查；本地提交，不推送远端、不构建 APK。

## 验收标准

- 移动网页版长按终端文字后松开，选区仍可见且菜单保留正确文本。
- “复制”和“粘贴到输入框”继续使用同一选区文本；桌面右键操作不变。
- 移动取消、触摸取消和终端卸载时不残留旧选区状态。
- 专项测试、生产构建和 `git diff --check` 通过。
