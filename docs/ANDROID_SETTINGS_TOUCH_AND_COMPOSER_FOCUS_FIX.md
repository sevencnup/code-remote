# Android 设置滑杆与输入焦点修复

## 目标

让设置页字体大小滑杆容易操作，并避免聊天输入框的光标、选区和输入手势被侧栏滑动手势打断。

## 根因与方案

聊天根视图会在大部分页面区域识别水平滑动，并在识别后向子控件发送取消事件。设置页的字体滑杆和聊天输入框也处于识别区域内，因此拖动可能被侧栏手势抢走。对输入框、滑杆、可滚动控件及可选择文本区域优先保留触摸序列；设置覆盖页不启动侧栏手势。增加字体滑杆的高度和垂直触摸容差，方便点按及拖动。

## 实施步骤

1. 在根视图手势识别前判断触摸目标是否为交互控件，交互控件接管完整触摸序列。
2. 设置页显示时停用聊天侧栏的滑动识别。
3. 扩大字体大小滑杆的触摸区域但不改变刻度和保存逻辑。
4. 更新 PATCH 版本与简短版本记录，构建新的 Android debug APK，检查差异并提交本地 Git；保留旧 APK，不推送远端。

## 验收标准

- 字体大小滑杆可在轨道任意位置按下和连续拖动。
- 输入框长按选词、移动光标和输入文字时不会被侧栏手势取消。
- 普通聊天区域仍可通过左右滑动打开侧栏。
