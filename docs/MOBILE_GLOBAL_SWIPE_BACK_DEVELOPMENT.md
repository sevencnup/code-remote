# 移动端全局页面侧滑返回开发记录

## 目标

移动端打开设置、文件预览、重命名和上下文菜单等全局页面或浮层时，支持从屏幕边缘侧滑返回并关闭当前界面；关闭动作应停留在当前 Codex Remote 页面，不能触发浏览器或 WebView 的页面退出。

## 交互约束

- 已打开的全局界面优先处理侧滑返回，不能把同一手势误识别为打开左侧栏或文件树。
- 左边缘向右滑、右边缘向左滑关闭全局界面；单指、水平位移超过阈值且明显大于纵向位移才触发。
- 现有左侧栏和右侧文件树的分区开关手势保持不变。
- 输入框、代码阅读和文件滚动区域的普通触摸不应误触关闭；只有从屏幕边缘开始的返回手势参与判定。
- 成功识别返回手势时阻止浏览器默认横向导航，避免离开当前页面。

## 实施步骤

1. 扩展移动端手势判定模型，增加全局页面的边缘返回方向。
2. 将全局页面关闭动作接入根触摸处理和已有 Android 返回处理顺序。
3. 为移动端根容器增加横向过度滚动保护，阻止浏览器页面退出。
4. 更新版本记录，执行差异检查和前端构建检查，创建本地提交；不推送 GitHub。

## 验收标准

- 设置、文件预览、重命名和上下文菜单打开时，从任一屏幕边缘向内侧滑可关闭当前界面。
- 全局界面关闭后仍停留在当前 Codex Remote 页面，浏览器地址和页面上下文不退出。
- 左右侧栏原有打开和关闭方向不变。
- 短滑、竖向滚动和非边缘横向触摸不关闭全局界面。
