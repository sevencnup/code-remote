# Android 原生侧栏跟手与聊天历史修复

## 目标与分类

修复原生 APP 侧栏只有开关、不能跟随手指拖动的问题；整理侧栏与顶部工具栏的图标和布局；避免聊天列表的短暂缺项清空当前聊天，并让历史加载失败可见、可重试。属于 PATCH：修复已有侧栏交互和聊天显示，不改变用户已有任务。

目标版本为 `0.18.1-dev.5`，Android `versionCode` 为 `136`。

## 已确认的问题

1. `ChatRootLayout` 只在手指抬起时调用 `setSidebarVisible`，拖动期间不更新面板位置或遮罩，所以看起来只有开关。
2. `refreshThreads` 把列表响应中暂时缺少当前 ID 当成聊天已删除，会清空当前聊天；运行状态和排队消息又没有同步清空，可能只剩思考提示和队列。
3. 历史加载失败只通过可能很快被状态栏刷新隐藏的提示显示；聊天区没有加载、失败和重试状态。
4. 顶栏和侧栏主要用文本字符充当图标，侧栏没有清晰的搜索、最近对话、刷新和底部操作层级。
5. 同一轮里的多条 `agentMessage` 会拆成多个聊天气泡；浏览器把它们合并显示。
6. Android 客户端没有本地历史缓存，重开已看过的大聊天仍需重新读完整历史，冷启动时容易长时间只看到运行状态。

## 实施步骤

1. 让侧栏面板和遮罩在水平拖动的每一帧跟随手指；松手后按拖动进度平滑停靠，纵向滚动继续交给列表。
2. 使用项目现有 Codex 和 Claude 品牌 SVG 制作原生矢量图标；为菜单、终端、文件、搜索、设置、刷新和关闭等常用操作提供一致的线框图标。
3. 整理侧栏品牌区、搜索、新建对话、最近聊天列表、当前项高亮和底部设置/重连入口；保留搜索、新建、刷新、切换聊天与聊天操作。
4. 列表刷新缺少当前 ID 时保留选中的聊天；只有聊天历史接口或明确删除操作才能改变当前聊天。
5. 历史读取期间显示加载状态；失败后在聊天区显示原因和重试操作；成功后清除错误状态并恢复消息。
6. 用压缩的私有文件缓存最多 32 个已读聊天，总容量上限 64 MiB；缓存命中后先显示旧历史，再请求增量更新。
7. 同一轮的连续 assistant 消息按浏览器行为合并，避免回复被拆成多个气泡。
8. 构建新的 debug APK，不覆盖旧包；在手机上检查聊天正文、侧栏拖动开合、侧栏控件、重新选择聊天和加载失败状态，不发送测试消息。
9. 更新版本记录，检查差异并创建本地 Git 提交；不推送 GitHub。

## 验收标准

- 从屏幕左边缘右拖时，侧栏与遮罩立即跟随手指；在侧栏中向左拖时，面板跟随关闭；松手后正确停靠。
- 竖向滚动聊天列表仍正常；按钮可点击并有可访问性描述；Codex/Claude 显示对应品牌标识。
- 侧栏提供可用的搜索、新建、刷新、设置、重连和聊天操作入口，选中聊天有清楚的视觉标记。
- 列表短暂漏项时当前聊天、正文与队列不会被清空；历史加载失败时有稳定的错误提示和重试入口。
- 缓存历史会优先显示并携带服务端同步版本；新聊天或无缓存聊天正常进行完整加载；本地缓存最多 32 个聊天、总量不超过 64 MiB。
- 同一轮多条 assistant 记录以连续正文显示，不改变原始聊天记录。
- APK 为 `0.18.1-dev.5`、`versionCode 136`，旧 APK 保留；安装不清除配对信息和聊天数据。

## 验证记录

- `./gradlew assembleDebug` 构建成功；`aapt` 确认 APK 为 `com.sevencnup.codexremote`、`0.18.1-dev.5`、`versionCode 136`。
- 隔离测试包截图确认顶栏品牌图标、终端/文件图标、侧栏搜索、新建入口、聊天列表选中态、刷新和底部设置/重连入口能够绘制；测试包和临时配对数据副本已清理，没有创建或发送聊天。
