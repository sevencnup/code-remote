# Android 输入框呼吸光晕形状修复

## 目标与分类

修复 / PATCH：原生输入框的呼吸效果已经存在，但显示为明显的椭圆色块。目标内部版本 `0.28.1-dev.6`，Android `versionCode 240`。

## 实施步骤

1. 对照网页版运行时光晕的渐变位置与透明度。
2. 将原生渐变移到输入框顶部，使用与输入框一致的圆角裁剪，降低色块感并保留柔和呼吸。
3. 更新版本记录，构建独立 APK，安装到已连接手机并核对版本，完成本地提交。

## 验收

- 运行时输入框内部呈现柔和光晕，不出现独立的椭圆轮廓。
- 停止运行时光晕消退，浅色输入框边界仍清楚可见。
- 安装版本为 `0.28.1-dev.6` / `versionCode 240`。

## 实施结果

- 光晕与输入框使用相同圆角裁剪，渐变中心位于顶部，降低灰白色椭圆色块的可见度。
- 呼吸周期调整为 2.8 秒，停止运行时仍淡出；APK 构建并安装成功，手机报告 `versionCode 240`、`versionName 0.28.1-dev.6`。
