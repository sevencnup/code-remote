# Android 聊天布局与文件树操作开发记录

## 目标

修复 Android 原生客户端的聊天区留白、抽屉拖动与宽度、聊天活动卡片位置、回到底部入口、滚动条显示和输入区按钮样式；并为文件树中的文件及文件夹增加“到输入框”操作。

## 修改分类与版本

- 分类：新增功能 / MINOR。
- 理由：文件树条目新增将路径放入输入框的操作，扩展了 Android 客户端原有能力；其余项目为已有布局和交互修复。
- 目标版本：`0.19.0-dev.3`，Android `versionCode` 递增至 `148`。`.dev.1`、`.dev.2` 与 `.dev.3` 均已安装用于验收，保留为历史 APK。

## 实施步骤

1. 调整聊天消息容器的左右留白，使用户消息与 AI 消息拥有均衡的可用宽度。
2. 优化两侧抽屉拖动时的事件处理和动画表现，收窄抽屉宽度；为文件树每个条目提供“到输入框”入口。
3. 按助手文字与工具操作的原始顺序展示轮次时间线；每轮操作记录与已编辑文件卡片分开展示，避免统一堆放到消息列表末尾。
4. 在聊天列表滚动离开底部时显示回到底部按钮，点击后平滑滚动到最新内容。
5. 隐藏聊天、文件树及侧栏等滚动容器的滚动条视觉提示。
6. 输入区模型、思考、权限按钮仅保留文字；发送按钮使用圆形底和向上箭头。
7. 构建新 APK 并在 Android 设备检查以上交互和布局；旧版本 APK 保留，安装时使用同 applicationId 覆盖升级。
