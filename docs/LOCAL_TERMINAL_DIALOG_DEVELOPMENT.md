# 本机终端弹窗开发文档

## 目标

在 Codex Remote 网页内提供一个连接运行服务的本机终端，并能把终端选中的文字插入聊天输入框。

## 交互设计

- 在顶部连接状态“Codex 已连接”右侧增加“终端”按钮。
- 打开终端后，同一位置的按钮切换为关闭按钮；窄屏隐藏顶部工具栏时，保留弹窗内的关闭按钮。
- 移动端终端字体比桌面端小 1px。
- 移动端长按终端文字选中内容并显示“复制”和“粘贴到输入框”操作；桌面端右键选中文字时提供相同操作。
- 点击后打开覆盖聊天内容区的终端弹窗；输入框保持在弹窗外并始终可见。
- 弹窗内提供真实交互式 shell，默认工作目录跟随当前聊天的工作目录；没有聊天目录时使用服务端默认工作区。
- 在终端中选中文字后右键显示“粘贴到输入框”，插入到当前光标处并保留已有草稿。
- 已有聊天在 POSIX 主机上使用同聊天 ID 的 tmux 会话；关闭弹窗、网页断线或 Python 后端重启只分离客户端，重新打开时接回原 shell。没有聊天 ID 的临时终端和 Windows 原生终端关闭时结束进程。
- tmux 会话输入 `exit` 后结束；未连接 30 分钟或未连接会话超过 10 个时由后台清理。tmux 和 xterm.js 的滚动历史均限制为 5,000 行。

## 实施步骤

1. 使用 xterm.js 和 fit 插件呈现终端，添加主题样式、尺寸同步、连接状态和关闭操作。
2. 在后端增加经过配对令牌验证的终端 WebSocket；POSIX 为已有聊天连接到按聊天 ID 隔离的 tmux session，Windows 使用 `pywinpty` 临时启动 shell，均支持输入、输出和终端尺寸调整。
3. 按当前聊天工作目录创建新 shell，拒绝不存在或非目录的路径；已有 tmux session 重新打开时保留 shell 当前目录和运行状态。关闭连接时分离 tmux 客户端，按 30 分钟空闲和 10 个未连接 session 上限清理。
4. 按移动端断点调整 xterm 字号；通过触摸长按坐标映射到终端缓冲区，选中单词或所在行并打开操作菜单。
5. 终端选择菜单支持复制到系统剪贴板和插入当前聊天输入框；桌面继续支持右键打开菜单。
6. 窄屏时显示弹窗内关闭按钮，桌面用原位工具栏关闭按钮，确保同时只显示一个关闭叉。
7. 更新版本记录和 Android 版本号；执行生产构建、Python 语法解析和差异检查，不新增或运行测试。

## 验收标准

- 顶部连接状态旁有终端入口；打开后遮住聊天内容，不遮挡聊天输入框。
- 桌面端使用原位按钮关闭终端；窄屏仍可通过弹窗内按钮关闭，同时只显示一个关闭叉。
- 移动端终端字体为 12px，桌面端为 13px；改变屏幕方向时字号同步更新。
- 移动端长按终端文字可以选中单词或行，并使用“复制”或“粘贴到输入框”；桌面右键菜单保留这两项操作。
- 终端实际运行在服务端所在电脑，命令可交互，窗口缩放后终端尺寸同步。
- 同一聊天重开终端或 Python 后端重启后，可以接回原 tmux shell；不同聊天使用独立 session。
- tmux session 在输入 `exit`、空闲 30 分钟或未连接 session 超过 10 个时清理；电脑重启后会话结束。
- 右键终端选中文字可将其插入输入框当前光标位置，原有草稿保留。
- 前端生产构建成功，Python 文件语法有效，`git diff --check` 无输出。

## 移动端触摸滚动与方向键

### 目标与分类

让移动端终端可以用手指上下滚动历史输出，并在底部提供上下左右方向键。本次属于 PATCH / 体验优化：补齐已有终端在触屏设备上的输入和浏览方式，目标版本为 `0.16.0-dev.10`。

### 交互约束

- 终端输出区允许纵向触摸滚动，滚动到边缘时不能带动聊天页面或侧栏。
- 底部方向键仅在移动端或触屏横屏布局显示，桌面端不占空间。
- 四个按钮发送标准终端方向键序列：上、下用于命令历史或程序导航，左、右用于移动光标；它们不冒充历史输出滚动按钮。
- 按下一次立即发送一个方向键；持续按住约 360 毫秒后连续发送，松开、取消或移出按钮立即停止。
- 终端尚未连接、连接断开或会话结束时禁用方向键。

### 实施步骤

1. 将终端 WebSocket 输入发送函数保存到组件引用，让底部按钮复用 xterm 键盘的同一输入通道。
2. 增加带长按连发清理逻辑的四向按钮，组件卸载时必须清除所有计时器。
3. 使用共享浮层的 footer 放置移动端按键条，并按现有移动布局断点显示。
4. 为 xterm 可视滚动层补充纵向触摸滚动和惯性滚动样式。
5. 更新版本记录并构建网页资源；不新增或运行测试，不重启服务，不生成 APK。
6. 检查差异并创建本地 Git 提交，不推送 GitHub，保留用户已有的 Android 开发文档修改。

### 验收标准

- 手机端可在终端输出区上下滑动查看 5,000 行缓冲范围内的历史。
- 点击四向按钮会在 shell、命令历史和交互程序中产生对应方向键输入。
- 长按按钮连续移动，松手后立即停止，不残留后台计时器。
- 桌面端终端尺寸和布局不受底部按键条影响。

### 完成记录

- 终端滚动层已启用纵向触摸和惯性滚动，并限制滚动边界继续带动外层页面。
- 移动端底部已增加四向按键，支持点击输入、长按连发以及断线自动停止。
- 桌面端隐藏按键条；移动端或触屏横屏布局才显示，不占用桌面终端空间。
- 版本已更新为 `0.16.0-dev.10`，本次未生成 Android 安装包，因此 `versionCode` 保持不变。

## 方向键模式兼容修复

### 问题与分类

tmux 会根据终端状态启用应用光标模式；方向按钮固定发送普通光标模式序列时，tmux 无法识别完整按键，并可能把末尾的 `A/B/C/D` 当作普通文字输入。本次属于 PATCH / 修复，目标版本为 `0.16.0-dev.11`。

### 实施步骤

1. 方向键只保存方向码，不再保存固定 ANSI 序列。
2. 每次发送前读取 xterm 当前的应用光标模式，生成与实体键盘相同的 `ESC O` 或 `ESC [` 序列。
3. 点击、键盘触发和长按连发共用同一个方向键发送入口。
4. 更新版本记录、构建网页资源并创建本地 Git 提交，不重启服务、不生成 APK。

### 验收标准

- tmux 普通命令行中，上下键浏览历史，左右键移动光标，不再输入 `A/B/C/D`。
- 终端程序切换光标模式后，四个按钮仍发送当前模式对应的方向键序列。
- 原有触摸滚动、长按连发和断线停止逻辑保持可用。

### 完成记录

- 方向按钮已改为读取 xterm 的 `applicationCursorKeysMode`，按当前状态动态发送普通或应用光标序列。
- 点击、键盘操作和长按连发已统一使用同一个方向键输入入口。
- 生产构建与差异检查通过；版本已更新为 `0.16.0-dev.11`，未生成 Android 安装包。

## 移动端连续退格

### 目标与分类

在移动端终端底部按键条增加退格键，支持点按删除一个字符和长按连续删除。本次属于 PATCH / 体验优化：改善现有终端的触屏输入便利性，目标版本为 `0.16.0-dev.12`。

### 实施步骤

1. 将四向键配置扩展为终端控制键配置，并在末尾增加退格键。
2. 退格键发送与 xterm 实体键盘一致的 `DEL` 字符，复用方向键的长按连发、松开停止及断线清理逻辑。
3. 将移动端按键条调整为五列，保持按钮触摸面积和窄屏可用性。
4. 更新版本记录、构建网页资源并创建本地 Git 提交，不重启服务、不生成 APK。

### 验收标准

- 点击退格键仅删除一个字符。
- 长按退格键约 360 毫秒后连续删除，松开、滑出、取消触摸或终端断线后立即停止。
- 四个方向键和终端内容触摸滚动行为不受影响。

### 完成记录

- 移动端终端按键条已增加退格按钮，并发送与 xterm 实体退格键一致的 `DEL` 字符。
- 退格与方向键已共用点按、长按连发和停止清理逻辑，按键条已调整为五列。
- 生产构建与差异检查通过；版本已更新为 `0.16.0-dev.12`，未生成 Android 安装包。
