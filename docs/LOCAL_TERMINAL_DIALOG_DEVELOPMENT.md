# 本机终端弹窗开发文档

## 目标

在 Codex Remote 网页内提供一个连接运行服务的本机终端，并能把终端选中的文字插入聊天输入框。

## 交互设计

- 在顶部连接状态“Codex 已连接”右侧增加“终端”按钮。
- 点击后打开覆盖聊天内容区的终端弹窗；输入框保持在弹窗外并始终可见。
- 弹窗内提供真实交互式 shell，默认工作目录跟随当前聊天的工作目录；没有聊天目录时使用服务端默认工作区。
- 在终端中选中文字后右键显示“粘贴到输入框”，插入到当前光标处并保留已有草稿。
- 关闭弹窗时结束该终端进程；窗口断线和服务退出时清理关联进程。

## 实施步骤

1. 使用 xterm.js 和 fit 插件呈现终端，添加主题样式、尺寸同步、连接状态和关闭操作。
2. 在后端增加经过配对令牌验证的终端 WebSocket，POSIX 使用系统 PTY，Windows 使用 `pywinpty`，支持输入、输出和终端尺寸调整。
3. 按当前聊天工作目录启动 shell，拒绝不存在或非目录的路径；关闭 WebSocket、弹窗或服务时终止进程及其子进程。
4. 为终端所选文字增加右键菜单，并通过输入框插入接口写入当前光标位置。
5. 更新版本记录和 Android 版本号；执行生产构建、Python 语法解析和差异检查，不新增或运行测试。

## 验收标准

- 顶部连接状态旁有终端入口；打开后遮住聊天内容，不遮挡聊天输入框。
- 终端实际运行在服务端所在电脑，命令可交互，窗口缩放后终端尺寸同步。
- 关闭弹窗后 shell 及其子进程结束。
- 右键终端选中文字可将其插入输入框当前光标位置，原有草稿保留。
- 前端生产构建成功，Python 文件语法有效，`git diff --check` 无输出。
