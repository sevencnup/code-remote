# Claude 模式助手名称修正

## 目标

Claude Code 模式下，聊天回复区域仍显示“Codex”；让助手回复名称跟随当前聊天窗使用的引擎。

本次属于修复 / 体验优化（PATCH），目标版本 `0.21.7-dev.6`。仅修改网页聊天显示，不改变消息数据、引擎调用或 Android 原生界面。

## 诊断

- 聊天窗顶部标题使用当前引擎状态动态显示“Codex”或“Claude Code”。
- 助手消息气泡单独把名称硬编码为“Codex”，切换引擎后没有使用同一状态。

## 实施步骤

1. 将当前聊天窗的引擎显示名称传给助手消息气泡。
2. 用引擎名称替换消息气泡中硬编码的“Codex”，并增加回归测试覆盖两种引擎。
3. 更新 PATCH 版本记录，运行专项测试、生产构建和 `git diff --check`。
4. 只提交本任务文件，不推送 GitHub、不构建 APK。

## 验收标准

- Codex 模式的助手回复仍显示“Codex”。
- Claude Code 模式的助手回复显示“Claude Code”。
- 回归测试和生产构建通过；其他工作区文件不进入提交。
