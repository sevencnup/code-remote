# 从文件树目录新建聊天开发文档

## 目标

在右侧文件树的目录右键菜单中增加“进入该路径”。使用后，在当前聊天面板创建一个以该目录为工作目录的新 Codex 对话，并切换到该对话。新会话保存自己的工作目录，因此以后重新打开该聊天时仍会使用所选目录。

Codex 已启动会话的工作目录固定在会话元数据中。本功能不改写已有会话，而是从所选目录启动新会话；其他聊天面板和全局默认目录不受影响。

## 设计边界

- 菜单项只在目录上显示；文件的右键菜单和“加入输入框”行为保持不变。
- 所选路径以服务端实际目录为准。新建会话接口复用现有目录解析，拒绝不存在或不是目录的路径。
- 新建的会话落在触发菜单的当前面板，沿用该面板的模型和审批设置。
- 创建成功后文件树跟随新会话的工作目录，不保留此前手动浏览目录的覆盖值。
- 创建失败时保留当前会话，并显示已有错误提示。

## 实施步骤

1. 扩展文件树目录右键菜单，添加“进入该路径”并传递目录绝对路径。
2. 将路径回调连接到当前聊天面板的新建对话流程，成功后让文件树跟随新会话。
3. 扩展前端新建会话请求，携带可选工作目录。
4. 扩展后端新建会话请求模型和运行时调用，通过现有工作目录解析函数确认路径有效，再用规范化后的路径启动 Codex 会话。
5. 按项目语义化版本规则记录这项新增能力，并检查改动范围及会话工作目录在前后端的传递链路。

## 验收标准

- 右键目录可见“进入该路径”；右键文件时不出现该选项。
- 使用菜单后，当前面板切换到新会话，标题栏和文件树都显示所选目录。
- 新会话再次打开后仍使用所选目录；其他面板的聊天和工作目录不变。
- 不存在的目录不会创建会话，当前聊天保持打开。
- 文件树原有的“加入输入框”功能保持可用。
