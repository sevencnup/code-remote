# Android 消息宽度与图片附件布局修复

## 目标

修复 Android 用户消息仍逐字竖排、多个图片附件把输入框撑高的问题，并将图片缩略图移动到输入框上方，匹配网页端的附件布局。

## 根因与方案

用户消息依赖多层 `WRAP_CONTENT` 和 `maxWidth` 相互推导宽度，窄屏测量结果仍可能塌缩。根据 `StaticLayout` 在最大内容宽度内测出实际行宽，再将用户文本视图设为明确宽度。图片附件当前显示为可换行长文件名，且位于正文输入框下方；改为输入框上方的横向附件栏，图片使用固定尺寸缩略图和移除按钮，文档使用单行省略名称。

## 实施步骤

1. 为聊天文本计算受最大宽度约束的实际行宽，并明确设置文本视图宽度。
2. 为聊天内的图片预览设置明确宽度，避免图片与内容气泡形成循环测量。
3. 将附件栏放到输入框正文之前，使用固定高度和横向滚动布局。
4. 在线程版本与简短版本记录中记为 PATCH，构建新的 Android debug APK，检查差异并提交本地 Git；保留历史 APK，不推送远端。

## 验收标准

- 窄屏中文和英文消息均保持正常横向排版、自然换行及右对齐。
- 两张或更多图片附件以固定尺寸缩略图显示在输入框上方，不因文件名换行撑高输入框。
- 每个图片缩略图均可移除；附件发送数据保持原图内容。
