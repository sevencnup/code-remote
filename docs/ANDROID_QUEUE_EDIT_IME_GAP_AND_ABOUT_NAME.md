# Android 排队编辑键盘间距与项目名称

## 变更分类与版本

- 分类：PATCH / 修复既有编辑布局并更新项目介绍文字。
- 目标版本：`0.56.1-dev.1`，Android `versionCode 316`。
- 版本记录：修复排队消息编辑时输入框被键盘遮挡，并更新关于项目的名称。

## 目标行为

- 设置页“关于”中的项目名称显示为“Code Remote”。
- 排队消息进入编辑后，键盘打开时输入框与键盘之间始终保留额外的底部间距；结束编辑或收起键盘后恢复原有间距。
- 普通输入框的布局保持原样。

## 实施步骤

1. 将设置页项目名称从 `Code Agent Remote` 更新为 `Code Remote`。
2. 记录 IME 的底部 inset，并在排队编辑且键盘可见时为聊天页面增加固定安全间距；进入和退出编辑时同步重算。
3. 更新 PATCH 版本号及变更记录。
4. 编译 Android Kotlin 并构建独立 APK，覆盖安装到已连接设备时保留旧版本安装包；核对已安装版本。不运行独立测试套件。
