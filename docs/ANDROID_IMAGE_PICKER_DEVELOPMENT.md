# Android 图片选择器开发文档

## 目标

让 Android APK 内聊天输入框的图片按钮唤起系统图片选择器，并把选择的图片交回网页输入框。

## 根因

网页使用了标准的 `input[type=file]`，但 Android `WebView` 默认没有 `WebChromeClient.onShowFileChooser` 实现。没有原生文件选择回调时，点击按钮不会打开系统选择器。

## 实施步骤

1. 在 `WebChromeClient` 中接管网页文件选择请求，仅允许选择图片并支持多选。
2. 使用系统 `ACTION_OPEN_DOCUMENT` 选择器，并将返回的 `Uri` 数组交回 WebView。
3. 处理取消选择、重复请求和 Activity 销毁，避免网页文件回调永久悬挂。
4. 更新 Android 版本号和版本记录，构建新的 APK，不覆盖历史产物。
5. 在真机上验证图片按钮、单图选择、多图选择和取消操作。

## 验收标准

- 点击输入框图片按钮能打开系统图片选择器。
- 选择一张或多张图片后，图片缩略图显示在网页输入框内。
- 取消选择不会卡住输入框，后续仍可再次打开选择器。
- 旧版本 APK 保留，新 APK 使用独立版本号。
