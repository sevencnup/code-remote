# 操作记录交互开发文档

## 目标

让操作记录中的文件修改和图片查看步骤可以打开对应内容，同时保持记录默认收起且可以手动展开。运行中的思考状态和计时继续显示。

## 实施步骤

1. 将文件修改记录与当前轮次的文件差异关联，在操作记录中提供可点击的差异预览入口。
2. 从图片查看记录中保留受限的图片路径，并增加只允许读取工作目录内常见图片格式的认证接口。
3. 在现有聊天预览浮层中显示用户点击的图片，并提供操作记录到文件/图片预览的回调。
4. 核实运行状态行、思考文案和计时器在操作记录默认收起后仍可见；修复发现的问题。
5. 更新版本和简短版本记录，执行前端构建、差异检查并创建本地提交。

## 验收标准

- 修改文件记录可以打开对应文件及其差异。
- 图片查看记录可以打开对应图片。
- 操作记录初始保持关闭，用户仍可手动展开。
- 回复进行中显示思考/当前操作和已用时间。
- 仅可通过认证接口读取聊天工作目录内受支持格式的图片。
