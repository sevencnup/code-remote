# 移动端用户消息宽度修复开发文档

## 目标

修复手机窄屏下用户消息气泡被压缩到单字宽、文字逐字竖排的问题，同时保持消息靠右且右边缘与输入框对齐。

## 根因与方案

用户气泡使用 `width: max-content` 参与移动端 CSS Grid 的内在尺寸计算。部分移动浏览器在中文逐字换行场景会把可用宽度收缩到最小内容宽度。

将用户消息行改为右对齐 Flex，气泡改用 `fit-content` 宽度计算；移动端保留 84vw 的最大宽度并设定安全最小宽度。这样短消息仍保持紧凑，长消息使用正常的多字换行宽度。

## 实施步骤

1. 调整用户气泡的内在宽度与最小宽度规则。
2. 在移动端补充稳定的可用宽度上限，避免网格重新压缩气泡。
3. 更新版本记录，执行生产构建和差异检查，并创建本地 Git 提交。

## 验收标准

- 手机端中文、英文和混合消息不会逐字竖排。
- 长消息在约 84vw 的气泡内正常换行。
- 短消息仍紧凑地靠右显示。
- `pnpm --filter codex-remote build` 成功，`git diff --check` 无输出。
