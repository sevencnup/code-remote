# 移除网页版百炼语音输入开发记录

目标版本：`0.43.0-dev.1`（不兼容变更；项目尚处于 `0.x`，按约定递增中版本）。用户认为语音识别延迟过高，明确要求删除该功能。

## 范围与数据边界

- 移除网页聊天输入框的录音按钮、转写状态和百炼配置卡片。
- 移除专属浏览器录音脚本、前端控制器与客户端 API，以及服务端百炼设置/测试 HTTP 接口和语音 WebSocket 接口；保留其他聊天、终端、通知功能。
- 删除仅服务于已移除功能的测试和样式；历史开发文档与历史版本记录保留作追溯。
- 不删除服务器上已保存的 `bailian-voice-settings.json`、环境变量或用户的 API Key；代码移除后它们不再被读取。删除这些用户数据需要另行确认。
- 只在本地仓库提交，不推送远端；不重启正在使用的服务，先以构建产物验证网页。

## 实施步骤

1. 清点百炼相关引用与当前工作树，确认无其他模块依赖。
2. 移除网页录音与设置 UI、样式和前端客户端调用；移除浏览器录音控制器和 worklet 公开资源。
3. 移除服务端百炼模块、模型、初始化和路由；移除专属测试并调整 Vite 测试/配置。
4. 更新前后端版本号及 `CHANGELOG.md`，只记录用户可见的删除描述。
5. 运行前端构建、相关测试和 Python 测试；核对构建产物不再包含录音脚本/入口，检查 `git diff --check`。
6. 仅提交本次涉及文件到本地仓库；验证当前网页构建可访问，不推送 GitHub。

## 验收标准

- 网页输入框不再有麦克风按钮，设置页不再有百炼配置卡片。
- 前后端不再暴露百炼语音相关代码路径/接口；网页其余功能继续构建和运行。
- 已保存配置文件不被删除或输出。
