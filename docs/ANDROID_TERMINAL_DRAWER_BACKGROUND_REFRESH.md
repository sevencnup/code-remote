# Android 终端操作、侧栏手势与后台刷新

## 目标

终端选中文字时，系统选择菜单不遮挡“复制到输入框”；左侧栏从屏幕边缘也能稳定拉出；APP 回到前台后优先更新当前聊天，同时避免后台反复下载聊天内容。

## 开发步骤

1. 将终端“复制到输入框”按钮移到终端底部操作区，保留终端顶部关闭按钮。复制行为与长文本处理沿用现有实现。
2. 允许从左侧边缘开始打开侧栏，降低边缘斜向滑动被误判的概率，保留输入框、设置弹窗与终端操作的触摸优先级。
3. 后台 WebSocket 只接收轻量状态事件和完成通知；收到消息变化时标记待同步，不随每段回复下载聊天历史。
4. 回到前台时保留健康的 WebSocket，优先增量刷新当前聊天，再刷新侧栏与队列；短暂切出且没有变化时避免多余请求。
5. 更新版本记录，构建独立 APK 并安装到设备。

## 流量取舍

短连接心跳与完成事件会消耗少量持续流量；反复拉取完整聊天及图片会更费流量。APP 在后台只监听事件，回前台用服务端历史修订号获取增量，连接异常时才降级为完整窗口读取。系统杀掉 APP 进程后仍无法保证即时通知，需要系统推送或前台服务。
