# AI 群聊 Claude 排队回复丢失修复

## 问题与分类

分类：修复 / PATCH。Claude 回复已进入其独立会话，但在共享队列尚未启动真实轮次时，后台群聊面板可能卸载并丢失同步监听，导致已有群聊能力没有按预期显示回复。

## 版本与记录

- 版本：`0.59.2-dev.1`
- 版本记录：`修复 AI 群聊 Claude 排队回复未同步显示`
- 不生成 Android 安装包，不递增 Android `versionCode`。

## 实施步骤

1. 让群聊面板的后台挂载状态覆盖尚未完成的成员回复等待，而不只覆盖网络发送阶段和已启动的运行阶段。
2. 当成员回复同步完成，或本轮发送失败时，清除等待状态，允许不活跃群聊面板卸载。
3. 保留现有按会话消息 ID 收集增量回复、以及真实轮次状态处理逻辑。
4. 更新版本记录，执行生产构建与 `git diff --check`；不新增或运行测试。
5. 只暂存并提交本次修改到本地 Git，不推送 GitHub。

## 验收标准

- 切换离开群聊后，即使 Claude 消息仍排在共享队列中，群聊面板也持续挂载并监听回复。
- Claude 回复同步完成后，非当前群聊可恢复卸载。
- 已有的独立会话、群消息合并和成员回复等待行为保持不变。
- 生产构建成功，差异检查无输出。
