# Android 文件树上传与品牌展示

## 目标

1. 对照网页端文件树，在 Android 右侧文件树支持从手机选择多个文件，上传到当前目录或指定文件夹，并显示上传进度与结果。
2. 使用 `assets/branding/code-remote.svg` 更新 Android 应用图标和应用内品牌标识。
3. 在设置的“关于”部分显示新 logo，并将项目名称、介绍和 GitHub 入口中的文字居中。

## 分类与版本

- 分类：新增功能 / MINOR。手机用户新增了直接向服务端工作区上传文件的能力；图标和排版调整随本次合并。
- 开发中仓库版本已更新至 `0.88.3-dev.1`，Android `versionCode 375`。
- 目标版本：`0.89.0-dev.1`，Android `versionCode 376`。
- 版本记录：`Android 文件树支持上传文件并更新应用标识`。

## 实现步骤

1. 复用服务端 `/api/v1/codex/workspace/upload`：通过 Android 文件选择器选取文件，流式发送原始字节，单文件上限与网页端一致为 512 MB，避免把大文件整份读入内存。
2. 在文件树顶部和文件夹操作菜单提供上传入口；上传期间显示文件名、序号和进度，完成后刷新目标目录，失败时显示错误且保留已成功上传的文件。
3. 将提供的 SVG 导出为 Android 使用的 PNG 资源，更新应用图标资源，并在“关于”部分显示；将三处介绍文字居中。
4. 更新版本号和版本记录，构建 Android 包并检查改动；只提交本次文件到本地 Git，不推送远端。

## 边界

- 不修改网页端和服务端的上传协议。
- 上传由用户主动在系统文件选择器中选取，不请求广泛存储权限。
- 不覆盖旧安装包。
