# 桌面端嵌套工作区文件预览开发文档

## 目标

桌面端点击文件树或审核文件列表中的文件时，保留现有文件树，并在最右侧打开独立的只读文件预览栏。预览栏可单独调整宽度，并清晰显示所打开文件的路径；移动端使用独立全屏预览层，不参与桌面分栏宽度计算。

## 设计约束

- 不改变现有文件读取接口、安全校验、只读属性、行号、刷新和复制功能。
- 文件树继续显示在预览栏左侧；关闭预览只关闭预览栏，不清空文件树状态。
- 预览栏使用独立拖动分隔条调整宽度，支持键盘方向键、双击恢复默认值；宽度按应用窗口宽度的比例保存在当前浏览器，窗口缩放或切换全屏时按相同比例适配。
- 主聊天区与文件区域均须响应式收缩；宽度限制考虑文件树、预览栏和聊天区的合计，避免打开预览后把聊天内容裁切。
- 预览栏顶部显示完整文件路径，路径可换行并保留完整路径提示；窄栏下操作按钮不得遮挡路径。
- 审核列表打开文件仍使用对应对话的工作目录；切换工作目录时应关闭旧预览并取消过期读取结果。
- 手机端文件树点文件打开全屏预览；“加入输入框”按钮负责路径插入，关闭预览后原文件树状态保留。

## 实施步骤

1. 调整 `WorkspaceExplorer`：文件树保持常驻；文件预览改为最右侧独立面板，关闭按钮仅关闭该面板；将审核入口和桌面端文件树单击统一接入该面板。
2. 扩展桌面主网格，为预览面板增加可键盘操作的独立分隔条，并为文件树及预览栏的宽度计算加入聊天区最小可用宽度约束。
3. 为预览栏宽度新增独立持久化比例设置；支持拖动、方向键调整和双击恢复默认值，窗口尺寸变化时按窗口宽度比例缩放并遵守布局宽度限制；兼容旧版像素宽度设置。
4. 显示可换行的完整文件路径，并适配窄预览栏中的工具栏、代码区及各主题样式。
5. 更新 `CHANGELOG.md` 版本记录，执行 TypeScript 检查、Vite 生产构建和 `git diff --check`；确认未启动服务进程后创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 桌面端打开文件后，文件树仍在左侧，文件内容在最右侧独立栏显示。
- 文件预览栏显示完整路径、代码行号，并保留只读、刷新、复制及滚动能力；关闭后文件树展开和滚动状态不丢失。
- 预览栏可用鼠标和键盘独立调整宽度，双击分隔条恢复默认宽度，刷新后宽度比例保留；窗口从自定义尺寸切换到全屏或反向切换时，预览栏相对窗口宽度的比例保持不变（受聊天区和预览区最小/最大宽度约束）。
- 审核文件入口仍针对触发入口所属对话的工作目录读取文件。
- 收窄预览栏或窗口时，路径和按钮不会互相覆盖，聊天区不会被网格裁切。
- 手机端不显示调宽分隔条；文件树插入路径和全屏预览分别由加号按钮与文件点击触发。
- TypeScript 检查、Vite 生产构建和 `git diff --check` 均通过。
