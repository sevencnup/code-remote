# 工作区文件树上传开发文档

## 需求与版本分类

用户希望直接从网页把本机文件放进右侧文件树的指定目录，包括在浏览器能够读取系统剪贴板文件时用粘贴上传。当前文件树的复制、剪切、粘贴只操作服务端已有条目。新增本机文件上传能力属于新增功能 / MINOR，目标版本为 `0.80.0-dev.1`。

## 实施步骤

1. 后端增加已配对设备可用的工作区文件上传接口。沿用现有工作区目录与文件名校验，按块写入文件，限制单文件大小，拒绝同名覆盖，并在上传失败时清理不完整文件。
2. 前端请求层发送原始文件内容，保留文件名和目标目录；无需将文件转成聊天附件或 Base64。
3. 在文件夹及工作区根目录的右键菜单增加“上传本机文件”，支持一次选择多个文件，显示上传进度、刷新目标文件夹，并说明失败原因。
4. 文件树获得焦点时，识别系统剪贴板中的文件并上传到最近选中的文件夹；输入框粘贴与文件树内部复制粘贴继续按各自入口处理。浏览器无法提供剪贴板文件时，用户仍可使用文件选择器。
5. 更新版本记录，检查代码与构建结果，清理临时资源，并提交本地 Git 仓库。

## 验收范围

- 右键目标目录后能从本机选择多个文件上传，根目录也可作为目标。
- 浏览器提供文件对象时，在文件树中粘贴可上传到所选目录。
- 同名文件不被覆盖，路径不会逃出所选工作区；失败的上传不留下半个文件。
- 上传后文件树显示新文件，已有的服务端文件复制、剪切、粘贴仍可用。

## 后续优化：底部上传进度条

用户需要在上传时看到真实的传输进度。此变更改善已有上传功能的反馈，属于体验优化 / PATCH；上传功能仍在 `0.80.0` 内部测试阶段，版本递增为 `0.80.0-dev.2`。

1. 将上传请求改为能提供浏览器发送字节进度的传输方式，保留配对认证、单文件 512 MB 限制、服务端错误信息和十分钟超时。
2. 文件树底部上传时显示当前文件、批次序号、已发送字节、百分比和进度条；浏览器发完文件但服务端尚未确认时明确提示等待确认。
3. 上传完成后恢复原有底部提示；部分文件失败时继续上传其余文件，并显示汇总与失败原因。兼顾桌面和移动端窄文件树。
4. 更新版本记录，检查构建并提交本地仓库。

验收时确认进度条随浏览器实际发送字节前进，多文件切换清晰，超限、同名和网络失败仍有提示。
