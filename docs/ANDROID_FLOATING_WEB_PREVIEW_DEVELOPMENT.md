# Android 聊天网页悬浮预览开发说明

## 目标与分类

聊天中的 HTTP/HTTPS 链接目前直接交给外部浏览器。新增 App 内可调整大小的网页悬浮预览，让用户查看页面时仍能看到并操作聊天输入框。用户因此可以在 App 内完成原先必须跳出 App 才能完成的网页查看，归类为新增功能 / MINOR。

目标版本：`0.31.0-dev.3`，Android `versionCode 275`。

## 交互设计

- 点击助手或用户消息里的 HTTP/HTTPS 链接，在聊天页面打开悬浮网页预览。
- 预览使用 Android WebView，提供返回、前进、刷新、外部浏览器打开和关闭操作；非网页协议继续交给系统应用处理。
- 悬浮窗默认位于聊天区域，不遮挡输入框；可拖动右边调整宽度，拖动顶边或底边调整高度，并记住用户上次的尺寸。拖动顶边时保持底边位置，拖动底边时保持顶边位置。
- 关闭预览时停止加载并销毁 WebView；仅允许 HTTP/HTTPS 页面留在预览中，不注入 JavaScript 原生桥接。

## 实施步骤

1. 将聊天文本中 HTTP/HTTPS 链接的点击处理改为打开 App 内预览；保留非网页协议的系统打开行为。
2. 创建轻量可调尺寸 PopupWindow 和 WebView，增加导航工具栏、加载进度、边界约束及输入框避让。
3. 保存宽度和高度比例，并在屏幕旋转或可用区域变化时按当前聊天区尺寸恢复。
4. 更新版本号与 CHANGELOG，构建新的独立 APK，安装到已连接设备并检查版本及主要界面操作。
5. 执行 `git diff --check` 并创建本地提交；不推送 GitHub。

## 验收标准

- 助手 Markdown 链接、助手裸网址和用户消息网址均可在 App 内打开 HTTP/HTTPS 页面。
- 网页预览提供返回、前进、刷新、外部浏览器和关闭按钮。
- 右侧边缘可调整宽度；顶部和底部边缘都可调整高度，分别保持相对侧的位置；调整后输入框保持可见和可操作，尺寸可恢复。
- 关闭预览后页面不再加载，WebView 资源释放。
- 新 APK 可在现有应用上覆盖安装并保留配对和本机数据。
