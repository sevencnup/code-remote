# 会话历史后台预热开发文档

## 目标

缩短聊天切换等待时间：用户打开过的会话应在本次页面会话内保留历史，切换时先立即显示缓存内容，再在后台静默同步最新服务端历史；近期会话也应在空闲时预热。

## 根因

- 当前只将最后一个活动会话写入浏览器存储。
- 切换至其他会话时会先清空消息列表，再等待 `thread/read` 返回。
- 非当前会话回复完成后只刷新侧边栏状态，没有把完成后的完整历史放入缓存。

## 实施步骤

1. 增加受容量和条目数限制的内存 LRU 会话缓存，保留消息、会话信息及运行状态。
2. 切换会话时优先使用内存缓存或现有持久化缓存，取消不必要的前台加载遮罩，并继续后台同步。
3. 对最近会话安排低优先级预热；后台会话完成后强制刷新其缓存，使回切可直接看到完整回复。
4. 保留现有历史版本号校验，避免后台读取覆盖当前会话中的乐观消息或流式内容。
5. 更新版本记录，执行构建、后端测试和差异检查后创建本地提交。

## 验收标准

- 已访问过的会话切回时立即显示上次内容，不再先出现空白加载页。
- 后台会话完成回复后，切回可直接显示完成内容，后台同步不阻塞输入。
- 缓存受条目数和内容大小限制，不会因大量长会话持续占用内存。
- `pnpm build`、后端单元测试和 `git diff --check` 均成功。
