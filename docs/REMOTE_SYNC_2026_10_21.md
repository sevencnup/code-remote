## 步骤

1. 获取两个远端的最新 `main`，核对分叉和改动范围。
2. 将 `github/main` 合并到本地 `main`；冲突处保留当前 Code Remote 更名、版本和界面功能，同时纳入 GitHub 的后端修复。
