# 代码选区备注开发记录

## 目标

在文件预览选区的“添加到对话”入口增加可选备注输入，让备注与选中的代码、文件路径及行号一起加入同一份 Markdown 附件，方便后续按选区编号说明修改意图。

## 交互约束

- 备注可选；留空时维持现有添加选区的行为。
- 备注和代码选区必须写入同一个附件，文件路径、行号与既有选区编号逻辑继续保留。
- 备注支持多行；加入附件后清除当前选区菜单和备注草稿。
- 输入备注时保留正常文本编辑和复制快捷键，不触发页面的代码复制行为。
- 桌面端和移动端上下文菜单均需适配输入框及屏幕边界。

## 实施步骤

1. 在文件预览的选区上下文菜单中加入多行备注输入框，并处理菜单定位及键盘快捷键。
2. 扩展代码选区 Markdown 附件生成函数，将非空备注放在代码和路径信息之前。
3. 补充附件内容测试，更新版本记录并运行测试、生产构建和差异检查。
4. 创建本地 Git 提交；未收到明确命令前不推送 GitHub。

## 验收标准

- 可以不填备注，继续按原方式添加选区。
- 填写的备注与选区源码、文件路径和行号在同一个附件中，能供 Codex 按编号理解修改意图。
- 在备注框里输入和复制文本不会被上下文菜单快捷键劫持。
