# 全文件系统浏览与手动绑定目录开发文档

## 目标

将右侧文件区扩展为后端主机的文件资源管理器：用户可输入并绑定任意现存目录作为浏览根目录，在其子目录中浏览并预览文本文件；隐藏目录和原先跳过的目录也可查看。该功能只改变文件区的浏览根目录，不改写当前 Codex 会话保存的工作目录。

## 安全与边界

- 文件区 API 仍必须通过现有配对令牌鉴权；不新增公开或未鉴权接口。
- 去掉当前“必须位于项目根目录父级内”的限制，允许显式绑定后端主机上的绝对目录。
- 目录树和文件预览仍将子路径限定在当前绑定根目录之内，并拒绝相对路径穿越及解析后逃逸的符号链接；超过单页数量的条目可继续加载，不遗漏目录项。
- 文件预览继续只读，并保留 UTF-8、二进制、文件大小和行数限制；解除隐藏文件/忽略目录过滤。
- 绝对路径必须由后端所在操作系统解释。移动端输入的是服务端路径，不是手机本地路径。

## 实施步骤

1. 调整后端目录根解析：接受并规范化任意现存目录，保留不存在目录、非法路径和权限错误提示；移除固定父目录限制。
2. 调整文件树和预览过滤：显示点号隐藏项和此前忽略的目录；仍保留绑定根内的路径穿越保护和只读文本预览上限。
3. 增加文件区路径输入、绑定/打开和上级目录操作；默认跟随当前聊天目录，手动绑定后保存在当前浏览器，并允许恢复跟随聊天目录。
4. 让目录加载、预览、刷新和加入输入框都使用当前浏览器绑定的根目录；从审核卡片打开文件时继续使用该聊天自身的工作目录。
5. 补充后端测试，验证可绑定外部目录及隐藏文件，同时验证绑定根外的相对穿越仍被拒绝。
6. 运行后端测试、TypeScript 构建、Vite 构建和 `git diff --check`；记录版本更新说明并提交本地 Git，不推送 GitHub。

## 验收标准

- 可在文件区输入如 `D:\\Projects\\demo` 或 `/home/user/project` 并打开；实际路径按后端主机系统填写。
- 树区域可浏览该目录下的所有目录项，包括隐藏项和常见依赖/构建目录；大目录可分批继续加载。
- 绑定目录可预览其内允许的 UTF-8 文本文件；二进制和超过既有限制的文件仍被拒绝。
- 绑定根目录外的 `..` 路径和越界符号链接无法访问。
- 现有配对鉴权、聊天目录展示和审核卡片文件预览行为不回归。
