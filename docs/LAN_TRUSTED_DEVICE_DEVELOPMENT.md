# 局域网受信任设备开发记录

## 目标

让同一局域网中的手机或电脑在首次输入配对码后，作为受信任浏览器继续访问本机 Codex Remote；后端重启不再要求该浏览器重新配对。

## 范围与安全边界

- 仅通过 `dev:lan` 或 `preview:lan` 暴露网页；Codex 引擎继续只监听 `127.0.0.1`，由 Vite 反向代理访问，不能直接从局域网访问引擎端口。
- 每次引擎启动仍生成新的配对码，且只用于首次授权新浏览器。
- 浏览器保存原始访问令牌；服务端只持久保存令牌的 SHA-256 摘要，不保存配对码或原始令牌。
- 受信任令牌保存在 `~/.codex/codex-remote/trusted-devices.json`，文件权限设为仅当前用户可读写。可通过 `CODEX_REMOTE_AUTH_FILE` 更改文件位置。
- 退出网页时向服务端撤销当前令牌，并删除本地令牌；清除浏览器站点数据、换浏览器或手动撤销后都需要重新配对。

## 实施步骤

1. 为后端配对认证增加安全的本地持久化令牌摘要存储，启动时加载、首次配对时写入、撤销时删除。
2. 新增当前设备退出并撤销令牌的 API，前端退出操作调用该 API。
3. 更新局域网启动和撤销方式说明。
4. 新增后端单元测试，验证重启后令牌仍有效且撤销会跨重启生效；执行前端生产构建。
5. 更新版本记录并创建本地 Git 提交。

## 验收标准

- 同一浏览器在服务端重启后能直接恢复访问，无需再次输入配对码。
- 新浏览器、无痕窗口或清除站点数据后必须使用当次启动的配对码。
- 原始令牌和配对码均不会写入服务端磁盘文件。
- 退出后，当前浏览器保存的旧令牌无法再通过 API 或 WebSocket 认证。
- 局域网网页继续经 Vite 代理访问 loopback 引擎，`18766` 不暴露到局域网。
