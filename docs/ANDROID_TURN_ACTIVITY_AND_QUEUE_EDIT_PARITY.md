# Android 轮次活动与文件改动展示对齐

## 目标

让 Android 原生聊天显示与网页版对应的三个层次：回复期间的文件更改摘要、操作执行状态与耗时、轮次结束后的“本次已编辑”文件卡片。网页版编辑排队消息时，将取消编辑操作移到输入区上方，底部只保留确认操作，避免误点“停止回复”。

## 步骤

1. 对照网页端轮次文件更改、操作活动和计时的数据来源，复用 Android 已有的线程快照与通知数据。
2. 在 Android 输入框上方显示当前轮次的文件更改数和增删行数，可展开文件明细。
3. 在回复内容的文件更改位置显示轻量记录；把轮次结束后的文件汇总改为带首个文件、审核入口及“查看另外 N 个文件”的卡片，并放在该轮最后。
4. 在 Android 运行状态行显示当前命令或正在查看的文件、已用时间；计时只更新状态文字，不重建聊天记录。
5. 调整网页版编辑排队消息时的按钮：底部移除“停止”，取消编辑移到输入区上方，保留打勾确认。
6. 检查页面构建与 Android APK 构建，安装递增版本，完成本地提交。

## 验收

- Android 当前轮文件变更在输入框上方可见，回复内的文件更改记录处于对应位置，完成后有“本次已编辑”卡片。
- 文件卡片显示增删统计、首个文件、审核、插入对话和其余文件展开；文件可打开差异预览。
- 运行状态展示命令或文件名，并按秒更新已用时间；结束后计时停止。
- 网页编辑排队消息时底部没有“停止”键，可在上方取消编辑或用勾确认修改。

## 实施记录

- Android 文件更改从操作记录中提取轻量行，并在轮次末尾展示“本次已编辑”卡片；运行中的文件统计显示在输入框上方。
- 运行行读取轮次开始时间，按秒更新耗时；文件改动独立变化时只刷新最后一轮。
- 网页排队编辑的底部停止键已移除，取消操作移至输入区顶部。
- Android `.dev.1` 和 `.dev.2` 曾用于编译和安装核对；根据参考图把文件记录改为可展开的文件数摘要，把运行命令与“已用 X 分 X 秒”分行显示。最终包递增到 `0.28.0-dev.3` / `versionCode 234`。
- `.dev.3` APK 离线构建成功并覆盖安装，设备确认 `versionName=0.28.0-dev.3`、`versionCode=234`，旧包文件均保留。
- 共享工作区的网页构建被同期未完成的侧边栏批量操作代码阻挡（`threadDeleteTarget` 尚未统一迁移），本次网页修改仅单独纳入提交；待那组改动完成后需重新运行网页构建。
