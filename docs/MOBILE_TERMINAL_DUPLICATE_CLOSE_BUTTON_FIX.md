# 移动端终端重复关闭按钮修复

## 目标与分类

修复移动端打开本机终端后同时出现两个关闭叉号的问题。本次属于 PATCH：移除已有终端浮层里的重复关闭入口，不改变终端功能。目标版本为 `0.8.0-dev.8`。

## 实施步骤

1. 移动端终端打开时隐藏聊天标题栏中的终端切换按钮，保留浮层标题栏唯一的关闭按钮；桌面端行为保持不变。
2. 更新 Web 版本、Android `versionName` 和变更记录；Android 原生代码不变，不生成 APK 或递增 `versionCode`。
3. 构建 Web 静态资源供当前 preview 服务使用，不重启管理 Codex 进程的服务。
4. 不新增或运行测试；检查差异并只提交本次文件，不推送 GitHub。

## 完成标准

- 移动端终端打开时只显示一个关闭叉号。
- 关闭后聊天标题栏中的终端按钮恢复显示。
- 保留用户已有的 `docs/ANDROID_APK_DEVELOPMENT.md` 修改。
