# 侧边栏聊天搜索与顶部紧凑布局

## 目标

在侧边栏“新建对话”按钮上方增加聊天搜索框，并压缩侧边栏品牌栏及其周围间距，减少移动端侧边栏顶部占用。

## 用户可见行为

- 搜索框位于品牌栏下方、“新建对话”按钮上方。
- 搜索当前模式下已经加载的聊天名称和最近消息摘要；不因输入搜索词而读取聊天正文。
- 搜索不区分英文字母大小写，并保留置顶聊天排序。
- 有搜索词但没有匹配结果时，显示明确的无匹配提示；清空搜索词后恢复完整聊天列表。
- 当前折叠侧栏不显示搜索控件；收窄侧栏时清空筛选，避免搜索框隐藏后列表仍处于过滤状态。
- 收紧品牌栏高度、侧栏顶部内边距及品牌栏到新建按钮之间的空白；移动端和横屏触控布局同步调整。

## 实施步骤

1. 在侧栏组件中加入受控搜索词和搜索框，使用现有线程元数据过滤当前引擎的列表。
2. 增加搜索框、结果提示和空结果样式，适配深色、白色、暖色及自定义主题。
3. 缩小侧栏顶部与品牌栏间距，并检查桌面、移动端及触控横屏规则。
4. 将网页、服务端和 Android 版本提升至 `0.18.0-dev.1`，并递增 Android `versionCode`；在变更记录中只记录用户可见更新描述。
5. 完成生产构建、差异检查和本地 Git 提交；保留工作区中既有的 Android 开发文档修改，不推送到 GitHub。

## 验收标准

- 搜索框显示在新建对话按钮正上方，可输入、清空并即时筛选。
- 匹配聊天名称或最近消息摘要时显示对应会话，且会话仍按置顶状态排序。
- 无匹配结果和空搜索状态有正确提示。
- 折叠侧栏不出现挤压布局的搜索框，且不会保留不可见的筛选状态。
- 移动端侧栏顶部明显更紧凑，搜索框和新建按钮仍易于触控。
- 搜索操作不会触发额外的聊天正文网络请求。
