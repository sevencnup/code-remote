# 自定义主题颜色覆盖开发记录

## 目标

让自定义主题中配置的背景、面板、控件和文字颜色覆盖聊天、操作记录、文件审核、文件树与预览、输入区、菜单及弹层；不让模块继续暴露固定深色主题底色。

## 实施步骤

1. 盘点自定义主题颜色变量的生成与应用范围，按截图核查操作记录、文件编辑器、关闭/复制按钮，并扩展检查所有带固定背景色的界面模块。
2. 为基础表面、次级表面、控件、悬停/选中状态、边框和弱化文字建立一致的自定义主题映射；保留语法高亮、增删差异、状态提示等语义颜色。
3. 验证自定义主题相关代码与样式，运行测试和生产构建。
4. 更新版本记录，检查变更范围并完成本地 Git 提交；不推送 GitHub。
