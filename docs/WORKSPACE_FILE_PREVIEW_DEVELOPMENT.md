# 桌面端工作区文件预览开发文档

## 目标

在电脑端支持从右侧文件树和审核文件列表打开工作区文件只读预览；预览仍位于右侧文件区，通过单独的竖向分隔条调整文件区宽度。手机端本次保持原有文件浮层及路径插入行为。

## 设计边界

- 文件预览只读，不提供保存或修改工作区文件的接口。
- 读取接口沿用配对令牌鉴权与当前线程工作目录约束；拒绝工作区外路径、隐藏文件/目录、忽略目录、二进制文件和超出大小/行数限制的文件。
- 仅展示 UTF-8 文本；前端以等宽字体、独立行号和可横向滚动的代码区呈现，不新增语法高亮依赖。
- 桌面端单击文件树文件后，在文件树右侧的独立栏打开预览，文件树保持显示；关闭预览后文件树的展开和滚动状态保留。右键菜单继续用于插入路径，移动端的“加入输入框”按钮和点按插入行为保持不变。
- 审核卡片中的文件路径也可打开对应工作区文件预览；不同并发对话必须使用该对话自己的工作目录。
- 桌面端右侧文件区宽度由独立分隔条调整，范围为 220–2400px；上限随窗口宽度动态变化，最多占聊天区与文件区可用宽度的约 66%，并为聊天区保留约 240px；设置保存在当前浏览器，分隔条支持键盘方向键。文件树不启用拖放文件到输入框。
- 聊天区和输入框根据实际列宽自适应收缩；窄列下精简状态栏并重排输入框设置和操作按钮，空间不足时隐藏输入框右侧的快捷键文字提示，避免被右侧分隔边界裁切。
- 手机端不增加预览或宽度调整；文件条目的现有点按插入路径行为保持不变。

## 实施步骤

1. 在后端增加受配对令牌保护的文本文件读取接口，复用工作目录和路径解析校验，并限制隐藏/忽略路径、文件字节数、行数及 UTF-8 文本格式。
2. 增加客户端文件读取类型与请求方法。
3. 扩展右侧文件资源管理器：桌面端单击文件加载只读预览，提供返回、刷新、复制、路径和行号；保留文件树的展开/滚动状态及路径插入操作。
4. 将审核卡片的文件路径接入当前对话工作目录下的预览入口。
5. 增加桌面端可键盘操作的垂直分隔条，拖动调整右侧文件区宽度并持久化；移动端隐藏分隔条且保留既有交互。
6. 增加路径、安全边界和文本限制测试；更新版本记录，执行前端构建、后端测试和差异检查，并创建本地 Git 提交。

## 验收标准

- 桌面端单击文件树中的文件或审核列表中的路径，右侧区域显示对应文本文件预览；返回后文件树状态保留。
- 文件预览显示路径、代码行号和可横向/纵向滚动的代码；可复制文件内容。
- 目录、隐藏/忽略路径、工作区外路径、二进制文件和超限文件不会被预览。
- 右侧分隔条可鼠标拖动和键盘调整；宽度在合理范围内并在刷新后恢复。
- 文件树桌面端右键菜单和移动端“加入输入框”行为不变，仍不支持拖放。
- 手机端文件条目仍插入路径，本次不出现预览视图或调宽分隔条。
- 前后端相关测试通过，TypeScript/Vite 构建成功，`git diff --check` 无输出。
