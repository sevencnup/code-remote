# CPA Usage Settings Save Button

## 用户可见分类与版本

- 分类：新增功能（MINOR）。设置页增加独立的配置保存能力，用户可以先保存地址和密钥，再处理连通性问题。
- 目标版本：`0.58.0-dev.1`。

## 目标

将 CPA Manager 设置中的“测试连通性并保存”拆成两个明确操作：测试只检查当前填写的地址和密钥，不改变已保存配置；保存只将配置写入 Codex Remote 服务端共享状态，不要求 CPA Manager 此刻可连接。

## 实施步骤

1. 在 Codex Remote 后端增加认证后的 CPA 连接测试接口；测试请求使用当前表单凭据，密钥留空时仅允许沿用同一地址已保存的密钥。
2. 调整设置保存接口，使其仅校验并持久化地址和密钥，不发起 CPA 网络请求；修改地址时仍要求输入管理密钥。
3. 在前端增加独立“测试连通性”和“保存配置”按钮，显示各自的加载状态与结果；测试成功不自动保存，保存成功后更新共享状态并清空密码输入。
4. 更新版本号、CHANGELOG 和本开发文档；执行前端构建与差异检查，不新增或运行测试。
5. 审阅改动并本地提交，不推送远端。

## 安全与兼容

- 两个接口继续使用现有配对认证。
- 管理密钥只由前端提交到 Codex Remote 服务端；测试接口不回传密钥，配置读取响应不变。
- 连接测试仍通过后端代理请求 CPA analytics 接口，沿用既有地址校验、超时和重定向限制。
- 配置保存支持 CPA Manager 暂时离线；统计查询在连接恢复后使用已保存配置。

## 验收要点

- “测试连通性”成功或失败都不更改服务端共享配置。
- “保存配置”成功后其他已配对设备可读到更新后的地址和已配置状态。
- CPA Manager 暂时离线时仍可保存配置。
- 更换地址时不能遗漏新的管理密钥；同一地址留空密钥可保留现有密钥。
- 前端构建成功，提交内容不包含未跟踪的历史 APK 产物。
