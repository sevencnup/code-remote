# 文件预览选区引用开发记录

## 目标

在右侧文件预览中选中代码后，通过右键菜单将代码引用插入聊天输入框；引用包含本机文件路径、对应行号范围和所选内容。

## 交互与实现约束

- 只有在预览代码或编辑器中存在有效选区时才接管右键菜单；无选区时保留浏览器默认菜单。
- 预览模式按实际选中的代码行计算范围；编辑模式按文本选区偏移计算范围。
- 插入内容使用路径、行号和 Markdown 代码块，代码中已有反引号时自动选择更长的围栏，避免内容被截断。
- 通过输入框现有草稿接口插入，不自动发送、不覆盖已有草稿；插入后按桌面/移动端当前文件面板状态处理焦点。
- 保留文件树已有右键菜单，并提供复制所选内容的菜单操作。

## 实施步骤

1. 增加选区引用格式化工具和单元测试。
2. 为预览行暴露行号信息，支持普通预览、差异预览与编辑器中的右键选区。
3. 添加文件预览选区右键菜单和输入框追加文本接口，不干扰文件树右键菜单及已有草稿。
4. 补充样式、版本记录，运行前端测试、生产构建和差异检查。
5. 创建本地提交；未收到明确命令前不推送 GitHub。

## 验收标准

- 选中一段代码并右键，可将准确路径、行号范围和选中代码插入输入框。
- 复制选区、取消/关闭菜单、无选区时的浏览器默认菜单均正常。
- 差异预览的增删标记和行号不会丢失；编辑器选区可获得正确行号。
- 已有草稿不会被覆盖，选区引用不会因路径去重逻辑而丢行。
