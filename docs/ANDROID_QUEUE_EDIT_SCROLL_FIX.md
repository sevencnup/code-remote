# Android 排队消息编辑滚动修复

## 目标与分类

修复长排队消息进入编辑后，输入框末尾和操作按钮被展开的队列及键盘挤出屏幕、手指无法上下查看文本的问题。属于 PATCH：恢复已有编辑功能的可见性和操作便利性。目标版本为 `0.76.1-dev.1`，Android `versionCode` 为 `359`。

## 原因

- 排队列表和编辑输入框共处于底部 composer。进入编辑后队列仍保持展开，卡片过多时使 composer 高于键盘上方的可用高度。
- 多行输入框限制为五行，但没有明确设置纵向滚动手势与超长文本进入编辑时的光标位置。

## 实施步骤

1. 编辑排队消息时暂时收起队列内容，退出编辑后恢复原有展开状态；键盘出现期间保持队列内容收起，确保输入框与底部操作区可见。
2. 为多行输入框配置内部纵向滚动；载入排队消息后将光标定位到文本末尾，使末尾内容可立即查看和继续修改。
3. 更新 Android 与项目版本标识以及简短版本记录。
4. 构建独立 APK，检查改动与构建结果；不运行测试，不安装到设备。本地提交，不推送 GitHub。

## 完成标准

- 展开队列后编辑长消息，键盘打开时输入框和确认按钮仍在可见区域，输入框可通过上下滑动查看文本。
- 退出编辑后原队列展开状态保留；键盘关闭后队列内容恢复显示。
- 原草稿及附件在取消或保存编辑后按既有逻辑恢复。

## 实施结果

- 编辑期间以及键盘显示期间暂时隐藏排队列表，保留队列原来的展开状态；关闭键盘或结束编辑后按原状态显示。
- 编辑长消息时输入框限制为三行可见区域，文本在框内纵向滚动；进入编辑后定位到末尾。
- `:app:assembleDebug --offline --no-daemon` 构建成功，APK 单独保存为 `artifacts/code-remote-android-0.76.1-dev.1-debug.apk`；`git diff --check` 无输出。
- 按本次任务约定未运行测试，也未安装到设备。
