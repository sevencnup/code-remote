# Android 运行状态与聊天记录同步显示

## 目标与分类

打开正在运行的聊天时，Android 先显示“正在加载聊天记录…”，却同时显示“正在思考/正在运行”状态行。网页版在历史记录加载期间隐藏运行状态。本次修正现有显示顺序，属于修复 / PATCH，目标版本 `0.66.1-dev.1`，Android `versionCode 349`。

## 实施步骤

1. 对照 Android 的历史加载状态和网页版运行状态的显示条件，确认状态行与加载占位文字同屏的原因。
2. 在 Android 聊天渲染中，历史加载期间隐藏运行状态行；已有缓存历史时继续即时显示。
3. 历史请求完成后确保重新渲染，即使增量响应没有新消息，也清除加载占位并显示对应的运行状态。
4. 更新版本，构建 Android APK，保留历史安装包；核对改动后仅做本地 Git 提交。

## 预期结果

- 加载占位文字与“正在思考/正在运行”不同时出现。
- 聊天记录可显示时，运行状态出现在记录下方；缓存历史仍可立即显示。
- 空增量响应或加载失败不会把旧占位文字留在页面上。
