# CPA 按模型显示消耗金额

## 目标

在 Token 用量统计页面的“按模型”表格中增加每个模型的消耗金额，沿用当前 Manager Server 返回的模型分组统计和 USD 展示格式。

## 分类与版本

- 分类：新增功能 / MINOR。用户可以查看此前模型明细中没有单独展示的金额。
- 目标版本：`0.63.0-dev.1`。
- 版本记录：`在 CPA 用量统计中显示各模型消耗金额`。

## 执行步骤

1. 使用 `model_stats[].cost` 展示模型金额，不在前端根据 Token 数重新估算。
2. 使用现有美元金额格式化器；接口未返回有效金额时显示 `—`，避免把未知金额误报为 `$0.00`。
3. 更新版本与 changelog，保留工作区现有的 Android 终端改动。
4. 运行前端构建和 `git diff --check`；不执行测试套件。

## 验收标准

- 按模型表格出现金额列，使用当前所选时间范围和调用方筛选的统计结果。
- 有有效 `cost` 时显示两位小数的美元金额；缺失或无效时显示 `—`。
- 其他概览金额、账号表格和筛选行为保持不变。
