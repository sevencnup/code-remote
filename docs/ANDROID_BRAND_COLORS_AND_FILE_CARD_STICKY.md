# Android 侧栏配色与文件卡片滚动优化

## 目标

- Codex 聊天图标在白色、黑色、暖色和自定义主题中保持蓝色。
- Claude 模式侧栏底部操作与设置页普通文字使用主题文字色，选中项仍有可辨认的状态。
- 展开“本次已编辑”文件卡片后，标题和底部操作保持可见，文件列表独立滚动。

## 步骤

1. 核对侧栏图标、底部操作、设置选中项及文件卡片的现有绘制逻辑。
2. 固定 Codex 品牌蓝色；将普通操作文字恢复主题文字色，并保留选中背景和勾选图标。
3. 把展开卡片的文件内容放入有高度上限的滚动区域，使标题和底部操作固定在区域两端。
4. 更新 Android 版本与简要版本记录，构建新 APK，检查差异并提交本地 Git。

分类：PATCH / 修复配色与改进已有卡片的滚动操作；目标版本 `0.28.2-dev.2`，Android `versionCode` 246。

## 执行结果

- Codex 品牌图标使用按背景明暗选择的蓝色；Claude 模式的侧栏底部及设置页普通文字使用主题文字色。
- 展开文件卡片后标题和底部控制留在卡片两端，文件列表按屏幕高度限制并独立滚动。
- Android debug 构建完成，独立 APK 已保存并安装到连接的手机；未做界面实机逐项操作检查。
