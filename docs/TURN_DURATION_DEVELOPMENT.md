# Codex 轮次耗时开发文档

## 目标

在对话消息流底部显示当前网页发起的 Codex 轮次耗时。任务运行时实时显示已用时间，完成或中断后固定显示最终耗时。

## 输入框状态

Codex 正在回复时继续保持输入框、模型、思考强度、授权模式和图片附件锁定，只保留停止操作。当前远程端不提供插队或排队发送；允许编辑会造成“已输入但无法发送”的歧义。

## 实施步骤

1. 在远程状态 hook 记录本轮启动时间和最终耗时。
2. 处理 `turn/started`、`turn/completed`、发送失败、切换对话和新建对话，确保计时正确开始、结束或清除。
3. 在消息流末尾增加 Codex 风格的耗时行，并每秒刷新运行中的时长。
4. 更新版本记录，执行生产构建和差异检查，并创建本地 Git 提交。

## 验收标准

- 发送后立即显示“已用”时间，并每秒更新。
- 正常完成或停止后显示“用时”，数值不再变化。
- 切换或新建对话时不会保留上一轮耗时。
- 输入框在回复期间保持锁定，停止操作仍可用。
- `pnpm --filter codex-remote build` 成功，`git diff --check` 无输出。
