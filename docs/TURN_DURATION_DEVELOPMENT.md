# Codex 轮次耗时开发文档

## 目标

在对话消息上显示本轮时间信息：用户消息显示提交时间，Codex 回复显示开始时间和耗时。回复生成时实时显示已用时间，完成或中断后固定最终耗时。

## 时间定义

- 用户时间记录网页收到发送操作的时间；排队消息显示其进入队列的时间。
- Codex 用时从 App Server 的 `turn/started` 开始，到 `turn/completed` 结束；排队等待时间不计入回复用时。
- 历史对话优先使用 App Server 的 turn/item 时间；用户消息没有独立时间时回退到 turn 开始时间。

## 实施步骤

1. 在消息模型和历史解析中保存用户发送时间、Codex 回复开始时间及可用的历史耗时。
2. 在远程状态 hook 依据 `turn/started`、`turn/completed` 记录轮次耗时，并处理发送失败、排队、切换对话和新建对话。
3. 在用户气泡旁显示发送时间，在 Codex 回复头部显示开始时间与实时/最终耗时。
4. 更新版本记录，执行生产构建和相关测试、差异检查，并创建本地 Git 提交。

## 验收标准

- 实际 turn 开始后显示“已用”时间，并每秒更新；排队等待时间不计入。
- 正常完成或停止后显示“用时”，数值不再变化，并对应到该条 Codex 回复。
- 用户消息显示发送时间；Codex 回复显示开始回复时间。
- 切换或新建对话时不会把上一轮运行计时带入新对话；已完成的消息时间仍随历史保留。
- `pnpm --filter codex-remote build` 成功，`git diff --check` 无输出。
