# 网页终端异常隔离与恢复

## 分类与目标

本次属于修复 / PATCH：打开终端时偶发的 React 界面异常不应把整个聊天页替换成全页恢复卡片。与 tmux 鼠标拖选修复一起并入 `0.40.1-dev.1`。

## 诊断

- 截图中的提示由应用根部 `AppRecoveryBoundary` 显示，说明终端打开期间有 React 渲染或生命周期异常，并且 350 毫秒内的自动重建再次遇到异常。
- 根边界覆盖聊天页和终端。终端子树的异常因此会短暂打断整页，而且边界丢弃了捕获到的错误，无法留下可诊断信息。
- 将终端放入独立边界，失败时只显示终端面板内的重试与关闭操作；记录错误和组件堆栈到控制台，保留根边界作为整页的最后保护。

## 实施步骤

1. 为终端组件增加局部错误边界，重试时重新挂载终端，关闭时返回原聊天页。
2. 为根边界和终端边界记录捕获的异常，避免丢弃诊断信息。
3. 维持当前聊天错误恢复行为；完整构建网页，确认终端鼠标选区修复同时通过浏览器交互验证。
4. 更新当前 PATCH 版本记录，并与终端鼠标选区修复一起本地提交。

## 验收标准

- 终端子树渲染异常时，聊天页仍在，用户能重试或关闭终端。
- 错误和组件堆栈记录到浏览器控制台，根边界仍可以处理终端之外的渲染异常。
