# Android 图片预览与前台恢复时的输入法焦点修复

## 目标

输入法已关闭时，关闭图片预览或从后台返回 App 后，输入法不应自行弹出。聊天草稿和光标内容应保留；用户再次点击输入框时仍可正常输入。

## 步骤

1. 给聊天根容器提供可接收焦点的位置，避免页面初次显示时输入框自动获得窗口焦点。
2. 打开图片和文件预览前，将聊天输入框焦点移到根容器；预览窗口初次显示时保持输入法关闭。
3. Activity 进入后台且输入法已关闭时转移聊天输入框焦点；输入法仍打开时保持当前编辑状态。
4. 更新 PATCH 测试版本、独立保存 APK，并安装到已连接设备；核对安装版本。

## 验收

- [x] 先打开再收起输入法，打开文件树中的 WebP 图片并关闭，系统报告输入法始终关闭；再次点聊天输入框可以打开。
- [x] 输入法关闭后切到桌面并返回 App，系统报告输入法仍关闭。
- [x] 焦点转移只请求根容器焦点，不重写聊天输入框文本或光标位置；流式消息渲染逻辑未调整。
- [x] 构建并安装 `0.22.0-dev.6`，Android `versionCode 200`。

分类：PATCH / 修正现有输入法和焦点行为，不增加新的任务能力。

实机：PJZ110。图片预览和桌面返回两条路径均在聊天输入框曾获得焦点、系统键盘随后收起的状态下检查；`dumpsys input_method` 返回 `mImeWindowVis=0`、`mInputShown=false`。消息正文中的图片弹窗使用相同的焦点转移和软键盘隐藏处理，尚未单独点按验收。
