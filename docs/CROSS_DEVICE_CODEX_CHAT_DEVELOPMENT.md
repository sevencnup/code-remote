# 跨设备 Codex 群聊开发文档

## 目标

让多台各自运行 Code Remote 与本机 Codex 的设备加入同一群聊。每台设备上的网页都能查看同一消息流；用户点名某台设备时，该设备自己的 Code Remote 后端把群聊上下文交给本机 Codex，并把回复同步回房间。

## 范围与决策

- 设备是平级成员。创建房间的设备只负责保存消息和转发事件，不充当其他设备的 Codex 主控。
- 每台设备保留自己的 Code Remote 后端、Codex App Server、工作区与权限设置。跨设备流量通过 Code Remote 的 LAN HTTP/WebSocket API 传输，不监听或解密 SSH 隧道。
- 房间创建者是消息协调节点。加入端主动通过 LAN 地址和一次性房间码加入，之后用每台 Code Remote 服务各自持有的节点令牌建立 WebSocket 长连接；断线后自动重连并从持久化消息序号续传。
- 设备码只用于一次性加入；已授权节点使用独立随机令牌。浏览器配对令牌不能用作设备节点凭证。
- 群聊消息在创建房间的设备以及加入设备各自的本机持久化存储中保存。原有 Codex thread 不会被改写；被点名设备会在本机 Codex 历史中创建一条专用 thread，群聊提示和回复按 Codex 原生行为保存在该 thread 中。
- 群聊首版支持文本消息。选择“所有设备”只在房间显示；选择某一台设备会显示为 `@设备名` 并触发该设备。
- 每台设备首次被点名时创建一条专用于该房间的本机 Codex thread，后续点名继续使用该 thread。每次调用都附上最近群聊消息作为明确标记的上下文，使该设备能看到其他成员此前说过的内容。现有普通 Codex thread 不被修改。
- 目标设备收到消息后由后端驱动本机 Codex App Server；回复增量合并为一条群消息并同步给所有节点。处理期间收到新的点名消息时，将其作为追加指示交给当前 turn；空闲时按顺序开始新的 turn。非目标设备只保存和显示消息，不会自行启动 Codex。
- 仅已加入房间的设备可以触发点名执行。消息中来自其他 AI 的内容作为待分析文本传给本机 Codex，不授予任何额外工具或权限。
- 服务端维护群聊自身的短期邀请状态、成员、消息和本机 thread 绑定；关闭 Code Remote 后仍可恢复房间，退出会撤销本机成员配置。
- 前端从侧栏打开独立的“设备群聊”面板；支持创建房间、查看加入地址与码、输入地址和码加入、查看成员/连接状态、选择接收设备、发送和监控流式回复。

## 实施步骤

1. 新增设备群聊管理模块与本机 SQLite 存储，覆盖房间/成员/邀请/消息、幂等事件写入、节点凭证校验及重连游标。
2. 在 FastAPI 生命周期启动/关闭节点管理器；增加受浏览器配对保护的本机群聊 API、仅接受一次性码的加入 API、节点令牌保护的消息 API，以及供加入节点连接的 WebSocket。
3. 创建方保存并广播消息；加入方主动连回创建方，接收快照和增量消息。服务重启或断线后按已确认序号续传；暂时无法发出的本机消息保留在待发送队列中，恢复后补传；重复事件不产生重复消息。
4. 目标节点为每个房间恢复或创建本机 Codex thread，把最近群聊上下文与新消息交给 App Server，采集 assistant 增量并同步。Codex 忙碌或本机不可用时，在群聊里显示可读错误，不静默丢消息。
5. 新增 TypeScript API 客户端和独立群聊面板，加入侧栏入口、连接状态、成员列表、消息流、@设备选择器和窄屏样式。
6. 更新 `package.json` 与 Android `versionName` 到 `0.68.0-dev.1`，在 `CHANGELOG.md` 只记录功能描述；不生成 APK，因此不变更 Android `versionCode`。
7. 执行前端生产构建与 `git diff --check`，不新增或运行自动化测试；检查差异后只暂存本任务文件并创建本地提交，不推送 GitHub。

## 验收标准

- Linux 与 Windows 两个 Code Remote 页面可通过创建方地址和一次性码加入同一房间，双方都能看到成员和相同消息流。
- 任一设备发给房间的文本会持久化并同步到其他在线设备；断线恢复后不会丢失或重复显示。
- 用户点名 Linux 或 Windows 时，消息只在目标设备的本机 Codex 执行，Codex 回复流式回到共享房间；未被点名的设备不会启动 Codex。
- 同一房间再次点名同一设备时，本机 Codex 继续使用该房间专属 thread，并在提示中收到近期的共享消息上下文。
- 关闭并重新启动服务后，房间、成员、消息及节点连接可恢复；邀请码过期或已使用后不能重复加入。
- 未配对浏览器不能调用本机群聊 API；没有有效节点令牌的远端不能读消息或发送消息。
- 常规单机 Codex 聊天、历史记录、工作目录和权限设置不受影响。
- `pnpm build` 成功，`git diff --check` 无输出。
