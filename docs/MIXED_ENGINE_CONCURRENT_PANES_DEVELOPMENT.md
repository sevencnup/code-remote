# Codex 与 Claude 混合引擎并发窗格开发文档

## 目标

允许同一工作区同时打开 Codex 与 Claude Code 会话，并通过现有并发打开操作添加其他引擎的会话。

## 范围

- 保留单一左侧聊天列表，混合显示 Codex 与 Claude Code 会话，并为两种会话明确显示引擎名称。
- 继续复用现有每窗格独立引擎、会话状态和并发打开行为。
- 右侧文件树和底部输入框继续跟随当前选中窗格；不为每种引擎重复加载左右侧栏。
- 本次属于 MINOR / 新增能力，版本更新为 `0.38.0-dev.1`；不生成安装包，Android `versionCode` 保持不变。

## 实施步骤

1. 移除左侧会话列表对当前选中引擎的过滤，保留搜索、置顶、选择、快捷键与并发打开行为。
2. 为 Codex 与 Claude Code 会话都显示清楚的引擎标签。
3. 更新 Web 与 Android `versionName`、`CHANGELOG.md` 和本开发记录。
4. 运行生产构建与差异检查；不运行测试、不推送远端、不生成 APK。

## 验收标准

- 左侧列表可同时浏览和搜索两种引擎的会话。
- 通过“并发打开”添加另一种引擎的会话后，两个窗格可同时运行不同引擎。
- 点击会话窗格时，右侧文件树和底部输入框跟随当前选中窗格。
- 生产构建与差异检查通过。

## 完成记录

- 左侧聊天列表改为混合显示 Codex 与 Claude Code 会话，并显示对应引擎标签；搜索、置顶、选择和“并发打开”操作沿用现有逻辑。
- 每个会话窗格继续独立切换并保存引擎；右侧文件树和底部输入框继续跟随当前选中窗格，无需重复加载侧栏。
- Web 与 Android `versionName` 更新为 `0.38.0-dev.1`；Android `versionCode` 保持 `279`，未生成 APK。
- `pnpm build` 与 `git diff --check` 通过；构建有大型 chunk 提示，未影响产物生成；未新增或运行测试。
