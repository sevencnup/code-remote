# AI 群聊成员设置

## 需求分类

新增功能 / MINOR。用户可以在群聊里分别调整 Codex 与 Claude 的模型、推理强度和权限，不必离开群聊切换到成员原对话。

## 方案

- 在现有群聊输入区增加一个可展开的成员设置面板，不创建新的聊天窗口或模态弹窗。
- 面板提供 Codex / Claude 两个切换项；每次显示所选成员自己的模型、推理强度和权限选项。
- Codex 模型与推理强度沿用已加载的模型列表及各模型支持的推理强度；Claude 使用现有 Claude 模型、推理强度和权限选项。
- 改动保存到各成员所关联聊天的独立偏好中，保持两种模式的设置与权限隔离；发送和互相接力均使用最新选择。
- 切换 Codex 模型时，如当前推理强度不受新模型支持，则回到该模型默认推理强度。

## 开发步骤

1. 扩展群聊面板属性，接收两种模式的选项列表、当前偏好及按关联聊天 ID 保存偏好的回调。
2. 在群聊现有输入区添加可折叠设置面板，并按所选成员呈现三个设置项。
3. 更新版本及变更记录至 `0.54.0-dev.1`。
4. 执行前端生产构建和差异检查，不新增或运行测试。
5. 仅将本次相关文件提交到本地 Git，不推送 GitHub。

## 验收标准

- 用户可在同一群聊输入区分别调整 Codex 与 Claude 的模型、推理强度和权限。
- 更改仅写入对应模式关联的聊天偏好，不串改另一模式。
- 并发发送及互相接力读取最新偏好，Claude 默认推理强度不会发送无效的 `default` 值。
- `pnpm build` 成功且 `git diff --check` 无输出。
