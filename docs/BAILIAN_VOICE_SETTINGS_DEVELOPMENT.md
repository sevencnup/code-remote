# 百炼语音输入项目内配置开发记录

## 目标

在网页版设置中配置阿里云百炼语音输入，不再要求用户手动编辑服务器环境文件或重启服务。

## 方案

1. 服务端将百炼设置保存到配对授权状态目录下的独立 JSON 文件，使用原子写入并限制文件权限；API Key 不写入日志，也不通过设置接口返回。
2. 增加受配对认证保护的读取、保存和重置接口。环境变量仍作为兼容性回退；项目内保存的设置优先，并在新语音连接建立时立即生效。
3. 在现有网页版“设置”中加入百炼配置卡片，可填写 API Key、Workspace ID、地域和模型；已保存 Key 留空时保持不变，并支持恢复环境变量配置。
4. 为配置存储、环境变量回退、脱敏接口和设置表单增加测试/验证。
5. 按新增功能递增开发版版本并记录更新描述；只提交本次功能相关文件，保留工作区里已有的其他修改。

## 验收

- 设置接口在没有有效配对令牌时不可访问。
- API Key 不出现在读取接口响应中；设置文件权限尽量限制为仅服务用户可读写。
- 保存配置后新建语音连接立即读取新配置，无需重启。
- 清除项目内配置后回退到环境变量；没有可用凭证时，语音功能给出设置引导。
- 运行百炼单元测试、前端构建和相关前端测试。
