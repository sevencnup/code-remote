# Android 侧栏时间分组与批量操作

## 需求

侧栏按最后聊天时间显示“今天、最近 7 天、15 天内、30 天内、更早”；置顶聊天单独展示。增加选择模式，支持批量置顶与批量删除。排队消息三枚图标改为明显更圆润的造型。

## 步骤

1. 检查聊天列表更新时间字段与现有置顶、删除 API。
2. 加入分组和选择模式，批量操作只作用于已勾选且属于当前连接、当前模式的聊天。
3. 替换排队图标资源，合并本轮即时发送和行距调整，递增版本。
4. 构建独立 APK、安装核对，本地提交。

## 分类

新增功能：时间分组与批量置顶、删除扩展了侧栏能力。与本轮修复一起发布为 `0.26.0-dev.1`。

## 后续修正

排队消息第二个操作是“立即发送”，图标须显示圆润的发送箭头，不使用勾选符号。复核时间分组、批量操作和即时消息占位在切换模式、连接后的状态隔离。本次修正版本为 `0.26.1-dev.1`。
