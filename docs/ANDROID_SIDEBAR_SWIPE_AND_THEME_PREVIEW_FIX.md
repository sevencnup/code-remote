# Android 侧栏手势与主题透明度预览修复

## 目标

让聊天页左右半区的侧栏手势稳定命中，并让自定义主题透明度拖动时只更新背景图层，不重建聊天页面。

## 根因与方案

- 手势起点检查把所有可点击、可长按视图都当成手势保护区。聊天正文大量使用可选择文本，因此多数起点会直接关闭侧栏手势识别。让明确需要保留触摸序列的输入框、滑杆和横向滚动区继续优先处理；聊天正文和普通按钮允许明显的水平移动触发侧栏。长按开始选择文本后仍保留原触摸序列。
- 自定义主题透明度只在拖动结束时保存，但随后调用整页 `rerenderAppKeepSettings()`，重建聊天视图并再次渲染全部消息。改为拖动中实时预览根背景颜色和背景图透明度，结束时只保存偏好，不重建聊天页。

## 分类与版本

本次属于修复 / 体验优化（PATCH）：恢复已有左右侧栏手势的稳定性，并消除主题预览对聊天内容的整页刷新，不改变用户可完成的任务。目标版本为 `0.21.6-dev.3`，Android `versionCode` 为 `176`。

## 实施步骤

1. 调整根视图触摸分类，让聊天正文和一般点击项可参与水平侧滑；保护输入框、SeekBar、横向滚动区域和长按后的文本选择。
2. 为背景透明度增加临时预览值，拖动时只更新根背景、顶栏底色及背景图片 alpha。
3. 松开滑杆时保存透明度，不调用整页渲染；保留已打开的设置页、聊天滚动位置和消息视图。
4. 更新版本记录，构建 Android Debug APK，安装到连接设备，检查差异并创建本地 Git 提交；不推送 GitHub。

## 验收标准

- 左半屏向右滑可稳定打开对话侧栏，右半屏向左滑可稳定打开文件树；竖向聊天滚动、输入框、滑杆、横向附件条和长按选字仍可用。
- 自定义主题透明度拖动过程中背景连续变化；聊天消息不被重新创建、不闪烁，松手后设置保留。
- Android Debug APK 构建成功，安装版本和 `versionCode` 正确。
