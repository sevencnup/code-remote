# Android 文件活动归入操作记录

## 目标与分类

修复 / PATCH：文件更改操作已经存在，但原生界面在“操作记录”外重复生成默认展开的文件列表。目标内部版本 `0.28.1-dev.10`，Android `versionCode 244`。

## 实施步骤

1. 检查独立操作消息和助手回复时间线中的文件更改渲染路径。
2. 移除操作记录外的独立文件列表，统一在“操作记录”展开内容中展示对应文件；默认随操作记录折叠。
3. 保留文件点击预览和轮次结束后的文件更改汇总卡片，避免丢失现有能力。
4. 更新版本记录，构建独立 APK，安装到已连接手机并核对版本，完成本地提交。

## 验收

- “操作记录”收起时不出现单独的“文件已更改”列表。
- 展开操作记录可看到对应文件和增删统计，点击文件仍可预览。
- 轮次结束后的文件汇总卡片仍可审核、插入对话和展开。
- 安装版本为 `0.28.1-dev.10` / `versionCode 244`。

## 实施结果

- 删除了操作记录外默认展开的文件列表；独立操作和助手回复时间线均在“操作记录”展开内容里显示文件明细。
- 文件行仍可点击预览，轮次结束后的审核汇总卡片继续保留。
- APK 构建并安装成功，手机报告 `versionCode 244`、`versionName 0.28.1-dev.10`。
