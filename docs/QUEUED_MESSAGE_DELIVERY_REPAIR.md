# 排队消息重复发送修复

## 问题

服务端已接收排队消息、甚至已开始回复时，网页可能仍把同一消息显示为待发送；随后旧回复完成，又会自动发送一次。快速连续提交也可能把同一份输入重复加入队列。

## 开发步骤

1. 给输入框发送流程加同步防重，避免 React 状态更新前的第二次提交。
2. 排队发送以服务端带请求编号的送达回执作为确认，及时移除对应队列项；保存排队项的发送尝试时间和历史锚点，供页面恢复时核对。
3. 读取真实对话历史时，对已经尝试发送的排队项按内容、附件和消息顺序核对；修复同一次快速提交留下的旧重复项。无法确认送达的项目暂停自动重发。
4. 并发窗口按对话分别保存队列，并同步同一页面中各窗口的队列状态，避免旧快照重新带回已发送项目。
5. 补充发送与恢复的回归测试，执行前端构建、相关测试和差异检查。
6. 写入版本更新描述并提交到本地 Git。
