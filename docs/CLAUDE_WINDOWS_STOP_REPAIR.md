# Windows Claude Code 停止卡住修复

## 问题与分类

修复 / PATCH。网页发出停止请求后可能长期显示“正在停止”，已有的停止能力未按预期完成。

## 实施步骤

1. 检查网页停止请求与后端 Claude CLI 的进程结束流程。
2. 在 Windows 上结束当前 Claude CLI 的进程树，避免子进程持有输出管道。
3. 给进程结束和流读取加入有界等待，确保停止请求能完成并发送轮次完成事件。
4. 加入针对停止挂起的回归检查，运行相关检查与构建。
5. 更新版本记录，仅提交本地 Git。

## 验证结果

- 14 项 Claude 流式与停止检查通过。
- 覆盖 CLI 输出管道不关闭时的停止完成事件，以及 Windows 只结束指定 Claude 进程树的命令参数。
- 差异格式检查通过。
