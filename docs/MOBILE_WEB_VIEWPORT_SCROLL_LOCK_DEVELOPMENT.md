# 移动网页版外层页面滚动锁定

## 现象与根因

- 移动浏览器中拖动内容时，整个页面仍有上下或左右移动/回弹的感觉。
- `body` 和应用外壳已有溢出限制，但 `html` 与 `#root` 未锁定溢出行为，滚动链可能传递到视口外层。

## 实施步骤

1. 锁定 `html`、`body`、`#root` 的外层溢出和过度滚动。
2. 在主应用外壳阻止滚动链回弹，同时保留聊天消息、侧栏和文件内容等内部滚动区域。
3. 按 PATCH 更新版本及变更记录。
4. 执行 `pnpm build` 和 `git diff --check`，不运行测试；提交本次相关文件，不推送 GitHub。

## 验收标准

- 移动网页根页面不会随手势发生整页滚动或边界回弹。
- 聊天消息、对话侧栏、文件树及代码内容仍可在各自区域内滚动。

## 验证结果

- `pnpm build` 通过；Vite 有既存的大 chunk 提示。
- `git diff --check` 通过。
- 未运行测试；未部署或重启服务，未推送 GitHub。
