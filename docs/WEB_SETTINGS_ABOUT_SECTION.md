# 网页设置页关于模块

## 目标

在网页设置页底部增加可展开的“关于”模块，交互和内容布局参考 Android 端：默认收起，点击标题后居中显示项目说明、Logo、项目名称、简介及 GitHub 项目地址。

本次属于新增功能（MINOR）：网页端此前无法从设置页查看项目介绍和源码入口。目标版本为 `0.90.0-dev.1`。

## 实施步骤

1. 在设置页底部增加可访问的折叠式“关于”模块。
2. 复用当前项目 Logo，加入项目名称、网页端简介和可点击的 GitHub 地址。
3. 为桌面端、移动端和现有主题补齐布局与颜色样式。
4. 更新版本和版本记录，构建网页并检查差异后提交本地仓库。

## 验收标准

- 设置页底部显示“关于”，默认收起且可以点击展开、再次收起。
- 展开内容整体居中，Logo、名称、简介和 GitHub 地址在手机与电脑宽度下均可正常显示。
- GitHub 地址在新标签页打开，键盘操作和焦点样式可用。
- 各主题下文字清晰，网页构建通过。
