# Android 输入框单操作按钮与图标调整

## 需求

输入框右侧合并发送、暂停和继续操作，编辑排队消息时显示确认。排队消息的编辑、立即发送、删除图标改为统一的现代简约线条风格。

## 行为

- 编辑排队消息：确认修改。
- 输入框有内容或附件：发送消息，保留回复期间排队发送能力。
- 输入框为空且正在回复：暂停回复。
- 输入框为空且已暂停：继续回复。
- 其它情况：发送消息。

## 步骤

1. 检查当前两个按钮和按钮状态更新路径。
2. 合并单按钮、补齐草稿变化时的状态刷新，并替换图标资源。
3. 递增版本，构建独立 APK、安装核对并本地提交。

## 分类

体验优化；同一组已有能力改为单按钮，目标版本 `0.25.3-dev.1`。
