# Android 原生界面统一、历史缓存与消息信息开发记录

## 需求范围

1. 左右抽屉共用同一套面板、遮罩、宽度、手势和动画组件。
2. 最近编辑文件展开后可查看并上下滚动全部文件，不再只显示前几项。
3. 输入法打开时，模型、思考等级和权限菜单保持贴近对应按钮，且不关闭输入法。
4. 聊天历史优先显示本地缓存，后台再增量同步；加载过程不得阻塞已缓存内容。
5. 用户和助手消息显示发送时间。
6. 终端覆盖聊天内容区域，但保留底部聊天输入框可见，顶部区域尽量充分利用。
7. 排队消息显示该条消息选择的模型和思考等级。
8. 顶部导航背景延伸至系统状态栏下方，并移除顶部和底部边线。

## 修改分类与版本

- 分类：新增功能 / MINOR，同时包含修复与体验优化。
- 理由：消息时间与排队消息参数属于此前不可见的新信息，已有缓存、弹层、抽屉和布局问题按修复处理；合并发布时按最高影响分类。
- 目标版本：`0.20.0-dev.1`。
- Android `versionCode`：`168`。

## 实施步骤

1. 抽取原生左右抽屉共用的边缘面板结构与动画参数，并让手势控制走同一套状态更新逻辑。
2. 将最近编辑文件列表放入有最大高度的内部滚动区域，保留折叠状态并渲染全部条目。
3. 用 Activity 内的锚定弹层替换输入区选择对话框，根据输入法后的可见区域放置菜单并保持输入焦点。
4. 审核磁盘缓存读取、选择聊天和网络同步顺序，改为缓存先显示、网络后台刷新；缓存不可用时才显示整页加载状态。
5. 从消息项或所属轮次中解析时间，使用低干扰样式显示在用户和助手消息旁。
6. 将终端限制在顶部导航与聊天输入区之间，适配输入法和窗口尺寸变化。
7. 在排队消息行中显示模型和思考等级，并兼容 Codex 与 Claude Code 字段。
8. 调整系统栏与顶部导航的 inset 处理，使导航背景覆盖状态栏区域且没有上下边线。
9. 完成静态检查、针对测试、Android 构建与真机逐项复验，保留新 APK 并只提交本地 Git。
