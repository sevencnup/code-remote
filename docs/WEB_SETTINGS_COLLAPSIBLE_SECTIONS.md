# 网页设置模块折叠功能

## 需求

网页设置页中的各个模块支持独立展开和收起，减少长页面滚动距离，并保留模块中的输入内容和组件状态。

## 交互规则

1. 使用原生 `details` 和 `summary` 提供键盘与无障碍交互。
2. 主题模块默认展开，其他模块默认收起。
3. 标题右侧显示展开箭头，展开时旋转。
4. 收起模块时隐藏标题下方的分隔线。
5. 模块内容始终保持挂载，折叠不会清空表单内容。
6. 聊天快捷键模块收起时退出快捷键录制状态，避免隐藏区域继续接收按键。
7. 每个模块的展开状态保存在当前浏览器中，关闭设置页或刷新页面后仍保持上一次状态；首次进入时主题展开，其他模块收起。

## 实施步骤

1. 将设置卡片标题样式整理为可复用的折叠标题样式。
2. 改造 MCP 自动批准、CPA Manager Server 接入、主题、显示、聊天切换快捷键、系统通知和关于模块。
3. 调整聊天快捷键操作按钮的位置，避免在 `summary` 内嵌套可点击按钮。
4. 为每个模块分配稳定标识，并在浏览器本地存储中保存展开状态。
5. 更新项目版本与版本记录。
6. 执行生产构建检查并提交到本地仓库。
