# Android 聊天排版与输入框视觉对齐

## 目标

让 Android 原生客户端的聊天正文更接近网页版的宽松行距，并让输入框在 AI 回复时呈现与网页版一致的柔和呼吸光，同时用半透明渐变、高光和圆角描边还原网页版液态玻璃质感。保持现有聊天交互、输入焦点、键盘行为和主题切换不变。

## 实施步骤

1. 对照 `src/styles.css` 的聊天行高、网页输入框玻璃层和运行时呼吸动画。
2. 调整 Android 用户消息、助手 Markdown 消息和操作时间线正文的行距，使阅读密度接近网页。
3. 将 Android 输入框背景改为按主题适配的半透明渐变玻璃层，增加轻微高光和描边；回复运行期间增加低对比度、缓慢往复的呼吸光。
4. 确认动画只在回复期间运行，主题变化和输入框交互正常，并构建独立版本 APK。
5. 检查改动和构建结果后本地提交；不推送 GitHub。

## 验收

- 长段落和多段 Markdown 正文不再显得拥挤，用户与助手正文均保持可读。
- 深色、浅色、暖色和自定义主题的输入框都能分辨出玻璃层次，文字和按钮对比度可读。
- AI 回复期间输入框有柔和呼吸光；回复结束后动画停止。
- Android Debug APK 可成功构建，且版本号、`versionCode` 和产物路径不覆盖既有安装包。
