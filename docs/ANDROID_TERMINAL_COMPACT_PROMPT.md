# Android 终端精简提示符

## 问题与分类

手机终端恢复 tmux 会话时，旧的模式切换提示、前一次 shell 提示符和当前完整路径提示符同时出现在屏幕顶部。当前 Bash 提示符 `root@主机:完整路径#` 在约 29 列的手机终端里自动折成两行，浪费键盘打开后的可见高度。

本次是修复 / PATCH：改善已有终端的移动端布局与操作便利性，终端执行能力不变。目标包 `0.62.0-dev.11`，Android `versionCode 335`。

## 步骤

1. Android 终端连接时声明需要精简提示符；网页终端不发送此标记。
2. 服务端仅在该 tmux 会话尚未处理过、只有一个客户端、当前前台程序是空闲 Bash 且没有处于 tmux 模式时，将本会话的 Bash 提示符改成 `当前目录名#` 或 `当前目录名$`，并清掉可见旧文字。保留 tmux 会话，不修改全局 `.bashrc`。
3. 正在运行其他程序或有多个客户端时保留现有终端内容，不向程序发送命令。
4. 更新版本记录，构建独立 APK 并安装。检查首次打开后只显示简短提示符，键盘弹出后仍可见，终端输入正常。
5. 仅提交本次源码与文档到本地 Git。服务端重启安排在本轮回复之后，避免中断承载本对话的 Codex Remote 服务。

## 验收

- 手机打开空闲终端后，不再显示之前的切换提示和重复提示符；当前提示符占一行。
- 正在运行的终端程序及同时打开的其他客户端不被清屏或注入 shell 命令。
- 键盘开合不再让提示符消失；此前隐藏的 tmux 底部状态行继续隐藏。

## 检查记录

- 独立 tmux 会话实测：首次打开和重连现有会话后，仅显示 `codex-remote#` 一行；网页默认连接不触发精简；前台运行 `sleep` 时跳过提示符修改。
- `assembleDebug` 成功；独立 APK 已安装到 `10.126.126.2:5555`，设备显示 `versionCode 335`、`versionName 0.62.0-dev.11`。
