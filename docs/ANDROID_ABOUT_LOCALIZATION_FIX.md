# Android 关于模块语言切换修复

## 问题与目标

Android 设置页的“关于”模块只有“检查更新”等已有词条会随界面语言切换；标题、项目介绍和 GitHub 入口缺少英文映射，导致英文界面同时显示中英文。模块顶部的“项目介绍、源代码与更新。”也形成了多余的说明行。

目标是让“关于”模块所有界面文案统一跟随中文、英文设置，并删除顶部说明行。

## 分类与版本

- 分类：修复 / PATCH。修正现有设置模块的语言切换与排版，不改变用户可完成的任务。
- 目标版本：`0.90.1-dev.1`，Android `versionCode 380`。
- 这是小幅界面修复，不单独增加 `CHANGELOG.md` 条目。

## 实施步骤

1. 让设置分组支持省略说明文案，并在“关于”模块移除顶部说明行。
2. 为“关于”、项目介绍、GitHub 入口和无障碍说明补齐英文映射。
3. 构建独立 Android APK，覆盖安装后保留现有设置和配对数据。
4. 只提交本次 Android 源码与开发文档，不混入工作区中同时存在的网页修改。

## 验收标准

- 中文界面显示完整中文“关于”内容。
- 英文界面的标题、项目介绍、GitHub 入口和更新检查均显示英文。
- Logo 上方不再显示“项目介绍、源代码与更新。”。
- 新 APK 不覆盖历史产物。

## 完成记录

- “关于”标题、项目介绍、GitHub 入口、折叠状态和无障碍说明已补齐英文映射。
- 设置分组支持不显示说明行，“关于”模块已删除顶部“项目介绍、源代码与更新。”。
- Android 构建成功，产物为 `artifacts/code-remote-android-0.90.1-dev.1-debug.apk`。
- 新版本已覆盖安装到手机，设备报告 `versionCode 380`；历史 APK 未覆盖。
