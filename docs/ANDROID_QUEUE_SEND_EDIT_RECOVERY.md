# Android 排队发送与编辑恢复

## 目标

- 排队消息处于遗留编辑占用时，用户可以明确取回编辑或解除占用并发送。
- 立即发送未执行时显示原因，不再静默无反应。
- 正在回复的聊天在服务重连后仍能确认当前轮次；自动队列继续等待并在可发送时推进。
- 队列刷新不移除正在按下的操作按钮。
- 编辑占用有续约和超时恢复，APP 或网页意外退出后不会永久挡住自动发送。

## 步骤

1. 检查 Android 队列操作与服务端队列状态，确认占用和轮次判断的断点。
2. 补齐队列项状态提示、恢复编辑与立即发送反馈，并保护按钮按下期间的视图。
3. 服务端从实时会话恢复正在运行的轮次编号，保证手动发送能正确判断是否可插入当前回复。
4. 构建新版本、在手机上核对排队操作与反馈，提交本地仓库。
