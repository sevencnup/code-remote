# Android 排队消息使用主输入框编辑

## 目标

点击排队消息的编辑按钮后，在主输入框中修改文字、图片和文件；保存更新原排队项，取消恢复原草稿。编辑期间不能误发送为新消息或切换到其它对话。

## 步骤

1. 进入编辑前向服务端申请编辑锁，保存当前输入框草稿及附件，把排队消息的文字和附件装入主输入框。
2. 在输入框显示编辑状态与保存、取消入口；发送按钮在编辑期间改为保存，允许仅附件消息。
3. 保存时更新原排队项的文字、图片、文档及模型设置，再结束编辑锁；失败时保留编辑内容供重试。
4. 取消时结束编辑锁并恢复原草稿；阻止编辑期间切换聊天、模式或重复编辑。
5. 更新 PATCH 测试版本，生成独立 APK，安装到已连接设备。

## 验收要点

- 编辑排队消息可添加、移除图片和文件，保存后附件仍属于原队列项。
- 取消后原草稿和附件不丢；失败时编辑内容不丢。
- 编辑期间不会把这条消息作为新消息发送。

分类：PATCH / 修复现有排队消息编辑不支持附件的问题。
