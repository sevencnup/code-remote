# 当前模式新建对话与品牌图标

## 需求判断

侧边栏的新建对话只创建当前窗口所属模式的聊天。跨模式操作继续由聊天顶部的模式切换按钮负责。Codex 和 Claude Code 的模式标识使用各自品牌图形，不再使用通用聊天或终端图标。本次是现有入口的操作与视觉修正，属于体验优化（PATCH）。

## 实施步骤

1. 让侧边栏“新建对话”直接创建当前窗口模式的聊天，移除模式选择菜单及关联状态；没有活动聊天时默认 Codex。
2. 让窗口内的“新建远程对话”入口也继承所在窗口模式，避免 Claude 窗口意外新建 Codex 聊天。
3. 使用 Codex 和 Claude 品牌图形替换顶部模式切换按钮与对话列表中的通用图标。图形本地保存，避免网页运行时请求外部图标服务；保留无障碍标签与主题对比度。
4. 清理失效的菜单样式，记录版本描述，检查改动并只提交本地仓库。保留用户现有 Android 开发文档修改，不主动重启后端。

## 图标来源

Codex 和 Claude 的矢量图形来自 Lobe Icons 对相应产品品牌标识的整理：`packages/static-svg/icons/codex.svg` 和 `packages/static-svg/icons/claude.svg`。仅使用图形轮廓，颜色由本项目主题样式控制。
