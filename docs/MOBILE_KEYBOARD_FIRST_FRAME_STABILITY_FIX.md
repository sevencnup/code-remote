# 移动端输入法首帧跳动修复

## 目标与分类

修复 Android APP 点击聊天输入框后，输入框先瞬间跳到页面顶部附近、再回落并等待输入法追上的三段式闪动。本次属于 PATCH：校正已有键盘视口布局的首帧计算，不改变输入、发送或键盘操作方式。目标版本为 `0.16.0-dev.8`。

## 现场判断

- Android 11 及以上由原生桥接提供输入法高度，网页按“页面布局高度减去输入法高度”设置聊天区域高度。
- 输入法启动初期，WebView 的 `window.innerHeight` 会短暂变成已经扣除输入法后的高度；原生桥接又会同时返回完整输入法高度。
- 现有代码直接使用这一帧的 `innerHeight` 再减一次输入法高度，造成重复扣减，聊天区域瞬间过矮，输入框因此跳到顶部附近。
- 后续 WebView 恢复完整布局高度后，输入框才回到正确位置；此时输入法仍在执行系统动画，于是形成用户截图中的三段移动。

## 实施步骤

1. Android 原生键盘高度可用时，缓存键盘打开前的完整布局高度；键盘开合期间只允许该基准高度增大，不接受 WebView 的瞬时缩小值。
2. 始终用稳定基准高度减去原生输入法高度，避免同一高度被扣除两次。
3. 屏幕方向变化、页面重新显示或 APP 恢复时重置基准，避免沿用旧方向的尺寸。
4. 保留普通手机浏览器现有的 `visualViewport` 计算，不影响 Chrome 等非 APP 场景。
5. 更新版本记录并构建网页资源；不新增或运行测试，不重启承载对话的服务，不覆盖历史 APK。
6. 检查差异并创建本地 Git 提交，不推送 GitHub，保留用户已有的 Android 开发文档修改。

## 验收标准

- 点击输入框后，输入框从原位置平滑跟随输入法上移，不先跳到顶部附近再回落。
- 输入法完全打开后，输入框贴在输入法上方，底部不出现额外大块留白。
- 收起输入法后聊天区域恢复完整高度。
- 横竖屏切换及 APP 恢复后不复用旧尺寸。
- 普通手机浏览器的键盘布局行为保持原样。

## 完成记录

- Android 原生键盘高度路径已保存键盘打开前的布局高度；输入框聚焦或键盘显示期间只接受更大的布局高度，过滤 WebView 动画中的瞬时缩小值。
- 页面重新显示、APP 恢复和屏幕方向变化会重建高度基准；普通浏览器仍沿用原有 `visualViewport` 分支。
- Web、服务端及 Android `versionName` 已同步为 `0.16.0-dev.8`；本次没有 Android 原生改动，不生成 APK，`versionCode` 保持 `128`。
- TypeScript 与 Vite 生产构建通过；未新增或运行测试，最终动画效果仍需在用户当前手机与输入法组合上观察。

## Android APP 输入框白闪回归修复

### 目标与分类

继续修复 Android APP 首次点击聊天输入框时整页重排和闪动的问题，并生成包含原生键盘桥接的新安装包。本次属于 PATCH / 修复：输入和键盘能力不变，目标版本为 `0.17.0-dev.2`，Android `versionCode` 为 `129`。

### 现场判断

- 当前 Android 11 以上虽然使用 `adjustNothing` 保持 WebView 表面尺寸，但网页仍通过缩短整个 `.remote-shell` 高度避开键盘；每个键盘高度事件都会让顶部栏、消息区、输入框和浮层一起重新布局。
- 输入框聚焦早于原生 IME 高度事件。首帧仍按全高布局，WebView 会先尝试把焦点控件滚入可视区；随后整页高度才缩短，形成一次明显跳动。
- 仓库中最后生成的 APK 是 `0.16.0-dev.4`。旧 APK 没有稳定的原生键盘高度桥接，只更新网页无法完整应用这条修复路径。

### 实施步骤

1. Android 原生路径保持应用根页面为完整稳定高度，只在移动聊天工作区底部加入 IME 占位，让消息区和输入框上移，避免整页及侧栏重新排版。
2. 记录最近一次真实键盘高度；输入框按下但 IME 高度尚未送达时先使用预测高度，实际 Insets 到达后平滑校正，键盘关闭时立即清除占位。
3. Android 桥接提供预测键盘高度并按横竖屏分别记忆；尚无历史值时使用受限的屏幕比例估值，避免首次安装后的第一次输入仍跳顶。
4. 更新网页、服务端和 Android 版本；递增 `versionCode`，生成不覆盖旧文件名的新 debug APK。
5. 执行网页生产构建、Android debug 构建和差异检查，不新增或运行测试，不重启承载聊天的服务。
6. 只提交本次文件，不纳入用户已有的 `docs/ANDROID_APK_DEVELOPMENT.md` 修改，不推送 GitHub。

### 验收标准

- 点击聊天输入框时，顶部栏和整页外壳保持原位，只有聊天工作区随键盘平滑收紧。
- 输入框不会先跳到顶部再回落，键盘完全打开后紧贴其上沿。
- 收起键盘后工作区恢复，侧栏、文件树和页面背景不出现白色空帧。
- 新 APK 包含 `adjustNothing`、实时 IME 高度和预测高度桥接，文件名与历史安装包不同。
- 普通手机浏览器继续使用原有 `visualViewport` 路径。

### 完成记录

- Android 原生路径不再缩短整个应用外壳；键盘高度只转为聊天工作区底部占位，顶部栏、侧栏和页面背景保持稳定。
- 输入框按下时会先使用预测 IME 高度；原生桥按横竖屏记住真实高度，首次没有记录时使用受限估值，真实 Insets 到达后平滑校正。
- Web、服务端和 Android 版本已更新为 `0.17.0-dev.2`，Android `versionCode` 已更新为 `129`。
- 网页生产构建和 Android debug 构建通过；新安装包为 `artifacts/codex-remote-android-0.17.0-dev.2-debug.apk`，旧安装包未覆盖。
