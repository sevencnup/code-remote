# Windows 后台驻留与自启动

## 目标

Codex Remote 不再依赖启动它的 Codex 聊天、终端窗口或桌面应用存活。用户登录 Windows 后服务自动启动，异常退出后由任务计划程序重新拉起。

## 实现

1. 使用当前 Windows 用户创建登录触发的计划任务。
2. 计划任务以普通用户的交互式令牌运行，保持对用户 `.codex` 的正常访问，不使用 Codex 沙盒令牌。
3. 后台运行器调用项目统一的 `pnpm start`，将输出写入 `.codex-remote/logs/windows-service.log`。
4. 任务失败后每分钟重试，且不设置最长运行时间。
5. 提供根目录安装入口，允许重新注册或修复计划任务。

## 验收

- 关闭启动终端或 Codex 桌面后，4173 和 18766 仍由计划任务管理。
- 用户下次登录后服务自动启动。
- 服务异常退出后计划任务自动重启。
- 网页可恢复连接，且 app-server 继续使用用户原有 `.codex`。
