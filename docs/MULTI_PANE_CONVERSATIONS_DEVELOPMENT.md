# PC 端并发对话分栏开发文档

## 目标

在 PC 端允许从侧边栏把多个 Codex 对话并排打开。每个窗口独立显示自己的历史、流式回复、运行状态和停止操作；底部保留一个输入框，并将发送目标绑定到当前选中的窗口。

## 实施步骤

1. 增加分栏窗口状态，保存打开的 thread ID、当前选中窗口和窗口顺序，避免同一对话重复打开。
2. 将 Codex 事件和消息状态按 thread ID 路由，保证多个窗口的回复、计时、文件改动和审批不会串到一起。
3. 在侧边栏对话记录增加并发打开入口，在每个分栏窗口右上角增加关闭按钮；关闭后选择最近窗口并让剩余窗口自动补位。
4. PC 端支持最多五个并发窗口，使用动态 Grid 分栏和 FLIP 位移动画；移动端保持原有单窗口布局和并发上限，避免窄屏分栏不可用。
5. 将共用输入框、模型、思考强度、授权模式、队列和停止操作绑定到当前选中的窗口；关闭窗口只关闭视图，不终止对应 Codex 任务。
6. 更新版本记录，执行生产构建和差异检查，并提交本地 Git 仓库。

## 验收标准

- PC 端最多同时打开五个对话窗口，窗口宽度平均分配；移动端保持原有行为。
- 关闭中间、左侧或右侧窗口后，剩余窗口平滑补位并铺满可用空间。
- 当前窗口有彩色内边框，输入框发送到当前窗口对应的 thread。
- 不同窗口的流式回复、停止、计时、队列和文件改动互不串线。
- 同一 thread 不会重复打开；移动端仍使用单窗口布局。
- 生产构建成功，`git diff --check` 无输出。
