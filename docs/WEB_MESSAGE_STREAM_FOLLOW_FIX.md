# 网页回复自动跟随修复

## 用户可见变化与版本

- 分类：修复 / PATCH。已有聊天回复本应在用户停留底部时自动跟随；修复新增内容造成的误判，保留主动上滑查看历史时的位置。
- 目标版本：`0.86.3-dev.1`。

## 原因

聊天区的滚动事件只按当前底部距离判断是否继续跟随。流式回复增加内容时，浏览器可能先发出滚动事件，此时自动定位底部的动画帧尚未运行；新增内容产生的距离会被误认成用户上滑。

## 实施步骤

1. [x] 记录聊天区上次滚动位置，仅在确实向上滚动并离开底部时暂停自动跟随。
2. [x] 保持切换对话、新发消息和“回到底部”后的跟随；用户主动上滑后继续保留当前位置。
3. [x] 更新版本和版本记录，构建网页、检查差异；不新增或运行测试。
4. [x] 仅提交本次修改到本地仓库，不推送 GitHub。

## 验收范围

- 底部收到新回复时自动跟随，暂时新增的内容高度不使“回到底部”按钮误出现。
- 用户主动上滑后不被后续回复拉回底部；滚回底部或点击按钮后重新跟随。
