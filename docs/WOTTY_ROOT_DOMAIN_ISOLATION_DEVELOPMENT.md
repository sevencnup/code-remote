# YHK 全局域名隔离开发文档

## 目标

修复 YHK 上 Nginx 未匹配域名时错误落入某个业务虚拟主机的问题，确保每个已配置域名独立响应，未配置的主域名和子域名统一隔离。

## 开发步骤

1. 记录 YHK 当前 Nginx 配置、监听状态、容器状态和 note 站点响应。
2. 在 YHK 保留原配置备份，将默认虚拟主机改为全局隔离规则；不修改已配置子域名、note 容器和 note 的代理目标。
3. 执行 `nginx -t`，通过后热加载 Nginx。
4. 分别使用 `wotty.app` 与 `note.sevencn.com` 的 Host/SNI 验证响应，确认主域名不再返回 note 页面，note 域名仍正常。

## 验证标准

- Nginx 配置测试通过并保持运行。
- 未配置的主域名和子域名不再命中任何业务代理。
- 已配置的子域名仍按精确 `server_name` 命中各自服务。
- `note.sevencn.com` 仍返回 note 项目页面。
- note 容器保持原运行状态。

## 回滚

恢复默认虚拟主机的原配置，执行 `nginx -t` 并热加载 Nginx；原 note 配置和备份文件保留。
