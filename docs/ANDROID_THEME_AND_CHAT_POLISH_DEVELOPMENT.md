# Android 聊天与主题设置修整

## 目标

修整 Android 原生聊天和主题设置：用户消息时间只在气泡外显示一次；用户消息在各主题下沿用黑色主题的颜色；暖色和自定义主题下的 Codex、Claude 助手名称继续显示品牌色；加强设置项选中态；让自定义颜色更容易选择；并把自定义背景图片限制在聊天区域，避免设置页透明时透出动态聊天内容。

## 实施步骤

1. 调整原生消息布局，把用户消息时间放在气泡外并移除气泡内的时间；固定 Codex 与 Claude 用户消息的黑色主题填充色，并保证前景文字有足够对比度。
2. 为暖色和自定义主题提供与黑色主题一致的 Codex 蓝、Claude 橙助手名称颜色。
3. 加强设置页面主题选项的选中填充、描边和勾选颜色，并给设置模块增加轻微品牌色层次。
4. 在背景色、字体色对话框中增加可点击的色阶色卡，同时保留十六进制输入。
5. 将自定义背景图片移到聊天区域；让主题底色保持不透明，透明度只控制聊天背景图片，并避免拖动时反复重绘整个根页面和顶部栏。
6. 更新版本与变更记录，构建独立 APK 并安装到已连接设备。

## 验收标准

- 用户消息时间只显示在气泡外；气泡内无时间。
- Codex、Claude 用户消息填充色在黑色、白色、暖色、自定义主题下保持黑色主题的视觉颜色，文字清晰可读。
- 暖色、自定义主题中的助手名称分别显示黑色主题下的 Codex 蓝和 Claude 橙。
- 当前主题选项有清楚的品牌色高亮，设置模块本身有轻微强调层次。
- 背景色和字体色均可点选色卡，也可直接输入 `#RRGGBB`。
- 自定义背景图片只出现在聊天区域；设置页和侧栏不透出聊天内容。拖动透明度只更新聊天背景图，不重建或改色整个页面。
- Debug APK 编译成功，已连接 Android 设备安装目标版本。
