# 网页聊天图片预览开发

## 目标

网页中已发送消息、输入框草稿和排队消息的图片都可以点开查看大图；排队消息要先显示可辨认的缩略图。

## 步骤

1. 核对三处图片的数据结构和当前渲染行为，确认预览不改变附件或队列状态。
2. 实现共用的图片预览按钮与可关闭的大图弹窗，支持键盘 Esc、点击遮罩关闭，并保持图片原始比例。
3. 将预览入口用于已发送消息、输入框草稿和排队消息；补齐移动端尺寸及深浅主题可读性。
4. 增加针对三处入口和弹窗行为的验证，执行构建与相关测试。
5. 记录版本和分类，仅本地提交本次改动。

## 验收

- [x] 三处均接入相同的大图弹窗；查看按钮与发送、移除操作分离。
- [x] 排队消息显示缩略图，纯图片排队消息同样有查看入口。
- [x] 弹窗按视口限制尺寸，提供关闭按钮、遮罩关闭及原生 Esc 退出。
- [x] `pnpm build` 和新增回归测试通过。

分类：MINOR / 网页新增对聊天图片放大查看的能力，目标版本 `0.24.0-dev.1`。
