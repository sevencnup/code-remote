# 远程 SSH 操作开发文档

本次用户可以从聊天操作此前无法触达的远程服务器，分类为**新增功能 / MINOR**，目标版本 `0.81.0-dev.1`。

## 目标与范围

- 设置页管理多台 SSH 服务器：名称、主机、端口、用户、本机密钥路径、启用状态及逐台权限。
- 目标机只需运行 SSH 服务，不安装 Code Remote。使用主机已有密钥及 `known_hosts`；不保存密码、私钥内容或自动接受未知主机密钥。
- Codex 和 Claude 通过 Code Remote 自带 MCP 工具列出服务器、查看限定的诊断信息、执行经授权的远程命令。
- 聊天中显示服务器、命令、执行中的输出、退出码及错误；刷新后仍可查看操作记录。

## 权限与安全边界

- `inspect` 只允许服务端定义的固定诊断项；`execute` 允许任意远程 shell 命令，权限等同目标 SSH 用户。每次调用重新读取服务端配置、检查服务器启用及权限；撤销立即对后续调用生效。
- 后端严格校验主机、端口、用户名、密钥路径和命令长度，使用参数数组启动 `ssh`，强制 `BatchMode=yes`、`StrictHostKeyChecking=yes`、连接超时及执行超时。
- 配置文件限制为当前服务账户读取，前端只接收密钥路径，不接收密钥内容。浏览器 API 需已配对认证。
- 当前 Codex/Claude 进程拥有本机命令权限。此处勾选只约束 Code Remote 的 SSH MCP 工具，不构成对系统 `ssh`、本地文件或其他工具的隔离。若需不可绕过的限制，必须把 AI 进程放入独立受限账户/容器，并在目标服务器用受限 SSH 用户。

## 数据与消息

- 服务器配置保存在 Code Remote 用户数据目录的权限受限 JSON 文件；操作日志写入 SQLite，记录服务器标识、命令、限量输出、状态、退出码、时间及关联的对话/回合/工具项。
- MCP 进程直接写操作日志；网页按当前对话读取增量输出并刷新卡片。历史加载时从日志恢复对应卡片。
- Codex 每个会话的 MCP 配置带随机上下文标识，Claude 每个回合带上下文标识与回合编号；主服务把上下文映射到对话和当前回合。不能确定回合的记录显示在该对话底部，不挂到其他对话。
- 输出限量并截断，不能保证远程程序输出中的秘密自动脱敏；界面应提醒不要让 AI 执行会打印密钥的命令。

## 实施步骤

1. 服务端实现配置存储、校验、连接检查、SSH 执行和操作日志。
2. 实现无额外 Python 依赖的 stdio MCP 入口，接入 Codex app-server 和 Claude CLI。
3. 把 MCP 调用及操作日志接到现有聊天事件与历史恢复，并在网页显示实时输出卡片。
4. 在设置页增加服务器列表、添加/编辑/删除、逐台权限及连接检查。
5. 按新增功能递增中版本、写简短版本记录、构建并本地提交。根据用户指令，本次不推送 GitHub。
