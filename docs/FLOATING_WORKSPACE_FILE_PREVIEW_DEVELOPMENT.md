# 工作区文件预览悬浮窗开发说明

## 目标

将桌面端工作区文件预览改为悬浮对话框。打开和关闭预览时不调整聊天区或文件树宽度，避免聊天页面比例被挤压或关闭后保持在意外的尺寸。

## 交互与边界

- 桌面端预览在页面上方居中显示，并提供遮罩、关闭按钮、点击遮罩关闭和 Escape 关闭；文件树与聊天内容在弹窗后保留原有布局。
- 移动端继续使用尊重安全区的全屏预览层；桌面和移动端共用预览、编辑、保存、复制、差异显示与未保存修改保护。
- 从文件树或审核卡片打开预览时，继续使用正确的服务端工作目录；关闭预览后返回原界面状态。
- 预览打开、调整窗口大小或关闭时，不修改文件树宽度和聊天区宽度设置，也不再展示文件树与预览之间的拖动分隔条。
- Android 系统返回和移动端侧滑返回仍按一层一层关闭预览、文件树等界面。

## 实施步骤

1. 将桌面预览面板从主网格列移除，改用固定定位悬浮对话框和遮罩；移动端沿用现有全屏安全区布局。
2. 统一桌面与移动端预览的对话框状态、关闭、焦点和 Escape/系统返回处理。
3. 移除仅用于并排预览的宽度分配、拖动分隔条和预览开关对文件树尺寸的耦合；保留文件树自身宽度设置。
4. 更新本开发说明与 `CHANGELOG.md`；执行生产构建和 `git diff --check`，不新增或运行测试，然后创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 桌面打开文件预览时，聊天区和文件树宽度不变；关闭后比例保持原样。
- 桌面预览窗口浮在页面上方，尺寸适配不同窗口；可用关闭按钮、遮罩或 Escape 关闭。
- 移动端预览继续尊重安全区，并可通过关闭按钮、遮罩、Escape、系统返回或侧滑关闭。
- 预览、编辑、保存、复制、语法高亮、差异显示及未保存修改保护保持可用。
- 打开与关闭预览不会覆盖已保存的文件树宽度偏好。
