# 工作区文件预览悬浮窗开发说明

## 目标

将桌面端工作区文件预览改为铺满聊天页面内容区域的悬浮窗口。预览覆盖聊天标题和消息区域，不遮挡右侧文件树和底部输入框；打开和关闭预览时不调整聊天区或文件树宽度。

## 交互与边界

- 桌面端预览从聊天页面内容区域四边铺满；遮罩也限制在聊天页面内容区域，文件树和底部输入框保持可见、可操作。可通过关闭按钮、点击聊天区域遮罩或 Escape 关闭。
- 桌面预览打开时仍可操作右侧文件树并切换预览文件；预览期间点击输入框可继续编辑对话。
- 移动端继续使用尊重安全区的全屏预览层；桌面和移动端共用预览、编辑、保存、复制、差异显示与未保存修改保护。
- 从文件树或审核卡片打开预览时，继续使用正确的服务端工作目录；关闭预览后返回原界面状态。
- 预览打开、调整窗口大小或关闭时，不修改文件树宽度和聊天区宽度设置，也不再展示文件树与预览之间的拖动分隔条。
- Android 系统返回和移动端侧滑返回仍按一层一层关闭预览、文件树等界面。

## 实施步骤

1. 将桌面预览面板移入聊天消息网格的定位容器，以 `inset: 0` 铺满聊天页面内容区域；移动端沿用现有全屏安全区布局。
2. 桌面遮罩限定在聊天内容区域且不锁定全局交互；移动端继续使用模态焦点约束，并保留 Escape/系统返回处理。
3. 移除仅用于并排预览的宽度分配、拖动分隔条和预览开关对文件树尺寸的耦合；保留文件树自身宽度设置。
4. 更新本开发说明与项目版本号；按改动规模决定是否写入 `CHANGELOG.md`。执行生产构建和 `git diff --check`，不新增或运行测试，然后创建本地 Git 提交，不推送 GitHub。

## 验收标准

- 桌面打开文件预览时，聊天区和文件树宽度不变；关闭后比例保持原样。
- 桌面预览窗口铺满聊天页面内容区域，不覆盖右侧文件树和底部输入框；可在窗口打开时从文件树切换文件，并用关闭按钮、区域遮罩或 Escape 关闭。
- 移动端预览继续尊重安全区，并可通过关闭按钮、遮罩、Escape、系统返回或侧滑关闭。
- 预览、编辑、保存、复制、语法高亮、差异显示及未保存修改保护保持可用。
- 打开与关闭预览不会覆盖已保存的文件树宽度偏好。
